# 机遇注册表 — 电力设备产业链

> 调研日期：2026-06-22

## O1：取向硅钢(HiB薄规格)持续紧缺 → 宝钢定价权增强

| 维度 | 内容 |
|------|------|
| **稀缺层** | 取向硅钢(HiB 0.23mm及以下) |
| **驱动** | 变压器能效升级(GB 20052-2020) + 新能源配套 + AI数据中心 → HiB需求增速>15% |
| **约束** | 全球仅约7家可生产高质量GOES，HiB薄规格国内仅宝钢量产，扩产3-5年 |
| **候选标的** | 宝钢股份(600019) — HiB钢国内唯一大规模量产 |
| **证据** | Strong: DOE供应链报告确认GOES短缺；宝钢年报HiB产能数据 |
| **主要风险** | 硅钢收入占宝钢总收入比例较小，钢铁周期性影响大 |
| **置信度** | 高 — 稀缺层判断有物理约束支撑，但传导到个股利润需验证比例 |

## O2：大型变压器全球短缺 → 中国变压器出口窗口

| 维度 | 内容 |
|------|------|
| **稀缺层** | 大型变压器制造 |
| **驱动** | 全球电网升级 + AI数据中心 → 变压器交期从6-12月延长到24-48月 |
| **约束** | 技术壁垒(铁芯/绕组/绝缘/真空处理) + 大件运输物理限制 + 80%+美国依赖进口 |
| **候选标的** | 金盘科技(688676) — 干式变压器出口龙头，墨西哥工厂规避关税 |
| **证据** | Strong: IEEE确认变压器短缺；金盘年报海外收入>30% |
| **主要风险** | 美国关税壁垒(25%+)、UL认证周期1-2年 |
| **置信度** | 中高 — 全球短缺明确但关税是硬约束 |

## O3：有载分接开关寡头 → 华明装备利润传导最直接

| 维度 | 内容 |
|------|------|
| **稀缺层** | 有载分接开关(OLTC) |
| **驱动** | 变压器产量增加 → OLTC需求同步增长 + 真空化替代升级 |
| **约束** | 全球双寡头(MR+华明)，认证壁垒高，客户粘性强 |
| **候选标的** | 华明装备(001270) — 国内市占率80%+，50%毛利率，22%净利率 |
| **证据** | Strong: 华明年报数据、收购MR中国业务 |
| **主要风险** | 高端特高压仍依赖MR技术 |
| **置信度** | 高 — 稀缺层→利润传导路径最清晰 |

## O4：特高压建设高峰 → 设备制造商受益

| 维度 | 内容 |
|------|------|
| **稀缺层** | 特高压变压器/GIS/换流阀 |
| **驱动** | 两网投资8000亿+/年，特高压建设高峰期2025-2027 |
| **约束** | 特高压设备仅少数企业能做，认证周期长 |
| **候选标的** | 中国西电(601179)、平高电气(600312)、许继电气(000400) |
| **证据** | Strong: 国网投资数据、年报利润增速 |
| **主要风险** | 依赖电网投资节奏，净利率偏低 |
| **置信度** | 中高 — 投资确定性高但盈利质量参差 |

## O5：民营电力设备龙头 → 思源电气综合优势

| 维度 | 内容 |
|------|------|
| **稀缺层** | GIS+电力电子(SVC/SVG) |
| **驱动** | 国内外电网投资加大 + 海外订单增长 |
| **约束** | 思源产品矩阵从中压到特高压全覆盖，海外拓展成效显著 |
| **候选标的** | 思源电气(002028) — 营收+28%/利润+32%，14.8%净利率 |
| **证据** | Strong: 年报数据、利润增速远超营收 |
| **主要风险** | 估值可能已反映预期 |
| **置信度** | 中高 — 增长明确但估值需验证 |

## O6：柔直(VSC-HVDC)从示范到规模 → 许继电气增量

| 维度 | 内容 |
|------|------|
| **稀缺层** | 柔直换流阀+直流控保 |
| **驱动** | 海上风电送出 + 城市直流配电 + 柔直规模化 |
| **约束** | 许继特高压直流市占率40-50%，与南瑞双寡头 |
| **候选标的** | 许继电气(000400) |
| **证据** | Medium: 柔直项目逐步落地，但规模化节奏待验证 |
| **主要风险** | 柔直规模化可能比预期慢 |
| **置信度** | 中 — 方向正确但规模化节奏不确定 |
