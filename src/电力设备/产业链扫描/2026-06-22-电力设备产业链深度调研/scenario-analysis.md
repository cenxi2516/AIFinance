## 四情景框架

### 情景A：基准（概率 50%）

**假设**：电网投资维持8000亿+/年，AI数据中心capex温和增长，取向硅钢HiB缺口持续

| 维度 | 预期 |
|------|------|
| 取向硅钢 | HiB薄规格缺口10-15万吨维持至2027，价格稳中有升 |
| 变压器交期 | 全球维持24-36月，中国国内12-18月 |
| 特高压 | 十五五规划逐步核准，3-5条新线路2026-2027开工 |
| 数据中心 | 北美AI capex温和增长+15-20%，金盘订单持续 |
| 出口 | 变压器出口增长20%+，但关税25%仍是硬约束 |

**假设**：电网投资超预期达9000亿+，AI capex爆发式增长(>30%)，取向硅钢缺口扩大

| 维度 | 预期 |
|------|------|
| 取向硅钢 | HiB薄规格缺口扩大至>20万吨，价格上涨10-20% |
| 变压器交期 | 全球进一步延长至36-48月 |
| 特高压 | 十五五规划超预期，6-8条新线路核准 |
| 数据中心 | AI capex>30%增长，金盘北美订单翻倍 |
| 出口 | 关税豁免或降低，出口增量超预期 |

**参考触发条件**：
- 国网年度投资计划>9000亿

### 情景C：悲观（概率 20%）

**假设**：电网投资低于预期(<7000亿)，AI capex放缓，取向硅钢扩产缓解缺口

| 维度 | 预期 |
|------|------|
| 取向硅钢 | 宝钢扩产+进口增加→缺口缩小至5万吨以内 |
| 变压器交期 | 缓解至12-18月 |
| 特高压 | 十五五规划推迟或缩减，新线路核准<3条 |
| 数据中心 | AI capex增速<10%，部分项目推迟 |
| 出口 | 关税升级至50%+或扩大范围 |

**参考触发条件**：
- 国网投资计划下调>10%
- 云厂商capex指引下调
- 变压器交期开始缩短

### 关键观察

1. **今日板块普跌**（-3%~-7%），仅宝钢微涨+0.52%，可能是系统性回调而非个股问题
2. **思源电气**四维共振最好——技术面最强（唯一站上MA5且5日涨+8.4%）、融资逆势加仓、PE虽46x偏高但利润增速+32%支撑
3. **华明装备 PE=191x 异常高**——需核实是否因一次性因素（如收购MR中国业务确认的商誉/摊销），稀缺层逻辑不变但估值安全边际极薄
4. **许继/平高 PE≈21x 最低**——估值有安全边际，但技术面最弱（20日跌-15%/-17%），可能被错杀，需等企稳
5. **东财主力资金流数据缺失**（IP被东财风控封锁），融资数据可作为替代参考但不完全等价
