### 各环节价值占比（占 PCB 成本）

| 环节 | 成本占比 | 稀缺性 | 国产化率 |
|------|:------:|:------:|:------:|
| 电子级玻璃纱 | ~5% | ★★★ | 中等 |
| **电子布** | **~10%** | **★★★★★** | 低（高端<10%） |
| 覆铜板(CCL) | ~30% | ★★★★ | 中等（高端<20%） |
| PCB 制造 | ~55% | ★★ | 高 |

### 电子布在产业链中的角色

> 电子布 = 电子级玻璃纤维布 = PCB 的"骨架"。它提供 PCB 板的**绝缘性、尺寸稳定性、机械强度**。没有电子布，PCB 就是一层软铜箔。AI 服务器的 20-78 层 PCB 中，每一层都需要电子布作为增强基材。

## 二、稀缺性分析（serenity-skill 瓶颈框架）

### 瓶颈层定位：**上游设备 + 中游高端制造 = 双重瓶颈**

```
物理世界约束：

  需求波 → 设备瓶颈（最刚性）→ 产能瓶颈 → 认证壁垒 → 价格传导
  ─────     ────────────────   ────────   ────────   ────────
  AI 服务器  丰田织机垄断90%+    建设周期2年   英伟达认证    电子布涨价
  需求爆发   交货期18-24月      产能弹性=0    6-18个月     → CCL 涨价
  同比+45%   订单排至2030年                               → PCB 涨价
```

### 三层物理约束

| 约束层 | 具体约束 | 缓解时间 | 严重程度 |
|--------|---------|:------:|:------:|
| **设备层** | 高端喷气织机被日本丰田垄断 90%+，年产能仅 2000-2400 台，新订单需等至 2029-2030 | 2-5 年 | 🔴🔴🔴🔴🔴 |
| **制造层** | 电子纱池窑建设 1.5 年 + 织布/表面处理爬坡，完整产能至少 2 年 | 2 年 | 🔴🔴🔴🔴 |
| **认证层** | 进入英伟达/台积电/华为供应链需 6-18 个月验证，认证后极少更换 | 1-1.5 年 | 🔴🔴🔴 |

> **核心发现**：电子布产业链的真正瓶颈**不在中国巨石的产能，而在于它扩产所依赖的日本丰田织机**。这是"瓶颈之上的瓶颈"——设备供给决定了整个行业的产能天花板。

### 价格弹性分析

```
★ Insight ─────────────────────────────────────

这意味着 PCB 厂商对电子布涨价的容忍度极高——
宁可接受电子布涨 100%，也不能让产线停摆。
这种"小成本、大瓶颈"的特性，使得电子布在

─────────────────────────────────────────────────
```

## 六、产业链传导机制

```
信号路径（上游 → 下游）：

  织机锁定 → 电子布供给刚性 → 电子布涨价 → CCL 成本上升 → PCB 涨价
     │              │                │              │
     ↓              ↓                ↓              ↓
  传导时滞:     传导时滞:        传导时滞:      传导时滞:
  0（即时）     18-24个月        1-3个月        1-2个月

反身性（下游 → 上游）：

  PCB 涨价 → AI 服务器成本上升 → 英伟达/苹果抢夺上游配额 → 进一步推高电子布价格
```

### 关键传导时滞

| 传导链 | 时滞 | 当前状态 |
|------|:--:|------|
| 需求爆发 → 电子布涨价 | 1-3 月 | ✅ 已发生（2025.9 起） |
| 电子布涨价 → CCL 涨价 | 1-2 月 | ✅ 已完成五轮传导 |
| CCL 涨价 → PCB 涨价 | 1-2 月 | ✅ 进行中 |
| 涨价信号 → 企业扩产决策 | 3-6 月 | ✅ 巨石/中材已行动 |
| 扩产决策 → 设备订购 | 1-3 月 | ✅ 设备已锁定 |
| 设备订购 → 设备交付 | **18-24 月** | 🔴 等待中（最大瓶颈） |
| 设备交付 → 产能爬坡 | 6-12 月 | ⏳ 2027-2028 |
| 产能释放 → 价格回落 | 3-6 月 | ⏳ 2027Q2+ |
