| 2026.06 | Samsung/SK Hynix 在华 VEU 授权撤销 | 在华外资厂也被收紧 |

**执法力度空前**：
- Applied Materials **$2.52亿**罚单（通过韩国子公司向中芯国际转运离子注入机，54项违规）
- Bosch **$3600万**和解（向华为实体销售 $7000万+传感器）
- BIS FY2026 预算 **$3.03亿**（+59% YoY）→ 执法资源持续加码

**传导分析**：

| 影响 | 子板块 | 逻辑 |
|------|--------|------|
| 🟢 **极强利好** | 半导体设备 | BIS 列名覆盖国内主力设备商 → 国产替代从"可选"变成"唯一选项"。北方华创/拓荆/中微被列后，国内 Fab 厂**只能**采购国产设备。大基金三期 70% 投向设备材料 → 资金+政策双轮驱动 |
| 🟢 **强利好** | 半导体材料 | 南大光电/华特气体/飞源气体等被列 → 国产材料验证窗口加速打开 |
| 🟢 **利好** | EDA | 华大九天被列 → 国产 EDA 从"备选"变"必选" |
| 🟡 **弱利好** | 先进封装 | 管制加速 Chiplet/先进封装路线（绕开先进制程限制） |
| 🟠 **弱利空** | 芯片设计(先进制程) | 先进制程流片困难加剧，但成熟制程设计不受影响 |

**核心结论**：这轮管制的本质不同在于——**被禁的企业本身就是国产替代的供给方**（设备/材料/EDA），列名等于官方认证了它们的战略地位和不可替代性。这是 2019 年华为被禁以来，**国产替代逻辑最顺畅的一轮**。

- 光模块在 7-8 月中报季重新定价，业绩超预期者收复 7 月跌幅
- 上证 4000 点附近反复争夺，科创 50 跑赢主板
- **科创 50 区间**：3,600-4,100 震荡偏强

### 📌 核心结论

1. **短期（1-2 周）**：外围科技股暴跌（SOX -13%）对 A 股科技形成情绪压制，但 **A 股半导体已展现出明显的脱钩韧性**——大盘暴跌时半导体逆势上涨+批量涨停、ETF 越跌越买+560 亿。SOX 11,950 支撑暂守，短期以震荡筑底为主。**7/15-16 ASML+台积电财报是近期最大变量。**

2. **中期（1-3 月）**：**半导体设备/材料是当前硬科技中最确定的赛道**。四重驱动形成罕见的共振：
   - ① BIS 列名倒逼国产替代（被禁 = 官方认证战略地位）
   - ② 大基金三期 3440 亿密集落地（70% 投向设备材料，并购整合加速）
   - ③ 在手订单 900 亿+ 锁定 2027-2028 年业绩
   - ④ SIA 全球销售翻倍（+104.1% YoY）+ AI capex $8,300 亿（+79%）→ 全球产业周期上行
   - **这是"政策+周期+业绩"三维共振，在历史上极为罕见。**

3. **AI 算力/光模块**产业趋势不变但短期面临获利了结压力（7 月初回调 15-20%），中报季（7-8 月）是验证窗口。**7/22-30 美股 M7 Q2 财报**将决定全球 AI 产业链方向。业绩超预期的光模块公司将率先修复。

4. **最大变量**：7/15-16 ASML + 台积电财报 → 决定全球半导体板块未来一个季度的方向。若双超预期 → 乐观情景激活；若双低于预期 → 悲观情景概率升至 40%。

5. **风险提示**：若 SOX 跌破 11,700 + 中东局势扩大 + ETF 资金转向流出 + ASML/TSMC 财报利空同时发生，建议转为防御（概率 ~0.4% 但破坏力极大）。更现实的关注点是科技拥挤度（TMT 成交占比持续高位），这是当前最被低估的风险。

6. **7 月下旬是多重验证窗口**：中报预告密集披露 + ASML/TSMC 财报 + M7 财报 + 政治局会议 + 美联储议息 → 波动将显著放大。建议在 7/15 前保持灵活，等待关键信号落地后再调整判断。
