## 🔗 关键传导路径

### 路径1：估值锚定传导 → 短期利空，中
**触发**：SOX自6月底历史高点14,655回撤~15%，最低触及11,960
**逻辑**：全球科技估值中枢下移 → A股科技估值承压 → 今日科创50 -4.25%
**关键观察**：A股科技是否脱钩？国产替代逻辑+国内流动性宽松是对冲力量
**脱钩信号监测**：当SOX继续下跌但A股半导体ETF不再跟跌 → 脱钩确认

### 路径2：出口管制传导 → 短期利空/中长期强利多，强 ⭐
**触发**：7月5日BIS大幅扩大实体清单，涉及拓荆科技(设备)、华大九天(EDA)、RSIC(精密仪器)、Nata(材料)
**逻辑**：管制加码 → 短期供应链风险(已有体现) + 中长期国产替代加速
**弹性最大环节**：半导体设备 > 半导体材料 > EDA
**关键观察**：国内晶圆厂是否加速国产设备采购（国产化率22.7%→目标30%+）、大基金三期2,400亿投放节奏
**反方风险**：若管制扩大至成熟制程(28nm+)设备 → 短期冲击将显著加大

### 路径3：AI capex 传导 → 利多，强 ⭐
**触发**：北美云厂商2026年AI capex估计$695-725B（超此前2027年预测），总AI支出或达$880B
**逻辑**：AI算力需求↑ → 光模块/服务器/PCB订单↑ → 业绩兑现
**弹性最大环节**：光模块(中际旭创/新易盛) > AI服务器(工业富联) > PCB(沪电股份/生益科技) > 散热
**关键观察**：中际旭创/新易盛在手订单、800G/1.6T出货量

### 路径4：半导体周期传导 → 偏多，中
**触发**：全球半导体仍在景气上行，但DRAM涨价斜率从Q1的+93% QoQ放缓至Q3的+13-18% QoQ
**逻辑**：AI驱动结构性超级周期 → 设备/制造景气 > 存储芯片面临价格拐点
**关键观察**：SIA月度销售、DRAM现货价(DDR5 16Gb $47)、台积电月度营收(6月历史新高+68% YoY)
**周期位置判断**：景气上行中期——涨价斜率放缓但不等于见顶，AI结构性需求支撑

### 路径5：国内产业政策传导 → 强利多，强 ⭐⭐
**触发**：五部门7月3日487号文件(税收减免) + 大基金三期2,400亿设备材料专项 + 工信部15-25%采购补贴
**逻辑**：政策创造需求 → 国产设备/材料导入加速 → 收入增长
**弹性最大环节**：半导体设备(国产化率最低，仅24%) > 半导体材料 > 制造
**关键观察**：大基金三期实际投资进度、晶圆厂国产设备招标中标公告
**反方风险**：政策从出台到落地有时间差，Q3-Q4才能看到实际订单转化

## 📝 情景推演

### 基准情景（概率 ~50%）：短期震荡筑底，中期重拾升势
- **假设**：SOX在12,000-13,000区间震荡企稳，国内政策持续落地，ETF资金继续流入
- **路径**：7月下旬-8月初科技板块在当前位置震荡→中报季验证业绩→9月重拾升势
- **科创50区间**：1,850-2,050
- **操作框架**：回调是布局窗口，优先半导体设备/材料+AI光模块，控制仓位等待右侧确认

### 乐观情景（概率 ~25%）：政策催化+外围企稳，V型反弹
- **假设**：TSMC法说会超预期上调capex + 政治局会议出台新科技政策 + SOX快速收复13,000
- **路径**：7月下旬科技板块快速反弹，科创50回到2,100+
- **触发条件**：大基金三期首批投资公告 + 国内设备公司中报超预期
- **弹性最大**：半导体设备（当前跌幅最大，反弹弹性也最大）

### 悲观情景（概率 ~25%）：多重风险兑现，深度调整
- **假设**：SOX跌破11,000 + DRAM价格大幅回落 + 出口管制扩大至成熟制程 + 中报低于预期
- **路径**：科技板块再跌10-15%，科创50下探1,700-1,800
- **关键支撑**：科创50 1,800（对应2024年底水平，当时国产替代逻辑尚未充分定价）
- **应对**：减仓至防御仓位，等待风险出清后的"黄金坑"机会

## 📋 综合研判逐条总结

1. **方向**：🟡 偏多。短期(1-2周)有继续回调压力，中期(1-3月)在政策+资金+业绩支撑下看好。
2. **节奏**：7月下旬至8月初是"验证窗口"（TSMC法说会+中报季+政治局会议），验证通过则9月行情可期。
3. **最强方向**：半导体设备/材料（国产替代逻辑+政策最强支撑+ETF流入最大），其次是AI光模块（业绩确定性高）。
4. **最弱方向**：存储芯片（价格拐点风险+德明利暴雷），消费电子芯片设计（需求不确定）。
5. **仓位建议框架**：当前位置可维持硬科技配置，但不宜追高加仓——等右侧信号（科创50连续2日不再创新低+成交量放大）确认后再加。
6. **最大风险**：出口管制扩大至成熟制程（概率15%但影响颠覆级），需持续跟踪。
7. **反方观点**：SOX从高点回撤15%可能只是开始，参考2022年SOX曾回撤40%+；当前A股科技估值仍在历史高位（科创50 PE 232倍），回调空间不小。
8. **与7月14日反弹的关系**：7月14日AI硬件反弹（东山精密/沪电股份涨停）被7月15日的全线重挫否定，说明市场对科技股分歧极大，"一日游"特征明显，不宜因单日反弹而追高。
