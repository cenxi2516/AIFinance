## 二、贵州茅台（600519）深度分析

### 2.1 产业链位置：白酒金字塔的绝对塔尖

```
消费者需求
    ↓
[终端零售] 烟酒店/商超/餐饮/i茅台直营  ← 茅台正在强化这一层
    ↓
[经销商层] 社会经销商（议价权被削弱中）
    ↓
[品牌方] 贵州茅台 ← ★ 我们在这一层 ★
    ↓
[生产端] 茅台镇15.03km²核心产区 → 基酒产能 → 30万吨+库存
```

**是否必经之路？** ✅ 是。在2000元+超高端白酒市场，茅台市占率57-85%。任何想要展示"最高规格"的商务宴请/礼赠场景，茅台是**唯一选择**。五粮液/国窖1573无法在心理价位上替代。

**议价权判断**：极强。应收周转天数几乎为零（先款后货），毛利率91.3%连续8季稳定。但2025-2026年批价从3500元跌至1520元，说明终端定价权正在从"金融属性驱动"回归"消费属性支撑"。

### 2.4 不可替代性评级：A 级（高度稀缺）

**为什么不是 S 级？**
- 在"投资/囤货"场景中，茅台的可替代性正在增强（共识瓦解后，茅台不再是"稳赚不赔"的资产）
- 在"商务宴请"场景中仍是唯一选择，但这一场景本身在萎缩
- 批价从3500跌至1520，说明市场对"不可替代性"的定价正在理性回归

**为什么是 A 级而非更低？**
- 品牌心智垄断：2000元+价格带无可挑战的市占率
- 供给不可复制：30万吨基酒+5年时间锁死，任何新进入者都无法在10年内构成威胁
- i茅台数字化直营正在构建新壁垒——9615万注册用户的消费数据+精准营销

**客户切换成本**（从商务客户视角）：从茅台切换到五粮液 → 接待规格降级 → 商业机会损失（难以量化但真实存在）。单个客户的切换成本 = "关系信用损失"。

### 2.6 对老登股定级的影响

**老登股原评级**：⭐⭐⭐ 核心老登（4.60分）
**Moat-Hunter 验证结果**：A 级（高度稀缺）→ **维持核心老登，护城河深度可信**

**一句话**：茅台的不可替代性在"消费场景"中依然坚固（A级），但在"投资场景"中已大幅削弱。对老登股框架而言，**消费属性的护城河才是可持续的**，当前PE 18.1x更多反映了投资属性的退潮而非消费属性的瓦解。

## 三、泸州老窖（000568）深度分析

### 3.1 产业链位置：浓香白酒技术巅峰

```
浓香白酒竞争格局（1000元+价格带）
    ├── 国窖1573 ← ★ 我们在这一层 ★
    ├── 五粮液普五（最大竞争对手）
    ├── 洋河梦之蓝M9/M6+
    └── 剑南春/古井贡年份原浆
```

**是否必经之路？** ⚠️ 部分是。在浓香白酒中，国窖1573的技术壁垒（93%明清古窖池）无人能及。但在千元价格带，**五粮液是直接替代选择**。在800元以下价格带，替代更多。

泸州老窖的"必经之路"属性**取决于场景**：
- 喝"最好的浓香" → 必经之路（国窖1573）
- 喝"千元白酒" → 五粮液可以替代
- 喝"低度白酒" → 38度国窖定义了这个品类（首个百亿大单品），不可替代性强

| **认证壁垒** | 2/5 | 国窖1573是浓香白酒中**唯一获得有机认证**的产品。但这个认证的品牌价值大于准入门槛价值。 | 财经网2026.05 |

### 3.4 不可替代性评级：A 级（高度稀缺）

**为什么是 A 级？**
- **低度国窖1573的不可替代性最强**：白酒行业首个百亿级低度大单品，定义了"低度高端白酒"这个品类。38度国窖的消费者（华北50亿+市场）几乎没有同档次替代选择。
- **"活态双国宝"的壁垒深度**：93%明清古窖池+24代非遗技艺，这种以"世纪"为单位的时间壁垒，无法被资本或技术跨越。
- **五码数字化的客户关系绑定**：5000万会员+扫码率50% → 精准知道谁在喝、何时喝、喝什么 → 未来可做精准营销和C2M。

**为什么不是 S 级？**
- 高度国窖1573在千元价格带有明确的替代方案（五粮液普五、茅台1935）
- 商务宴请需求萎缩对所有千元白酒都是逆风，不是泸州老窖独有问题
- 经销商库存7个月偏高，去库存周期可能持续到2027年

**客户切换成本**：从国窖1573切换到五粮液 → 需要接受的差异：①有機vs非有機 ②单粮vs多粮口感 ③品牌调性（"可以品味的历史"vs"中国的五粮液"）。切换成本较低（1-2次宴请即可完成切换）。但**低度国窖的切换成本更高**——市场上几乎没有同品质的低度竞品。

### 3.5 风险三重排除

| **客户自研** | ✅ 已排除 | 白酒品牌不可自研。 | — | — |
| **产能过剩** | ⚠️ 需跟踪 | 全行业库存偏高(经销商7个月)。公司主动去库+控量挺价。预判2026H2进入全行业去库存周期。 | ①高度国窖批价跌破800元 ②经销商库存升至10月+ ③Q2营收继续-15%以上 | 批价月度跟踪；合同负债季度变化；中秋国庆动销 |

**风险交互分析**：最危险的情景 = "商务宴请持续萎缩 + 五粮液降价挤压 + 去库存周期拉长到2027年"。如果同时兑现，低度国窖的全国化扩张可能不足以弥补高度国窖的缺口，卖方一致预期可能进一步下调至90亿以下。

### 3.6 对老登股定级的影响

**老登股原评级**：⭐⭐⭐ 核心老登（4.40分）
**Moat-Hunter 验证结果**：A 级（高度稀缺）→ **维持核心老登，但置信度降低**

**置信度降低的原因**：
1. 供需验证为🟡中等（非强），经销商端信号偏弱
2. 卖方EPS预期分歧极大(91-110亿)，不确定性高
3. 库存去化+商务需求萎缩的时间节点不确定

**维持核心的核心理由**：
- 低度国窖的品类定义权 + 活态双国宝的时间壁垒 = A级不可替代性
- PE 11.4x(历史0%分位) + 股息率5.8% = 估值已提供强下行保护
- **Q2(7-8月披露半年报)是验证窗口**——低基数下营收能否止跌是核心信号

## 四、中国人寿（601628）深度分析

### 4.1 产业链位置：寿险行业的绝对龙头

```
中国寿险行业格局
    ├── 中国人寿 ← ★ S级不可替代 ★（市场份额21.88%，总资产7.42万亿）
    ├── 中国平安（综合金融+科技）
    ├── 中国太保（财险强+寿险追赶）
    ├── 新华保险（纯寿险，规模较小）
    └── 互联网保险（众安/水滴等，差异化竞争）
```

**是否必经之路？** ✅ 对于特定客群，是。

- **政府和央企采购**：副部级央企信用 → 政府和国有企事业单位员工团险/年金 → 中国人寿是事实上的"默认选择"
- **县域市场**：1.8万网点+58.7万代理人覆盖所有省份（含西藏阿里）→ 在一个"网点到镇、人员到村"的市场中，是唯一选择
- **大额养老/理财型保险**：AAA评级+7.42万亿总资产 → "无论极端情况都能赔得起" → 这是商业保险公司无法提供的确定性

**议价权判断**：极强。保险公司不需要"议价"，其竞争力体现在：①NBV增速（+75.5% Q1 2026）②保单继续率 ③新业务价值率。中国人寿三个指标均为行业领先。

### 4.2 稀缺性评估（5类壁垒）

| 壁垒类型 | 评分 | 依据 | 证据来源 |
|---------|------|------|---------|

### 4.4 不可替代性评级：S 级（唯一不可替代）

**为什么是 S 级？**

1. **牌照+央企信用的双重独占**：保险全牌照+副部级央企的组合，在中国只有**中国人寿一家**。其他央企保险(人保/太平)要么缺银行信托牌照，要么寿险规模远不及。商业保险公司(平安/太保)没有央企信用。

2. **"保险+康养"生态闭环的不可复制性**：16城20个养老项目+75%入住率+1.8万入住人。这个重资产、长周期投入（单个养老社区从拿地到满住需5-8年），任何新进入者在10年内无法追平。

3. **县域网络+"最后一公里"的物理壁垒**：1.8万网点+58.7万代理人覆盖到乡镇一级。互联网保险可以卖百万医疗，但卖不了需要"面对面建立信任"的长期养老/分红险。

4. **四类供需证据全部正向**——Moat Hunter 框架中最强的验证信号。

**客户切换成本**（从一个50岁投保养老险的客户视角）：
- 退保 → 损失已缴保费的大量现金价值
- 转到另一家 → 新保单年龄更大、保费更贵、等待期重算
- 没有"携号转网"的机制
- **切换成本 = 几乎不可能切换**

### 4.5 风险三重排除

| 风险类型 | 状态 | 依据 | 触发条件 | 跟踪指标 |

**风险交互分析**：核心风险只有一条——**利率长期下行**。如果10年期国债收益率持续低于2.5%并维持5年+，保险公司投资端将面临系统性压力，分红险的吸引力也会下降。但这是全行业风险，不是国寿特有风险，且国寿的投资收益率(6.09%)和资产规模(17.5万亿管理)使其抗压能力强于行业。

### 4.6 对老登股定级的影响

**老登股原评级**：⭐⭐⭐ 核心老登（4.10分）
