2. **消费（扩消费五年规划）**：驱动事件=首份国家级扩消费五年规划+6月消费增速由负转正+超20地住房补贴；催化时点=7月下旬政策细则出台期；置信度 **中高**。⚠️ 但消费板块前期跌幅>5%，属于"利空出尽候选"，如果有反转催化剂（扩消费政策），弹性最大。

3. **军工/黄金（避险+地缘）**：驱动事件=美军连续袭击伊朗+霍尔木兹海峡危机+曼德海峡威胁；催化时点=冲突持续发酵期；置信度 **中**。⚠️ 地缘冲突类事件延续性不确定，脉冲性强。

**风险点**：

1. **AI/半导体高位回调风险 🚨🚨**：触发条件=前期涨幅>15% + WAIC利好出尽 + 韩国存储崩盘传导；影响范围=整个科技链条（AI芯片→算力→CPO→存储）；概率 **高（>80%）**。7/17已验证——创业板跌3%，算力硬件领跌。

2. **中东冲突失控风险 🔴**：触发条件=伊朗关闭曼德海峡或霍尔木兹海峡军事封锁；影响范围=全球油价+航运+通胀预期；概率 **低（<15%）但影响极大**。

### 中期（1-3 月）

**主线判断**：

1. **AI国产化（产业趋势未完）**：多条事件共振——WAIC+Kimi K3+DeepSeek估值+长鑫IPO+海光业绩+复旦量子+端侧AI备案。这是"产业类"催化（业绩+政策双驱动），延续性⭐⭐⭐⭐⭐最强。**但短期拥挤度见顶，需要先消化获利盘，之后主线重新凝聚而非终结**（广发证券结论）。

2. **消费复苏（政策驱动新主线）**：扩消费五年规划是制度性转变，从"刺激"→"保障"，持续性可能超预期。叠加基药目录改革（医药消费）和住房补贴政策，消费方向正在积累催化。

**潜在转折信号**：
- **如果中东冲突缓和** → 黄金/军工回落 → 科技风险偏好恢复 → AI主线重新凝聚
- **如果7月下旬消费数据持续超预期** → 消费方向从"弱预期差"→"强资金共振" → 可能出现高低切换
- **如果韩国存储崩盘持续扩散** → 全球AI投资预期下调 → 算力板块中期承压 → 端侧AI/国产替代可能替代算力成为AI新主线
