# 保险行业可验证假设注册表

> 研究质量取决于假设质量。好的假设必须**可证伪**——你知道什么证据出现时会承认它错了。
> 保险行业的关键假设围绕"利率方向"、"稀缺层兑现"和"估值修复"三个核心。

---

## 假设列表

### H1: 低利率下投资能力差异被放大，太保和平安的投资alpha溢价应被重新定价

- **假设内容**：在10Y国债<2.0%时，保险公司综合投资收益率差异从"谁多赚0.5%"这种微小差异变为"谁赚3%+谁赚不到3%"这种生死差异，投资能力强的公司应获得估值溢价而非被当作普通利率beta
- **前提/前置条件**：①10Y国债持续<2.0%（当前已满足）；②保险公司投资收益率分化加剧（需验证）
- **验证信号**：太保和平安2026H1综合投资收益率>4.5%，且显著高于国寿和新华（差距>1个百分点）
- **否定信号**：5家保险公司综合投资收益率差距<0.5个百分点 → 投资能力差异在低利率下并未被放大
- **验证窗口**：2026-Q3前（基于2026H1业绩数据）
- **数据来源**：各公司2026H1财报+业绩发布会
- **验证结果**：pending
- **对优先级的影响**：
  - 证实 → 太保和平安优先级进一步提升，估值修复逻辑确认
  - 证伪 → 投资能力不再是稀缺层，回归利率beta逻辑，弹性标的优先级上升

### H2: 中国太保在"投资稳健+渠道转型"两个稀缺层上的控制力排名前2，当前估值偏低

- **假设内容**：太保PE=5.6x/PB=0.95/PEV=0.5x是市场对其稀缺层控制力的低估，而非基本面合理定价
- **前提/前置条件**：①太保2026H1 NBV增速>10%；②太保综合投资收益率>4.5%
- **验证信号**：太保2026H1业绩确认NBV增速>10%+投资收益率>4.5%，且卖方研报开始强调太保的投资稳健性和渠道转型
- **否定信号**：太保2026H1 NBV增速<5%或投资收益率<3.5% → 基本面不支持稀缺层控制力判断
- **验证窗口**：2026-Q3前
- **数据来源**：太保2026H1财报
- **验证结果**：pending
- **对优先级的影响**：
  - 证实 → 太保优先级维持第1，估值修复目标PEV 0.6-0.7x
  - 证伪 → 太保优先级下降，重新评估稀缺层排序

### H3: 报行合一中期利好头部公司集中度提升，而非行业永久缩量

- **假设内容**：报行合一消灭中小公司费用竞争武器后，头部公司品牌和服务优势凸显，市场份额和NBV margin改善
- **前提/前置条件**：①报行合一持续严格执行（已满足）；②头部公司产品和服务差异化明确（部分满足）
- **验证信号**：2026H头部公司银保新单市占率上升>5个百分点，且NBV margin改善>2个百分点
- **否定信号**：行业银保总新单规模连续3年同比下降>10% → 蛋糕在变小而非重新分配
- **验证窗口**：2027-Q2前（银保渠道调整需要1-2年）
- **数据来源**：各公司银保新单数据+行业统计
- **验证结果**：pending
- **对优先级的影响**：
  - 证实 → 平安/太保优先级进一步提升（品牌+服务优势标的）
  - 证伪 → 银保依赖高的公司（国寿）优先级进一步下降

### H4: 人保财险承保利润(COR<97%)是低利率下极稀缺的"不依赖利差的利润来源"

- **假设内容**：人保财险COR<97%提供的稳定承保利润，在10Y国债<2.0%时具有独特的稀缺性，应获得估值溢价
- **前提/前置条件**：①人保财险COR持续<97%（多年数据已验证）；②市场开始区分财险和寿险的估值逻辑
- **验证信号**：卖方研报开始对人保采用分部估值法（财险PE 10-12x+承保溢价，寿险PEV 0.6x），且人保财险COR持续<97%
- **否定信号**：人保财险COR>100%（巨灾或定价恶化） → 承保利润稀缺性暂时消失
- **验证窗口**：2027-Q2前（市场认知改变缓慢）
- **数据来源**：人保财险季度COR数据+卖方研报方法论变化
- **验证结果**：pending
- **对优先级的影响**：
  - 证实 → 人保优先级上升，分部估值法确认后估值修复空间大
  - 证伪 → 人保优先级维持第3，财险稀缺性暂时消失但可恢复

### H5: 新华保险PE=5.4x是对利差损风险的合理定价而非低估

- **假设内容**：新华保险低PE反映的是储蓄型产品占比高+投资能力偏弱的利差损风险，而非价值低估
- **前提/前置条件**：①新华储蓄型产品占比>60%；②新华综合投资收益率偏低（<4%）
- **验证信号**：新华2026H1综合投资收益率<3.5% → 利差损风险确认 → PE=5.4x是风险定价
- **否定信号**：新华2026H1综合投资收益率>5% → 利差损风险不存在 → PE=5.4x确实是低估
- **验证窗口**：2026-Q3前
- **数据来源**：新华2026H1财报
- **验证结果**：pending
- **对优先级的影响**：
  - 证实 → 新华维持最低优先级，仅作为弹性标的观察
  - 证伪 → 新华优先级上升，可能从"风险定价"转为"低估修复"

### H6: 代理人质量提升是主动成果而非数量下降的被动结果

- **假设内容**：代理人人均NBV提升是因为公司主动优化队伍质量（提高招募标准+加强培训），而非单纯因为低产能者离开后均值被动上升
- **前提/前置条件**：①代理人招募标准提高；②培训体系完善；③人均产能绝对值提升（而非仅比例提升）
- **验证信号**：代理人数降幅放缓至<5%/季度，但人均NBV仍持续提升>10% → 证明质量提升是主动成果
- **否定信号**：代理人数降幅放缓后人均NBV增速也放缓 → 人均提升仅是数量下降的被动结果
- **验证窗口**：2027-Q1前
- **数据来源**：各公司月度代理人数量+NBV数据
- **验证结果**：pending
- **对优先级的影响**：
  - 证实 → 渠道转型标的（平安/太保）优先级确认
  - 证伪 → 渠道转型假设需要修正，总NBV增长依赖人数止跌
