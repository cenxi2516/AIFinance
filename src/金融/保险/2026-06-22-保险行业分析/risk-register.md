# 保险行业风险注册表

> 专业投资者的第一课：**先看风险，再看机遇。**
> 保险行业的核心风险公式：**利差 = 投资收益率 - 资金成本**。利率是保险行业最核心的宏观变量。

---

## 一、宏观风险

### R1: 长端利率持续下行/维持低位

- **风险描述**：10年期国债收益率持续走低或长期维持在2%以下，导致保险公司新增资金配置收益率无法覆盖负债成本，形成利差损
- **风险类别**：宏观 — 货币政策/利率周期
- **触发条件**：10年期国债收益率 <1.8% 持续2个季度以上，或央行进一步降息30bp以上
- **前置信号**：①央行降息信号 ②CPI持续<0.5% ③M2增速>名义GDP增速持续扩大 ④30年国债收益率创新低
- **影响程度**：**颠覆**（利差损是保险行业最根本性风险，日本90年代案例：利率从6%降至1%，多家保险公司破产）
- **当前概率**：**高（40-55%）** — 2026年中国仍处降息周期，10Y国债在1.6-1.8%区间
- **概率依据**：中国经济转型期需低利率环境支持，短期无反转迹象；但极低利率下央行可能企稳
- **时间窗口**：2026H2-2027（若经济未见底回升，利率将继续下探）
- **影响标的**：全部保险股，纯寿险公司（新华保险>中国人寿>中国平安）受影响最大，因对利差依赖度更高
- **应对预案**：
  - 信号初现 → 降低寿险权重，关注财险占比高的公司
  - 信号确认 → 仅保留投资能力强+产品结构优的标的
  - 风险兑现 → 大幅缩减保险仓位

### R2: 权益市场大幅波动/熊市

- **风险描述**：A股/港股大幅下跌，保险公司权益投资浮亏扩大，影响当期利润和净资产
- **风险类别**：宏观 — 市场风险
- **触发条件**：沪深300下跌>20%且持续2个季度以上
- **前置信号**：①北向资金持续净流出 ②融资余额快速下降 ③经济数据连续不及预期 ④地缘风险升级
- **影响程度**：**重度**（直接侵蚀利润和偿付能力，但不颠覆长期价值）
- **当前概率**：**中（20-30%）** — 当前A股估值中性，但外部不确定性较大
- **概率依据**：中美关系不确定性+国内经济复苏力度待验证
- **时间窗口**：2026H2-2027
- **影响标的**：权益配置比例高的公司（中国平安>中国太保），纯寿险公司更敏感
- **应对预案**：
  - 信号初现 → 关注公司权益仓位比例和浮盈情况
  - 信号确认 → 偏好投资稳健、权益占比低的公司
  - 风险兑现 → 等待市场企稳后再加仓

### R3: 人民币汇率大幅波动

- **风险描述**：人民币贬值超预期，影响保险公司海外资产价值和外资持有意愿
- **风险类别**：宏观 — 汇率
- **触发条件**：美元/人民币 >7.5 持续1个月以上
- **前置信号**：①中美利差持续扩大 ②外汇储备持续下降 ③资本外流加速
- **影响程度**：**中度**（对有海外配置的公司影响更直接）
- **当前概率**：**低（10-15%）**
- **概率依据**：央行有充足工具管理汇率，大幅贬值不符合政策目标
- **时间窗口**：2026-2027
- **影响标的**：海外投资占比高的公司（中国平安、中国太保）
- **应对预案**：
  - 信号初现 → 关注公司海外资产配置比例和汇率对冲策略
  - 信号确认 → 偏好国内资产为主的公司

## 二、政策与监管风险

### R4: "报行合一"监管全面执行，银保渠道费率大幅压降

- **风险描述**：监管持续推行"报行合一"（产品备案费用=实际执行费用），银保渠道手续费大幅压缩，短期银保新单规模和利润承压
- **风险类别**：政策 — 行业监管
- **触发条件**：监管进一步扩大"报行合一"覆盖范围（从储蓄型产品扩展到保障型产品），或银保渠道实际手续费降幅>50%
- **前置信号**：①监管会议或文件提及渠道费用管控 ②银保渠道新单增速骤降 ③中小公司银保策略转向
- **影响程度**：**重度**（短期银保新单和NBV大幅下滑，但长期利好行业费用率改善）
- **当前概率**：**高（>60%）** — 2024年已开始执行，范围扩大是大概率事件
- **概率依据**：监管态度明确，保护消费者利益+降低行业费用率是长期方向
- **时间窗口**：2026年全年（持续影响）
- **影响标的**：银保渠道占比高的公司（中国人寿、新华保险），银保渠道利润贡献大的受冲击更直接
- **应对预案**：
  - 信号初现 → 评估各公司银保渠道依赖度和转型进度
  - 信号确认 → 偏好个险渠道强、银保依赖低的公司（中国平安）
  - 风险兑现 → 关注渠道转型成效，不因短期下滑而恐慌

### R5: 保险产品预定利率进一步下调

- **风险描述**：监管继续下调保险产品预定利率上限（如从2.5%降至2.0%），短期产品吸引力下降，新单增速承压
- **风险类别**：政策 — 产品监管
- **触发条件**：监管发布新规下调预定利率上限>25bp
- **前置信号**：①长端利率进一步下行 ②行业协会讨论利率调整 ③中小公司利差损压力加大
- **影响程度**：**中度**（短期影响销售，长期保护行业利差空间，是"短空长多"）
- **当前概率**：**中（30-40%）** — 取决于利率走势
- **概率依据**：若利率继续下行，监管有动力下调预定利率以防范行业利差损风险
- **时间窗口**：2026H2-2027
- **影响标的**：储蓄型产品占比高的公司受短期冲击更大
- **应对预案**：
  - 信号初现 → 评估各公司产品结构调整进度
  - 信号确认 → 关注分红险/万能险占比提升的公司
  - 风险兑现 → 预定利率下调实为行业保护措施，中期偏利好

### R6: IFRS17会计准则切换后的财务可比性问题

- **风险描述**：IFRS17实施后，保险公司财务报表结构和关键指标定义变化，市场对"新指标"理解不充分可能导致估值偏差
- **风险类别**：政策 — 会计准则
- **触发条件**：新会计准则下的关键指标（如CSM、保险服务收入）与旧指标产生重大差异
- **前置信号**：①公司财报中CSM摊销节奏变化 ②合同服务边际出现负增长 ③分析师对可比性争议增多
- **影响程度**：**轻度**（主要影响短期理解和估值，不改变实际经营质量）
- **当前概率**：**中（25-35%）** — 已切换但市场理解仍在深化
- **概率依据**：2023年起已执行，但部分投资者对新指标仍不熟悉
- **时间窗口**：2026年
- **影响标的**：所有A股保险公司
- **应对预案**：
  - 关注公司管理层在业绩会上的指标解读
  - 优先使用NBV、EV等市场已认可的核心指标

## 三、产业链/行业风险

### R7: 代理人渠道持续萎缩，新业务价值增长乏力

- **风险描述**：保险代理人规模从高峰900万持续下降至当前约300万水平，虽质量在提升但数量下降过快可能导致新单增长失速
- **风险类别**：产业链 — 渠道变革
- **触发条件**：头部公司代理人数量环比降幅>5%持续2个季度，且NBV同比转负
- **前置信号**：①代理人招募困难 ②人均产能增速放缓 ③新单期交保费增速下降
- **影响程度**：**重度**（代理人是个险渠道的根基，短期内无法被其他渠道完全替代）
- **当前概率**：**中（25-35%）** — 代理人规模已大幅缩减，降幅正在收窄
- **概率依据**：2023-2025年头部公司代理人已基本企稳或降幅收窄，但经济环境不利可能再次加速脱落
- **时间窗口**：2026-2027
- **影响标的**：个险渠道占比高的公司（中国平安、中国人寿、新华保险）
- **应对预案**：
  - 信号初现 → 重点关注人均产能（活动率×件均×人均件数）能否对冲人力下滑
  - 信号确认 → 评估各公司多元化渠道建设进度（银保+经代+互联网）
  - 风险兑现 → 降低对NBV增长的预期

### R8: 产品同质化+价格战，新业务价值率下降

- **风险描述**：储蓄型产品同质化严重，公司间通过降低费用或提高收益承诺竞争，导致新业务价值率（NBV margin）持续下降
- **风险类别**：产业链 — 竞争格局
- **触发条件**：行业平均NBV margin连续2年下降>3个百分点
- **前置信号**：①中小公司激进定价 ②行业费用率上升 ③监管窗口指导费率
- **影响程度**：**中度**（"报行合一"已在整治，但执行力度待观察）
- **当前概率**：**中（20-30%）** — 监管约束下大概率可控
- **概率依据**："报行合一"直接针对此问题，监管力度较强
- **时间窗口**：2026-2027
- **影响标的**：产品差异化弱的公司受影响更大
- **应对预案**：
  - 关注有产品创新能力的公司（分红险、养老年金等差异化产品）
  - 偏好NBV margin稳定或改善的公司

### R9: 非标资产/地产关联风险暴露

- **风险描述**：保险公司持有的非标资产（含地产相关）出现违约或减值，影响投资收益和净资产
- **风险类别**：产业链 — 资产质量
- **触发条件**：地产企业违约事件再次集中爆发，或保险公司非标资产减值比例>3%
- **前置信号**：①百强房企销售持续恶化 ②保险公司信用减值损失大幅增加 ③非标资产配置比例异常上升
- **影响程度**：**重度**（2021-2023年地产爆雷已造成实质性损失，若再次集中暴露则冲击更大）
- **当前概率**：**中（15-25%）** — 地产风险已部分出清，但尚未完全化解
- **概率依据**：当前地产政策托底，但销售端恢复缓慢，部分中小房企仍面临偿债压力
- **时间窗口**：2026H2-2027
- **影响标的**：非标/地产配置占比高的公司需逐一排查
- **应对预案**：
  - 信号初现 → 索取公司非标资产和信用敞口明细
  - 信号确认 → 回避非标和地产敞口大的公司
  - 风险兑现 → 等待减值充分计提后再评估

## 四、公司层面风险

### R10: 投资能力分化，部分公司投资收益持续落后

- **风险描述**：在低利率环境下，保险公司投资能力差异被放大，投资收益持续落后于同业的公司面临利差损压力
- **风险类别**：公司 — 投资能力
- **触发条件**：公司综合投资收益率连续2年低于负债成本（约3-3.5%）
- **前置信号**：①公司调整资产配置策略（增配权益/另类） ②净投资收益率持续低于同业均值50bp以上 ③频繁更换投资负责人
- **影响程度**：**重度**（投资能力是保险公司的核心竞争力）
- **当前概率**：**中（20-30%）** — 小公司风险更大，头部公司投资能力相对稳定
- **概率依据**：低利率环境下投资难度普遍加大，但头部公司有人才和资源优势
- **时间窗口**：2026-2027
- **影响标的**：投资能力弱的中小公司，需逐一评估头部公司
- **量化阈值**：综合投资收益率 <3% 连续2年
- **应对预案**：
  - 优先选择投资能力强且稳健的公司
  - 关注公司资产配置结构的合理性（不过度集中某一类资产）

### R11: 偿付能力压力

- **风险描述**：部分公司偿付能力充足率逼近监管红线，需通过发债或增资补充资本，可能稀释股东权益
- **风险类别**：公司 — 资本充足
- **触发条件**：核心偿付能力充足率 <120% 或综合偿付能力充足率 <180%
- **前置信号**：①偿付能力报告中的压力测试结果恶化 ②公司发行资本补充债 ③权益市场大幅下跌
- **影响程度**：**中度**（头部公司偿付能力充裕，中小公司风险更大）
- **当前概率**：**低（<15%）** — 5家A股上市保险公司偿付能力均远超监管红线
- **概率依据**：头部公司偿付能力充足率普遍在200%以上
- **时间窗口**：仅当权益市场极端下跌时可能触发
- **影响标的**：5家A股上市保险公司整体风险可控
- **量化阈值**：核心偿付能力充足率环比下降>30个百分点
- **应对预案**：
  - 定期查看偿付能力报告
  - 偿付能力逼近红线的公司回避

## 五、市场行为风险

### R12: 保险股估值修复过快后的回调

- **风险描述**：保险股因利率反弹预期或政策催化快速上涨后，若预期落空可能面临回调
- **风险类别**：市场行为 — 情绪过热/预期落空
- **触发条件**：保险指数2个月内上涨>30%且换手率显著放大
- **前置信号**：①北向资金大额净买入保险股 ②融资余额快速上升 ③卖方集中推保荐
- **影响程度**：**中度**（短期交易性风险，不影响长期价值判断）
- **当前概率**：**低（<15%）** — 当前保险股估值处于历史偏低水平
- **概率依据**：保险板块整体PB和PEV仍在历史中低位
- **时间窗口**：2026年
- **影响标的**：弹性最大的标的（新华保险>中国人寿）回调幅度可能更大
- **应对预案**：
  - 信号初现 → 检查估值是否已脱离合理区间
  - 信号确认 → 减仓高弹性标的，保留核心仓位
  - 风险兑现 → 等待估值回落后再加仓

### R13: 外资/北向资金阶段性流出

- **风险描述**：外资对A/H保险股阶段性减持，导致股价承压
- **风险类别**：市场行为 — 资金流动
- **触发条件**：北向资金连续5个交易日净卖出保险股且单周净卖出>10亿元
- **前置信号**：①美元走强 ②中美关系紧张 ③全球risk-off
- **影响程度**：**轻度**（短期流动性影响，不改变基本面）
- **当前概率**：**中（15-25%）**
- **概率依据**：外资对保险股配置受利率预期影响较大
- **时间窗口**：2026年
- **影响标的**：外资持股比例高的公司（中国平安>中国太保）
- **应对预案**：
  - 外资流出时关注是否伴随基本面恶化
  - 若基本面无变化，外资流出可能是买入机会
