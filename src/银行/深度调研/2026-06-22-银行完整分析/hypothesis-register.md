## 假设列表

### H1: 杭州银行2026全年净利润增速>8%

- **假设内容**：杭州银行2026年全年净利润增速维持在8%以上，证明其资产端稀缺层可持续
- **前提/前置条件**：① 杭州/浙江GDP增速>5%；② 不良率<0.85%；③ 拨备覆盖率>500%
- **验证信号**：中报净利润同比>8% + 不良率环比持平或下降
- **否定信号**：中报净利润同比<5% 或 不良率环比上升>10bp
- **验证窗口**：2026-Q3前（8月中报发布）
- **数据来源**：杭州银行2026年中报
- **验证结果**：pending
- **对优先级的影响**：
  - 证实 → 维持排名第1，PB有望修复至0.9+
  - 证伪 → 降级至第3-4名，可能减仓

### H2: 行业净息差在2026H1触底企稳

- **假设内容**：商业银行整体净息差在2026H1触底（约1.3%），下半年不再恶化
- **前提/前置条件**：① LPR不再下调；② 存款利率继续市场化下行
- **验证信号**：2026H1行业净息差环比持平或回升≥2bp
- **否定信号**：2026H1行业净息差环比下降>5bp
- **验证窗口**：2026-Q3前（银保监数据+中报）
- **数据来源**：银保监季度数据 + 各银行中报
- **验证结果**：pending
- **对优先级的影响**：
  - 证实 → 整体板块优先级上升，城商行估值修复逻辑成立
  - 证伪 → 板块整体降级，仅保留股息率>6%的防御标的

### H3: 江苏银行ROE维持>12%且不良率<0.95%

- **假设内容**：江苏银行2026年全年ROE>12%（远超行业平均），不良率维持<0.95%
- **前提/前置条件**：① 江苏省GDP增速>5%；② 城投化债不要求大幅让利
- **验证信号**：中报ROE年化>12% + 不良率环比持平
- **否定信号**：中报ROE年化<10% 或 不良率>1.0%
- **验证窗口**：2026-Q3前
- **数据来源**：江苏银行2026年中报
- **验证结果**：pending
- **对优先级的影响**：
  - 证实 → 维持排名第2，PB 0.78明显低估
  - 证伪 → 降级，城投让利风险大于预期

### H4: 高股息策略在2026H2不退潮

- **假设内容**：10Y国债收益率维持<2.5%，险资等长期资金持续增配高股息银行
- **前提/前置条件**：① 低利率环境持续；② 无系统性风险事件
- **验证信号**：银行ETF季度净申购>100亿 + 险资持仓占比环比上升
- **否定信号**：银行ETF连续2月净赎回 + 险资减配银行
- **验证窗口**：2026-Q4前
- **数据来源**：基金申赎数据 + 险资持仓季报
- **验证结果**：pending
- **对优先级的影响**：
  - 证实 → 大行持仓信心增强
  - 证伪 → 大行优先级下降，纯高股息逻辑失效

### H5: 城投化债不要求银行大幅让利（展期利率>2.5%）

- **假设内容**：第三轮化债方案对银行相对温和，展期利率>2.5%，不会大幅侵蚀银行息差
- **前提/前置条件**：① 中央财政承担更多化债成本；② 地方财政基本盘未恶化
- **验证信号**：区域行中报息差环比持平（城投展期影响可控）
- **否定信号**：区域行中报息差环比下降>10bp 且 城投贷款展期比例>30%
- **验证窗口**：2026-Q3前
- **数据来源**：各银行中报 + 化债政策文件
- **验证结果**：pending
- **对优先级的影响**：
  - 证实 → 成都/南京银行维持优先级
  - 证伪 → 成都/南京银行降级，城投敞口大的区域行回避
