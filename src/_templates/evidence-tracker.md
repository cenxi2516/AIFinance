# 证据追踪表

> 基于 serenity-skill 的 evidence-ladder 标准。记录每个声称的证据强度。
>
> **核心原则**：所有证据必须来自权威来源。非权威来源仅作线索，不可用于支撑结论。

## 使用说明

- 每行一条声称 + 一个来源
- 来源权威性：**权威（一级）** / **可参考（二级）** / **待核实** / **不可引用**
- 证据等级：**Strong** / **Medium** / **Weak** / **Needs checking**
- 证据状态会演进：`leads` → `checking` → `confirmed` → `outdated`
- **不可引用来源自动标记为 `leads`，永远不得升级到 `confirmed`**
- 权威来源（一级）：交易所公告、年报/季报原文、官方政策文件、招投标公示、海关数据等（详见 `authoritative-sources.md`）

## 红色标志检查

- [ ] thesis 依赖单一客户传闻？（= 不可引用来源）
- [ ] 股价主要由社交媒体推动？（价格 ≠ 证据）
- [ ] 公司需要融资才能兑现收入？
- [ ] 客户未具名，收入影响模糊？
- [ ] 应收/存货增速 > 收入增速？
- [ ] 毛利率未改善却声称稀缺性？
- [ ] 管理层用主题语言但分部数据不变？
- [ ] **任何声称的数据来源为不可引用级别？**
