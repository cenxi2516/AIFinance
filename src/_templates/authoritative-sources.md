> 本文件定义"可引用"vs"可参考"vs"不可引用"的边界。

## 二、可参考来源（二级 — 可交叉验证，不可单独驱动强结论）

| 类型 | 来源示例 | 使用条件 |
|------|---------|---------|
| 券商研报 | 中金、中信、华泰、UBS、Goldman 等 | 必须标注"券商研报"+分析师+日期；假设需可见 |
| 行业白皮书 | 中国半导体行业协会、SEMI、IDC、Gartner | 标注发布机构和日期 |
| 权威新闻媒体 | 路透社、彭博、财新、第一财经、日经 | 标注媒体+日期；区分"报道"和"评论" |
| 公司官网宣传材料 | 产品页面、白皮书 | 标注"公司自述"；公司自述 ≠ 客观事实 |
| 学术论文/会议 | IEEE、OFC、VLSI 等 | 标注论文标题+作者+会议/期刊+日期 |

## 三、不可引用来源（仅作线索，严禁用于支撑结论）

| 类型 | 原因 |
|------|------|
| 社交媒体帖文（微博/雪球/X/Reddit/Discord） | 无法验证身份和动机 |
| 论坛讨论（股吧/淘股吧） | 匿名、无法验证 |
| 微信群/QQ群截图 | 来源不明 |
| KOL/大V言论（除非其身份为可验证的业内人士且陈述事实） | 可能是利益相关方 |
| "据说""传闻""有人透露" | 不可追溯 |
| AI 生成的分析内容（如 ChatGPT 回答） | 可能包含幻觉 |
| 价格走势/技术指标（作为"证据"支撑基本面判断） | 价格不是基本面的证据 |

## 四、非权威信息真实性评估流程

当被迫使用二级来源（可参考）时，必须执行以下评估：

1. **来源身份核实**：发布者是谁？是否有利益关联？（如券商是否正在承销该公司的定增）
2. **数据溯源**：该信息是否可以被一级来源验证？如果能，去查一级来源
3. **多方交叉验证**：同类信息是否被 ≥2 个独立来源报道/确认？
4. **时间敏感性**：该信息是什么时候发布的？是否已经过时？
5. **结论标注**：
   - 通过评估 → 标注"二级来源，已多方交叉验证"
   - 未通过 → 标注"待验证线索，不可支撑结论"

## 五、分析文件中的权威性声明

每个分析文件必须在开头明确标注其数据来源的权威性。格式：

```markdown
## 数据来源权威性声明

- [ ] 本文件所有关键数据来自一级（权威）来源：___ 条
- [ ] 使用了二级（可参考）来源：___ 条（已标注，已交叉验证）
- [ ] 无可引用来源：0 条
- [ ] 本文件不包含任何社交媒体/匿名来源的数据

> 如存在不可引用来源的数据，本文件仅视为草稿，不可交付。
```
