# 机遇注册表

> 风险注册表的配对文件。做完风险映射后，再谈机遇。
> 机遇同样需要条件绑定——"当 A 和 B 同时成立时，机遇 C 可能兑现"。

## 使用说明

- 每条机遇绑定具体的触发条件和前置条件
- 每条机遇标注"如果押注错了，最大的风险是什么"（风险对冲思维）
- 机遇需要分层：宏观机遇 > 中观机遇 > 微观机遇，三层共振时置信度最高

---

## 一、宏观机遇

> 经济周期转向、政策顺风、地缘政治利好、流动性改善。

### O1:

- **机遇描述**：
- **机遇类别**：宏观 — 经济周期 / 政策顺风 / 地缘利好 / 流动性改善
- **触发条件**：（什么具体事件或数据出现，说明这个机遇窗口在打开）
- **前置条件**：（什么必须先成立，这个机遇才可能兑现）
- **当前状态**：前置条件已满足 / 部分满足 / 未满足
- **时间窗口**：（机遇在什么时间范围内可能兑现——考虑物理延迟）
- **影响程度**：变革性 / 重大 / 中等 / 边际
- **当前概率**：高 / 中 / 低
- **受益标的**：（哪些持仓/候选会从这个机遇中获益最大）
- **风险对冲**：（这个机遇如果判断错了，最大的风险是什么）
- **验证路径**：（怎么确认机遇正在兑现而不仅是故事）
