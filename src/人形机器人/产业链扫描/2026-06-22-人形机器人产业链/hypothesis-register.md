# 可验证假设注册表

> 研究质量取决于假设质量。好的假设必须**可证伪**——你知道什么证据出现时会承认它错了。
> 避免"公司前景良好"这种不可证伪的陈述；用"2026Q3 前 XX 产品获得 ≥2 家客户认证"这种可检验的断言。

## 使用说明

- 每条假设必须可被公开数据证伪
- 设定验证窗口时考虑物理延迟（认证 6-18 月、扩产 12-36 月、财务确认 1-2 季）
- 验证结果只有四种：**confirmed**（证实）、**rejected**（证伪）、**partial**（部分成立）、**pending**（待验证）

### H1: 2027年底前至少1家人形机器人厂商实现千台级部署

- **假设内容**：到2027年12月，至少有1家人形机器人厂商（特斯拉/Figure/国内厂商）实现年度部署量≥1000台
- **前提/前置条件**：AI大模型在机器人控制上的应用取得突破 + 关节模组成本降至可接受水平
- **验证信号**：厂商官方公告年度交付/部署数量≥1000台
- **否定信号**：2027年Q3仍无任何厂商宣布千台级部署 + 厂商推迟量产时间表
- **验证窗口**：2027-Q4前
- **数据来源**：厂商公告、行业研报
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 所有人形机器人相关标的前置条件确认，优先级上调
  - 证伪 → 整个投资主题需重新评估，可能降级为远期观察

### H2: 国产行星滚柱丝杠在2027年底前通过≥1家人形机器人客户认证

- **假设内容**：鼎智科技或贝斯特的国产行星滚柱丝杠在2027年底前通过至少1家人形机器人整机厂的认证
- **前提/前置条件**：国产丝杠C5级精度+批量一致性达标 + 客户愿意给国产方案验证窗口
- **验证信号**：公司在年报/中报中披露"人形机器人客户认证通过"或"小批量供货"
- **否定信号**：公司连续2次送样未通过验证 + 客户转向进口方案
- **验证窗口**：2027-Q4前
- **数据来源**：鼎智科技/贝斯特年报、投资者关系公告
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 鼎智科技/贝斯特优先级大幅上调，丝杠国产替代逻辑确认
  - 证伪 → 丝杠相关标的降级，国产化逻辑延后2-3年

### H3: 灵巧手技术路线在2027年底前出现收敛趋势

- **假设内容**：到2027年底，腱绳驱动或电机直驱方案中至少有一条获得≥3家人形机器人头部厂商采用，路线出现收敛趋势
- **前提/前置条件**：头部厂商完成至少1轮迭代 + 方案对比有明确结论
- **验证信号**：≥3家头部厂商在新产品中采用相同技术路线
- **否定信号**：头部厂商仍在两条路线间反复切换 + 无收敛迹象
- **验证窗口**：2027-Q4前
- **数据来源**：厂商产品发布会、学术论文、专利
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 确认路线的零部件厂商优先级上调；被排除路线的零部件厂商降级
  - 证伪 → 灵巧手相关投资维持低配，等待收敛信号

### H4: 绿的谐波在2027年底前人形机器人相关收入占比>5%

- **假设内容**：绿的谐波的人形机器人相关收入（减速器+模组）在2027年占总收入比例>5%
- **前提/前置条件**：人形机器人量产启动 + 绿的谐波通过头部客户验证
- **验证信号**：年报中披露人形机器人相关收入>0.5亿元
- **否定信号**：2027年中报仍无人形机器人相关收入披露
- **验证窗口**：2027-Q4前
- **数据来源**：绿的谐波年报/中报
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 绿的谐波作为最确定的零部件标的，优先级上调
  - 证伪 → 绿的谐波降级，说明人形机器人量产推迟或HD垄断未松动

### H5: 人形机器人单台BOM成本在2028年底前降至<10万元

- **假设内容**：人形机器人单台BOM成本从当前的15-25万元降至10万元以下
- **前提/前置条件**：千台级量产 + 核心零部件国产替代取得进展
- **验证信号**：头部厂商公开披露成本下降至目标水平 + 国产零部件批量上车
- **否定信号**：2028年仍停留在15万+水平 + 国产替代未实质推进
- **验证窗口**：2028-Q4前
- **数据来源**：厂商公告、拆解报告
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 成本曲线确认，市场需求弹性释放，所有标的上调
  - 证伪 → 成本无法下降意味着无法走出示范阶段，整个主题降级

## 补充假设

### H6: 2026年底前A股人形机器人概念板块经历≥20%估值回调

- **假设内容**：由于业绩无法兑现预期，人形机器人概念股在2026年底前经历≥20%的估值回调
- **前提/前置条件**：中报/三季报人形机器人收入贡献极低 + 无新催化剂
- **验证信号**：板块指数从高点回落≥20% + 核心标的PE从高位回落
- **否定信号**：有重大催化剂（如特斯拉大规模部署）推动估值继续扩张
- **验证窗口**：2026-Q4前
- **数据来源**：行情数据
- **验证结果**：pending
- **对优先级的影响**：
  - 证实 → 回调后是更好的入场时机，等待估值合理再介入
  - 证伪 → 说明市场对人形机器人预期仍在升温，需警惕泡沫化
