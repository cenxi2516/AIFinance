## 🏰 公司一：航天电子（600879）—— 火箭测控 + 星载电子多环节垄断

### 一、产业链位置
- **所处环节**：**火箭 GNC 系统 + 遥测遥控 + 星载电子 + 星间激光通信终端**。覆盖火箭和卫星两大核心环节。
- **是否必经之路**：✅ **是**。火箭箭载计算机是火箭"大脑"，市占率 75%；遥测遥控是火箭"神经系统"，市占率 90%+。没有这两个系统，火箭无法发射。
- **议价权判断**：强。航天九院平台，军用火箭配套近乎垄断。航天机电组件毛利率 37%，激光通信终端市占率约 60%，商业订单占比提升至 ~35%。

### 二、稀缺性评估（5 类壁垒）

| 壁垒类型 | 评分(1-5) | 依据 |
|---------|----------|------|
| **技术壁垒** | **5** | 航天九院（中国航天电子技术研究院）唯一上市平台。箭载计算机 + 遥测遥控 + 星载电子 + 激光通信全链条自主可控。10Gbps 星间激光终端已批产准备 |
| **认证壁垒** | **5** | 国家航天核心配套，长征系列火箭数十年飞行验证。军工准入 + 宇航级认证齐全 |
| **规模壁垒** | **4** | 营收 139 亿元，存货 225 亿（历史极值）。大规模制造和交付能力已得到验证 |
| **客户粘性** | **5** | 长征系列火箭唯一配套商。商业火箭（星际荣耀等）也已切入。一旦进入 GNC 系统供应，客户不可能更换——切换等于重新设计火箭 |
| **政策壁垒** | **5** | 航天九院上市平台，国家航天核心资产。航天电子技术领域天然垄断 |
| **综合评分** | **4.80/5** | = 5×0.30 + 5×0.20 + 4×0.25 + 5×0.15 + 5×0.10 = 4.80 |

### 三、供需关系验证

| 证据类型 | 状态 | 具体数据 |
|---------|------|---------|
| **订单/合同负债** | 🟢 | 2025Q3 合同负债 19.6 亿元（较年初+3.5%，环比 H1 大增 9.5 亿）。存货 225 亿元（历史极值）。近 3 年商业航天累计合同超 6 亿元 |
| **产能利用率** | 🟢 | 存货达历史极值，公司在积极备产备货。前期迟滞订单 2025 年陆续恢复交付 |

### 四、不可替代性评级
**评级：A 级（高度稀缺，接近 S 级）**

- **供应商数量**：火箭测控/遥测领域，国内**唯一**大规模供应商。商业航天几乎没有替代选择。
- **替代方案成熟度**：无。长征系列数十年验证，切换供应商等于重新设计火箭。
- **客户切换成本估算**：极其高昂。GNC 系统切换 = 火箭重新设计 + 数年飞行验证。客户**绝不可能**切换。
- **判定依据**：供应商数量 =1（垄断），切换成本极高，合同负债 + 存货历史极值验证需求。扣分项：整体毛利率偏低（20%），2025 年净利降 58% → A 级（非 S 级因为盈利能力不够强）

| **客户自研** | ✅ **已排除** | 民营火箭公司不可能自研 GNC 系统。即使蓝箭自研发动机，GNC 仍需外部供应 | — |
| **产能过剩** | ✅ **已排除** | 需求远大于供给，存货历史极值反映的是交付压力而非过剩 | — |

**附加风险**：应收账款 110 亿元（较年初+40%），航天领域结算周期偏长。系统装备毛利率大幅下滑。

### 六、总结
- **核心壁垒一句话**：火箭 GNC + 遥测领域近乎 100% 垄断，客户无法替代——没有航天电子，中国火箭飞不起来。
- **最关键的一个验证点**：2026 年营收能否达公司目标 154.92 亿元（+14.6%），净利能否重回增长。
- **最大的一个风险点**：应收账款高企 + 系统装备毛利率恶化。
- **建议下次验证时机**：2026 年半年报（8 月），验证商业航天订单占比提升 + 激光通信终端批产放量。

## 🏰 公司三：西部材料（002149）—— 铌钨合金全球寡头

### 一、产业链位置
- **所处环节**：火箭发动机核心热端材料 → 铌钨合金（Nb521）/铌铪合金（C103）。用于燃烧室、喷管、推力室等承受 2200℃+ 高温的部件。
- **是否必经之路**：✅ **是**。液体火箭发动机热端部件必须使用铌基高温合金，无可替代材料。铌钨合金是双组元液体火箭发动机推力室的"黄金标准"材料。
- **议价权判断**：极强。全球仅 3 家量产（西部材料 + 美国 Carpenter + 英国 Teledyne），国内市占率 70-80%。航天材料毛利率 45-53%。SpaceX 在中国大陆**唯一**合规铌合金供应商。

### 二、稀缺性评估（5 类壁垒）

| 壁垒类型 | 评分(1-5) | 依据 |
|---------|----------|------|
| **技术壁垒** | **5** | 全球仅 3 家能量产铌钨合金。NASA + SpaceX 双重认证（认证周期约 2.5 年，300+ 参数验证）。材料配方 + 真空自耗熔炼 + 锻造工艺，know-how 积累数十年 |
| **认证壁垒** | **5** | 军工认证 5-10 年。SpaceX 认证是"黄金门票"——全球仅个位数材料企业通过。国内蓝箭、星河动力等均需通过认证才能使用 |

| **客户粘性** | **5** | SpaceX 核心供应链（占其铌合金供应链 70%+），蓝箭/星河动力/长征系列均为客户。一旦进入发动机材料供应体系，更换供应商 = 重新做全部飞行验证 |
| **政策壁垒** | **3** | 无特殊牌照限制，但出口管制（铌合金属于两用物项）为国内供应商提供天然保护 |
| **综合评分** | **4.55/5** | = 5×0.30 + 5×0.20 + 4×0.25 + 5×0.15 + 3×0.10 = 4.55 |

| **客户自研** | ✅ **已排除** | 火箭公司/发动机公司不可能自研特种冶金材料 | — |
| **产能过剩** | ⚠️ **需跟踪** | 钛合金二期扩产 4000 吨，若需求衔接不畅可能产能闲置 | 钛合金产能利用率 < 50% |

**风险交互分析**：最大风险是"传统钛制品继续恶化 + 航天订单交付延迟"，但航天材料壁垒本身极为稳固。2026Q1 营收-20%、净利-71% 是短期逆风。

### 六、总结
- **核心壁垒一句话**：全球仅 3 家能量产铌钨合金，SpaceX 中国唯一供应商，国内火箭发动机铌合金市占 70%+，认证壁垒 5-10 年。
- **最关键的一个验证点**：2026 年航天材料收入能否对冲到传统钛制品的下滑（验证"航天材料放量 > 传统业务萎缩"）。
- **最大的一个风险点**：传统钛制品毛利率持续恶化 + 短期业绩与高估值严重背离（PE 一度 ~420 倍）。
- **建议下次验证时机**：2026 年半年报（8 月），验证航天材料毛利率趋势 + 铌合金扩产进度 + SpaceX 订单持续性。

## 🏰 公司四：中国卫星（600118）—— 卫星制造国家队唯一平台

### 一、产业链位置
- **所处环节**：卫星总体制造（小卫星/微小卫星平台总装集成）

- **议价权判断**：弱。整星总装毛利率仅 5-8%，赚的是"辛苦钱"。卫星产业利润向上游载荷（T/R 芯片、星敏感器）集中，总装环节利润最薄。

### 二、稀缺性评估（5 类壁垒）

### 四、不可替代性评级
**评级：B 级（有明显壁垒，但利润结构性薄弱）**

- **供应商数量**：国家重大工程卫星 =1（航天五院/中国卫星），商业卫星 = 多家竞争
- **替代方案成熟度**：国家工程领域无法替代；商业卫星领域，长光卫星/微纳星空等民企正在抢占份额
- **客户切换成本估算**：国家工程不存在"切换"问题。商业市场切换成本低
- **判定依据**：国家队垄断 + 300 亿在手订单，但 5-8% 毛利率结构性薄利 + 商业卫星领域竞争加剧 → B 级

**附加风险**：整星总装利润率极薄（5-8%），"载荷为王"趋势下利润持续向上游转移。

- **核心壁垒一句话**：国家队卫星制造唯一上市平台，GW 星座核心供应商，在手订单 300 亿+。但壁垒不等于利润——毛利率只有 5-8%。
- **最关键的一个验证点**：海南超级工厂投产后，毛利率能否通过规模效应提升至 10%+。
- **最大的一个风险点**：结构性薄利——卫星产业"载荷为王"，总装赚的是辛苦钱。
- **建议下次验证时机**：2026 年年报（2027 年 4 月），验证海南工厂投产后的毛利率变化。

## 🏰 公司五：航天动力（600343）—— 液体发动机平台，但正在被替代

## 三个关键判断

### 判断一：航天电子是最接近 S 级的标的
火箭 GNC + 遥测领域近乎 100% 垄断，没有航天电子，中国火箭飞不起来。这种"基础设施"级别的不可替代性，在主板商业航天中独一无二。扣分项是整体毛利率偏低（20%），但这与"垄断但利润薄"的国家队体制特点一致。

### 判断二：铖昌科技是最"纯"的商业航天标的
4 类供需证据全部正向，毛利率 82% 且仍在攀升。T/R 芯片需求与卫星发射量呈线性关系——千帆从 162 颗→324 颗→最终万颗，铖昌是最确定的需求放大器。但 *ST 状态是一个真实风险。

### 判断三：西部材料拥有最深的护城河，但需要耐心
全球仅 3 家量产铌钨合金 + SpaceX 认证，这是任何竞争对手都无法在 5 年内复制的壁垒。但 2025-2026 年短期业绩逆风（传统钛制品恶化），航天材料的放量需要时间验证。PE ~420 倍意味着市场已经给出了很高的预期。
