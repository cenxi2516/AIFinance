# 商业航天全球竞争格局

> 中国商业航天的投资逻辑必须放在全球竞争格局下审视。核心差距不在"能不能造火箭"，而在可复用技术、发射频次、星座运营和制度基础设施。

**分析日期**：2026-06-23
**数据来源**：Wikipedia/WebSearch 验证数据 + 行业公开信息

## 二、SpaceX 飞轮模型——中国的参照系

### SpaceX 的正反馈飞轮

```
可回收技术成功 → 发射成本下降60-70%
    → 高频发射能力（130+次/年）
    → Starlink大规模组网（7,000+颗在轨）
    → 用户增长（400万+）+ 收入增长（~77亿美元/年）
    → 收入反哺研发 → 技术迭代加速（Starship/Falcon 9升级）
    → 发射成本进一步下降 → 飞轮加速
```

### 中国飞轮：尚未启动任何一个环节

```
可回收技术 → ❌ 0次成功回收
高频发射 → ❌ 工位不足，年极限~20次
星座组网 → ❌ 完成率16.7%
用户增长 → ❌ 服务覆盖不足
收入增长 → ❌ 下游零收入
技术迭代 → ❌ 验证失败拖慢迭代
```

**核心洞察**：SpaceX 的飞轮已进入自加速阶段，中国的飞轮还卡在"第一推力"上。投资中国商业航天的核心问题是：**谁能提供这个"第一推力"？** 目前看，答案可能是"发射工位扩建 + 可回收突破"的组合，但这两者都需要2-3年时间。

### 同质化问题

- **运力范围重叠严重**：5家公司都在1-6吨级近地轨道运力区间
- **可回收路线重叠**：至少5家同时开发可回收中大型火箭
- **市场容量不足**：2025年商业火箭仅约20次发射，远不足以支撑10+家公司存活
- **淘汰出清预期**：3-5年内至少5家将退出或被并购，2027-2028年融资冰点期

### 关键数据

- LC-2 设计可适配：9家公司的19种火箭型号
- 但适配≠能发射：每种新火箭需单独审批+验证，实际发射频次受限
- 对比 SpaceX：Falcon 9 单个工位可支持每周1次发射（年50+次），效率差距巨大

## 八、投资启示

1. **SpaceX 的飞轮是"已验证的未来"，中国商业航天是"未验证的叙事"**。投资逻辑完全不同——前者是"增长能持续多久"，后者是"飞轮能否启动"。

2. **中国追赶 SpaceX 的核心瓶颈不在技术，在基础设施和制度**。技术差距可以通过投入缩小，但发射场建设和监管框架完善需要时间。

3. **2-3年内中国商业航天不会有"SpaceX时刻"**。即使朱雀三号2026年成功回收，从1次成功到稳定运营还需要2-3年验证。投资节奏应匹配物理现实，而非市场叙事。

4. **A股投资应聚焦"控制稀缺层"的标的**，而非"故事最大"的概念股。航天级元器件和特种材料是目前确定性最高的方向。

5. **关注"第一推力"的验证节点**：朱雀三号回收成功 + 文昌二期开工 = 飞轮可能启动的信号。
