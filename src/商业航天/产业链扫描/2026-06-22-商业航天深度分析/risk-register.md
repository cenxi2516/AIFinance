## R1: 宏观风险

### R1.1 中国经济下行压制政府/企业航天预算

| 维度 | 内容 |
|------|------|
| 风险描述 | 经济增速放缓导致地方财政吃紧，商业航天作为"新质生产力"虽获政策支持，但实际预算分配可能不及预期；企业端 Capex 收缩影响卫星采购 |
| 触发条件 | GDP 增速低于 4.5%，地方财政赤字率持续上升，卫星互联网项目招标延迟或缩减 |
| 前置信号 | 国网/千帆星座招标频次下降、中标价格下行、地方商业航天产业园烂尾 |
| 影响程度 | 中度 |
| 当前概率 | 30%（2026H1 经济弱复苏，但航天属战略方向预算相对刚性） |
| 依据 | 二级来源：政策文件+行业观察 |

### R1.2 流动性风险：A 股市场整体流动性收缩

| 维度 | 内容 |
|------|------|
| 风险描述 | 如果市场整体进入存量博弈或减量博弈，商业航天等概念板块因估值偏高、业绩兑现弱，首当其冲被抛售 |
| 触发条件 | A 股日均成交额持续低于 7000 亿，外资持续净流出 |
| 前置信号 | 北向资金连续 5 日净流出超 200 亿、融资余额快速下降 |
| 影响程度 | 中度 |
| 当前概率 | 25% |
| 依据 | 二级来源：市场数据观察 |

## R2: 政策与监管风险

### R2.1 航天法缺位，监管框架滞后（★ 重点关注）

| 维度 | 内容 |
|------|------|
| 风险描述 | 中国尚无《航天法》，发射许可、频率申请、安全监管分散在国防科工局/工信部/民航局/军委装发部等多部门，审批链条长（单次发射审批 3-6 个月），协调成本高 |
| 触发条件 | 发生重大安全事故后监管急速收紧（参照 2024 年巩义事故后的安全整顿） |
| 前置信号 | 行业安全专项整治通知、审批周期明显拉长、小型企业因合规成本上升退出 |
| 影响程度 | 重度（监管收紧可能直接扼杀小型企业） |
| 当前概率 | 35%（政策鼓励期，但安全事故频率上升，收紧只是时间问题） |
| 依据 | 一级来源：政策文件、审批流程公开信息 |

### R2.2 第三者责任赔偿法律空白

| 维度 | 内容 |
|------|------|
| 风险描述 | 中国尚无明确的航天发射第三者责任赔偿上限立法，2024 年巩义事故暴露了这一法律空白。商业发射事故的民事赔偿框架不清，增加企业运营不确定性 |
| 触发条件 | 发生发射事故造成地面人员/财产损害 |
| 前置信号 | 保险费率上升、企业主动购买超额责任险 |
| 影响程度 | 中度 |
| 当前概率 | 20%（事故概率虽上升，但地面伤亡概率仍低） |
| 依据 | 一级来源：事故调查报告 |

### R2.3 政策鼓励期 → 规范化收紧的拐点

| 维度 | 内容 |
|------|------|
| 风险描述 | 2024 年政府工作报告首次将商业航天列入新质生产力，当前处于政策红利期。但鼓励期不等于放松监管——当行业规模做大，安全事故频率上升，监管收紧是必然方向 |
| 触发条件 | 年度商业发射事故 ≥ 3 次，或出现人员伤亡事故 |
| 前置信号 | 监管部门发布安全专项检查、行业准入门槛提高 |
| 影响程度 | 重度 |
| 当前概率 | 40%（2026 年上半年失败率已升至 7%，趋势恶化） |
| 依据 | 一级来源：发射统计数据 |

## R3: 产业链风险

### R3.1 发射工位严重不足（★ 重点关注）

| 维度 | 内容 |
|------|------|
| 风险描述 | 文昌商业场LC-1（2023.12建成）+LC-2（2024.11首飞），2025年完成17次发射已接近满负荷；千帆星座/国网星座进入高频发射阶段后，每年需 30-50 次发射，现有工位根本不够。对比 SpaceX 2025 年 130+ 次发射，基础设施差距巨大 |
| 触发条件 | 千帆星座/国网星座宣布加速组网但发射排期无法匹配 |
| 前置信号 | 发射场扩建公告、发射窗口排队时间延长、企业被迫赴海外发射 |
| 影响程度 | 颠覆（直接制约星座组网进度，影响整个产业链商业闭环） |
| 当前概率 | 70%（已是现实瓶颈，不是"可能发生"而是"已经发生"） |
| 物理约束 | 发射场建设周期 2-3 年，无法短期解决 |
| 依据 | 一级来源：文昌发射场公开数据、千帆星座组网进度 |

### R3.2 高端元器件依赖进口，受美国出口管制（★ 重点关注）

| 维度 | 内容 |
|------|------|
| 风险描述 | 卫星用抗辐射 FPGA、高端 AD/DA 转换器、星载计算机核心芯片依赖进口，受 ITAR 禁令和 BIS 实体清单双重制约。国产替代仍需 3-5 年验证周期 |
| 触发条件 | 美国进一步扩大管制范围（将管制扩展到含美国 IP 的第三国产品） |
| 前置信号 | 新增 BIS 清单实体、国产芯片验证公告、卫星型号因缺料延迟交付 |
| 影响程度 | 重度 |
| 当前概率 | 50%（结构性硬约束，不会因谈判而改变） |
| 物理约束 | 航天级芯片认证周期 3-5 年 |
| 依据 | 一级来源：ITAR 法规、BIS 清单 |

### R3.3 火箭发动机批量生产良率待验证

| 维度 | 内容 |
|------|------|
| 风险描述 | 液氧甲烷发动机（朱雀三号/天龙三号）仍处验证早期，批量生产良率和可靠性未经验证。2025 年 12 月朱雀三号一级回收失败、2026 年 4 月天龙三号首飞失败，均暴露技术成熟度不足 |
| 触发条件 | 可回收火箭连续 2 次以上回收失败，或批产型号飞行失败率 > 10% |
| 前置信号 | 发动机试车数据异常、发射推迟、技术方案重大修改 |
| 影响程度 | 重度（可回收是降低发射成本的关键，失败直接影响商业模型） |
| 当前概率 | 45%（近期失败率数据不乐观） |
| 物理约束 | 发动机可靠性需 10+ 次成功飞行验证 |
| 依据 | 一级来源：发射记录、公司公告 |

### R3.4 千帆星座组网进度严重滞后

| 维度 | 内容 |
|------|------|
| 风险描述 | 千帆星座计划 2025 年底前部署 648 颗卫星，实际仅部署 108 颗（完成率 16.7%）。组网进度严重滞后 → 下游应用无法落地 → 整个产业链商业闭环无法形成 |
| 触发条件 | 2026 年底累计部署仍低于 300 颗 |
| 前置信号 | 发射频次未提升、卫星招标缩减 |
| 影响程度 | 颠覆（星座延期 = 产业链失去终端需求验证） |
| 当前概率 | 55%（当前进度大幅落后，短期内难以追赶） |
| 物理约束 | 卫星制造+发射+在轨验证周期 18-24 个月 |
| 依据 | 一级来源：千帆星座官方数据 |

## R4: 公司层面风险

### R4.1 A 股概念股估值泡沫，商业航天收入占比极低（★ 重点关注）

| 维度 | 内容 |
|------|------|
| 风险描述 | 多数 A 股商业航天概念股 PE 在 80-150 倍区间，部分亏损公司无法用 PE 衡量（如航天宏图 2024 年亏损面临 ST 风险）。更关键的是，多数概念股的实际商业航天收入占比 < 10%，属于"概念搭车"而非实质受益 |
| 触发条件 | 概念炒作退潮，市场回归基本面定价 |
| 前置信号 | 龙虎榜游资撤离、融资余额下降、分析师下调评级 |
| 影响程度 | 重度（戴维斯双杀：估值压缩 + 业绩不及预期） |
| 当前概率 | 60%（概念退潮只是时间问题） |
| 量化阈值 | 商业航天收入占比 < 15% 的公司，估值下行空间 > 50% |
| 依据 | 一级来源：年报/季报数据 |

### R4.2 火箭公司过多，同质化严重

|------|------|

## 风险交互分析

**最危险的组合（2 个以上风险同时兑现）**：

| 组合 | 场景 | 综合影响 |
|------|------|---------|
| **R3.1 + R3.4** | 发射工位不足 + 星座组网延期 | **致命组合**：工位不够 → 发射跟不上 → 星座延期 → 下游无法验证 → 全产业链商业闭环断裂 |
| **R4.1 + R5.1** | 估值泡沫 + 概念退潮踩踏 | **戴维斯双杀**：估值 80-150x 回归 30-40x，叠加业绩不及预期，下行空间 50-70% |
| **R3.3 + R2.3** | 火箭连续失败 + 监管收紧 | **恶性循环**：事故频发 → 监管收紧审批 → 发射更少 → 验证更慢 → 更多事故 |
| **R3.2 + R4.2** | 元器件断供 + 资本退潮 | 小型火箭公司资金链断裂，且无力投入国产替代研发 |

## 当前风险定级

- 2 个颠覆级风险已现实发生（发射工位不足、星座组网滞后）

**仓位参考**：
- 高风险环境 → 严格控制总仓位 ≤ 15%
- 仅在出现明确风险释放信号后逐步加仓
- 优先选择商业航天收入占比高、有实质订单的公司
