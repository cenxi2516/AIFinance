## 二、核心情景推演

### 情景 A：基准情景（概率 ~40%）

**假设**：千帆星座2026年底组网至200-300颗（低于原计划但仍推进），可回收火箭继续测试但未实现稳定回收，发射工位建设按规划推进，政策环境维持鼓励+适度监管

**产业链演变**：
- 发射频率从当前约20次/年提升至25-30次/年（缓慢改善）
- 千帆星座组网进度改善但仍落后计划1-2年
- 可回收火箭技术验证继续，但商业运营尚早
- 元器件国产替代按预期推进（地面验证中）
- A股概念股分化：有实质订单的公司估值回归合理，纯概念股估值压缩

**各标的参考区间**（基于当前估值中枢±15-20%）：

| 标的 | 参考区间逻辑 | 估值回归方向 |
|------|------------|------------|
| 航天电器 | PE回归28-35x，业绩稳健增长消化估值 | 中性偏正 |
| 鸿远电子 | PE回归22-30x，军品周期触底后恢复 | 中性偏正 |
| 西部超导 | PE回归32-42x，新材料认证推动 | 中性 |
| 上海瀚讯 | PE从60-80x压缩至40-60x，增速不及预期 | 中性偏负 |
| 振华科技 | PE回归22-30x，稳增长 | 中性 |
| 臻镭科技 | PE维持60-90x，验证期无业绩支撑 | 中性偏负 |
| 中科星图 | PE回归40-55x，商业化进展缓慢 | 中性偏负 |

**触发条件**（判断基准情景成立）：
1. 千帆星座2026年全年发射5-8次（月均0.5-0.7次）
2. 朱雀三号/天龙三号继续测试但无连续成功回收
3. 文昌二期按期开工
4. 无重大安全事故触发监管急速收紧

### 情景 B：乐观情景（概率 ~20%）

**假设**：可回收火箭取得突破（连续2次+成功回收），千帆星座组网加速至2026年底300-400颗，发射工位扩建超预期推进，元器件国产替代取得在轨验证里程碑

**产业链演变**：
- 发射频率提升至35-40次/年
- 可回收火箭成功 → 发射成本下降预期 → 星座组网经济可行性确认
- 下游应用开始产生初步收入（遥感/通信）
- 市场对商业航天从"概念"重新定价为"成长"

**各标的参考区间**：

| 标的 | 参考区间逻辑 | 估值方向 |
|------|------------|---------|
| 航天电器 | PE扩张至35-45x，商业航天订单放量 | 正向 |
| 鸿远电子 | PE扩张至28-38x，军品+航天双轮驱动 | 正向 |
| 西部超导 | PE扩张至40-50x，材料需求爆发 | 正向 |
| 上海瀚讯 | PE维持60-80x，千帆订单高增支撑 | 正向 |
| 振华科技 | PE扩张至28-35x | 正向 |
| 臻镭科技 | PE维持80-100x，在轨验证通过催化 | 正向 |
| 中科星图 | PE扩张至55-70x，数据变现开始 | 正向 |

**触发条件**：
1. 朱雀三号或天龙三号连续2次+成功回收
2. 千帆星座2026年发射10次以上
3. 千帆在轨卫星超200颗
4. 国产星载芯片首次在轨验证公告

### 情景 C：悲观情景（概率 ~30%）

**假设**：可回收火箭再次失败，千帆星座组网停滞（2026年底仍低于200颗），发射工位建设延迟，概念退潮踩踏

**产业链演变**：
- 发射频率停滞在15-20次/年
- 星座组网无法形成最低可用星座，下游应用无法落地
- A股概念股戴维斯双杀（估值压缩+业绩不及预期）
- 资本退潮，小型火箭公司开始倒闭

**各标的参考区间**：

| 标的 | 参考区间逻辑 | 估值方向 |
|------|------------|---------|
| 航天电器 | PE压缩至20-28x，但军品基本盘支撑 | 中性偏负 |
| 鸿远电子 | PE压缩至15-22x，军品周期下行+航天退潮 | 负向 |
| 西部超导 | PE压缩至25-32x，需求下降 | 负向 |
| 上海瀚讯 | PE压缩至30-45x，千帆订单不及预期 | 强负向 |
| 振华科技 | PE压缩至18-25x | 负向 |
| 臻镭科技 | PE压缩至40-60x，验证失败 | 强负向 |
| 中科星图 | PE压缩至25-40x，变现困难证明 | 强负向 |

**触发条件**：
1. 朱雀三号/天龙三号再次失败
2. 千帆2026年全年发射<3次
3. 文昌二期建设推迟1年以上
4. 发生重大安全事故触发监管急速收紧
5. A股商业航天板块龙头公司季报营收同比下降>20%

### 情景 D：极端风险情景（概率 ~10%）

**假设**：中美冲突升级导致航天领域全面脱钩 + 国内安全事故频发触发监管冰冻 + 资本市场流动性危机

**触发条件**：
1. BIS将航天相关公司全部列入实体清单
2. 年度商业发射事故≥5次或出现人员伤亡
3. A股日均成交额持续低于7000亿
4. 外资连续5日净流出超200亿

**参考动作**：无条件收缩敞口至≤5%，仅保留航天电器等军品基本盘最稳固的标的，等待风险释放后重新评估

## 五、仓位参考框架

> 以下为研究框架建议的仓位思路，非具体仓位指令。

- **总仓位态度**：高风险环境 → 严格控制总仓位 ≤ 15%
- **组合内部配比**：
  - 核心仓位（航天电器+鸿远电子+西部超导）：8%
  - 稀缺层仓位（铖昌科技+臻镭科技）：3-5%
  - 卫星仓位（上海瀚讯+振华科技+斯瑞新材）：2-3%
  - 观察仓位（中科星图+中国卫星）：0%（概念搭车风险大）
- **单标的集中度上限**：不超过总敞口的5%
- **现金预留**：85%+（高风险环境下保持大量现金等待机会）

**加仓参考条件**（从15%提升至25%需满足）：
1. 可回收火箭实现连续2次+成功回收
2. 千帆星座年发射频次≥10次
3. 文昌二期按期开工
