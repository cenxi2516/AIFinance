## 假设列表

### H1: 千帆星座2026年底在轨卫星数将达200-300颗

- **假设内容**：千帆星座2026年底在轨卫星从当前108颗提升至200-300颗，组网进度虽落后计划但持续改善
- **前提/前置条件**：发射工位可用、火箭运力充足、卫星产线产能释放
- **验证信号**：千帆发射频次≥月均1次（2026H2）、单次发射卫星数≥18颗
- **否定信号**：千帆2026年全年发射<3次，或连续3个月无发射
- **验证窗口**：2026-Q4前
- **数据来源**：千帆星座官方公告、文昌发射场公开数据
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 全产业链优先级上升，尤其是上海瀚讯（载荷供应商）和航天电器
  - 证伪 → 全产业链优先级下降，仅保留军品基本盘标的

### H2: 中国将在2027-2028年实现可回收火箭稳定回收

- **假设内容**：蓝箭航天或天兵科技将在2027-2028年实现一级火箭连续3次以上成功回收
- **前提/前置条件**：发动机可靠性验证完成 + VTVL控制算法稳定 + 回收着陆系统验证
- **验证信号**：朱雀三号2026年下半年完成首次成功回收
- **否定信号**：朱雀三号+天龙三号2026年全年回收测试均失败
- **验证窗口**：2027-Q4前
- **数据来源**：蓝箭/天兵官方公告、发射实况报道
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 发射成本降本逻辑成立，星座组网经济可行性确认，全产业链重估
  - 证伪 → 星座组网只能依赖一次性火箭，成本无法下降，O4机遇推迟至2029+

### H3: 航天电器2026年商业航天收入占比将提升至12%+

- **假设内容**：航天电器商业航天收入占比从当前<10%提升至12%+，毛利率从35-38%提升至38%+
- **前提/前置条件**：千帆星座组网加速 + 商业火箭发射频次提升
- **验证信号**：2026年中报/三季报中商业航天收入同比增长>30%，合同负债环比增长>15%
- **否定信号**：商业航天收入占比仍<8%，合同负债持平或下降
- **验证窗口**：2026-Q3前（中报验证）
- **数据来源**：航天电器2026年中报/三季报
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 航天电器排名巩固为#1，可适度加仓
  - 证伪 → 商业航天对航天电器的弹性低于预期，排名可能被鸿远电子超越

### H4: 文昌二期将于2027年底前首个工位投用

- **假设内容**：文昌商业发射场二期建设按规划推进，2027年底前首个工位投入使用
- **前提/前置条件**：建设资金到位 + 环评/能评通过 + 设施建设完成
- **验证信号**：2026年内文昌二期开工公告发布
- **否定信号**：2026年全年无开工公告，或环评/能评未通过
- **验证窗口**：2026-Q4前（开工信号）
- **数据来源**：文昌国际航天城官方公告、环评公示
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 发射基础设施瓶颈有解，O5机遇概率上升
  - 证伪 → R3.1风险加剧，全产业链节奏推迟1-2年

### H5: A股商业航天概念股将在2026H2-2027H1经历估值压缩30-50%

- **假设内容**：商业航天概念股（中国卫星、航天宏图等）将在概念退潮后经历估值压缩30-50%
- **前提/前置条件**：星座组网持续滞后 + 业绩不及预期 + 市场回归基本面定价
- **验证信号**：概念股PE从80-150x压缩至40-60x，商业航天板块成交额占比持续下降
- **否定信号**：板块PE维持高位，概念炒作持续
- **验证窗口**：2027-Q1前
- **数据来源**：行情数据、板块成交额、估值分位
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 远离概念股，专注有实质订单的元器件/材料公司
  - 证伪 → 概念股仍有资金支撑，但需警惕泡沫风险

### H6: 航天级国产芯片将在2027-2028年完成首次在轨验证

- **假设内容**：紫光国微抗辐射FPGA或臻镭科技AD/DA转换器将在2027-2028年完成首次在轨验证
- **前提/前置条件**：芯片设计完成 + 流片成功 + 地面验证通过 + 卫星型号搭载
- **验证信号**：卫星型号公告采用国产芯片、紫光国微/臻镭科技年报披露航天客户认证进展
- **否定信号**：2027年底仍无任何卫星型号搭载国产芯片的公告
- **验证窗口**：2028-Q2前
- **数据来源**：公司年报/公告、卫星型号公开信息
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 紫光国微/臻镭科技排名大幅上升，O2机遇概率上升
  - 证伪 → 元器件国产替代逻辑推迟，短期无法贡献收入

### H7: 铖昌科技 T/R 芯片将获千帆/国网星座批量订单

- **假设内容**：铖昌科技相控阵 T/R 芯片将在 2026Q4-2027H1 获得千帆/国网星座的批量采购订单
- **前提/前置条件**：千帆/国网星座进入批量制造阶段 + 铖昌产品通过客户验证
- **验证信号**：合同负债环比增长 > 30%、年报中航天业务收入占比提升至 25%+
- **否定信号**：合同负债持平或下降、卫星制造商宣布自研 T/R 芯片
- **验证窗口**：2027-Q2前
- **数据来源**：铖昌科技年报/中报、合同负债数据、客户公告
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 铖昌科技排名大幅上升至第一梯队，O9机遇确认
  - 证伪 → T/R 芯片稀缺层逻辑减弱，排序下降

### H8: 工业级芯片降级使用方案将在千帆星座率先验证

- **假设内容**：千帆星座将大规模采用"工业级芯片+软件冗余"方案替代航天级芯片，2026H2-2027 在轨验证
- **前提/前置条件**：冗余设计可靠性验证通过 + 卫星寿命缩短可接受
- **验证信号**：千帆卫星公开采用工业级芯片方案 + 在轨运行 1 年故障率 < 5%
- **否定信号**：千帆仍坚持航天级芯片方案 + 工业级方案在轨故障率 > 10%
- **验证窗口**：2027-Q4前
- **数据来源**：千帆星座技术公开信息、在轨故障率数据
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → O8机遇确认，R3.2 风险大幅削弱，元器件稀缺层排序下降，整星制造排序上升
  - 证伪 → 元器件卡脖子逻辑维持，稀缺层排序不变
