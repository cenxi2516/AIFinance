## 三、产业链稀缺层重排（3-6月视角）

> 短期视角下，稀缺层排序需要考虑"催化剂密度"而不仅是"结构性稀缺度"。

| 排名 | 稀缺层 | 12月视角排位 | 3-6月排位变化 | 变化原因 |
|------|--------|------------|-------------|---------|
| 1 | **可回收火箭技术** | 3 | ↑2 | 朱雀三号6月测试 → 本月就可能兑现，3-6月窗口内催化剂密度最高 |
| 2 | **发射基础设施** | 1 | ↓1 | 长期仍是#1瓶颈，但3-6月内工位约束被千帆加速部分"证伪"（6月一周3射） |
| 3 | **航天级元器件** | 2 | ↓1 | 国产替代是慢变量（3-5年），3-6月窗口内催化剂有限 |
| 4 | **卫星批量制造** | 5 | ↑1 | 千帆加速直接拉动卫星制造订单，短期弹性最大 |
| 5 | **航天特种材料** | 4 | ↓1 | 随火箭/卫星放量受益，但传导滞后6-12月 |
| 6 | **卫星运营/应用** | 6 | → | 距商业变现仍远，3-6月内难有实质收入 |
| 7 | **地面设备** | 7 | → | 壁垒低、竞争充分 |

### 关键变化解释

**为什么可回收火箭从#3升到#1（3-6月视角）**：
- 朱雀三号遥二已竖立发射台，蓝箭官宣"接二连三，都会如期而至"
- 如果成功 → 中国首次入轨级可回收，全产业链成本逻辑打通 → 板块情绪重估
- 如果失败 → 至少再等6-12月 → 板块情绪承压
- **这是3-6月内最大的二元催化事件**

**为什么发射工位从#1降到#2（3-6月视角）**：
- 千帆6月首周3次发射（含24小时内2次），说明工位约束没有之前判断的那么硬
- 海南商业航天促进条例征求意见稿提出"支持多工位发射能力"
- 但长期看，工位仍是最大瓶颈——短期缓解≠长期解决

## 六、情景推演更新（3-6月窗口）

### 情景概率调整

| 情景 | 12月窗口概率 | 3-6月窗口概率 | 变化 | 原因 |
|------|------------|-------------|------|------|
| **乐观** | 20% | **25%** | +5pp | 千帆加速信号已触发+朱雀三号6月测试窗口 |
| **基准** | 40% | **40%** | → | 核心逻辑未变 |
| **悲观** | 30% | **25%** | -5pp | 千帆组网从"最大风险"变为"正在修复" |
| **极端** | 10% | **10%** | → | 地缘风险未变 |

### 3-6月窗口的核心情景路径

**路径A — 朱雀成功 + 千帆加速（概率~25%）**：
```
朱雀三号6月回收成功 → 板块情绪爆发 → Q2季报分化(西部超导/振华拐点确认?)
→ 千帆7月前冲324颗 → Q4复用飞行预期 → 全产业链重估
```
→ 方向：积极，但需警惕"利好兑现"回调

**路径B — 朱雀成功 + 千帆减速（概率~10%）**：
```
朱雀成功但千帆发射频次回落(7月后) → 火箭技术突破但下游需求证伪
→ 板块分化：火箭链受益 vs 卫星链承压
```
→ 方向：中性，选股要求极高

**路径C — 朱雀失败 + 千帆加速（概率~20%）**：
```
朱雀再次失败 → 板块情绪承压 → 但千帆仍加速(用传统火箭) 
→ 短期利空长期逻辑不变 → 回调后可能是买点
```
→ 方向：短期规避，等待情绪释放

**路径D — 朱雀失败 + 千帆减速（概率~25%）**：
```
双重利空 → 板块戴维斯双杀 → 概念退潮踩踏
→ 仅军品基本盘最稳固的标的(航天电器/振华科技)有安全边际
```
→ 方向：防御，收缩至军品核心标的

**路径E — 极端（概率~10%）**：
```
安全事故/地缘升级/流动性危机
```
→ 方向：无条件收缩
