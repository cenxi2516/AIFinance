## 三、概念股与实质受益股的区分标准

### 3.1 五维区分法

| 维度 | 实质受益 | 概念搭车 |
|------|---------|---------|
| **收入占比** | 商业航天收入 >30% | <10% |
| **订单可见性** | 有公开招标/合同公告/年报分部收入 | 仅有IR口径提及或"在研" |
| **合同负债** | 环比增长且可归因到航天业务 | 无变化或无法归因 |
| **估值匹配度** | PE <60x 或 PEG <2 | PE >80x 且 无增速支撑 |
| **催化剂实质** | 可回收成功/星座发射加速=收入加速 | 催化剂仅推升情绪，不推升收入 |

## 四、核心投资逻辑

### 4.1 长期逻辑（3-5年维度）

```
卫星互联网是国家战略 → 星座必须建成 → 发射+制造+运营全链条受益
→ 稀缺环节供应商获得超额收益 → 但时间可能比预期长2-3年
```

**逻辑成立的前提条件**：
1. 千帆/国网星座持续推进（不完全因发射失败/资金不足而停滞）
2. 可回收火箭3-5年内实现成熟回收（降低发射成本到星座经济性要求）
3. 国际频段争夺窗口不关闭（ITU要求7年内发射，否则频率作废）

**什么情况下逻辑被否定**：
1. 星座项目大规模缩减或暂停
2. 可回收火箭5年内无法稳定运行
3. ITU频率因未按时部署而丧失

### 4.2 短期逻辑（6-12月维度）

```
政策催化(政府工作报告/专项支持) + 发射事件(千帆/国网发射)
→ 概念板块脉冲式上涨 → 但缺乏基本面支撑的标的会快速回落
```

**短期逻辑的陷阱**：
- 发射事件是"催化剂"但不是"业绩兑现"，股价涨不等于基本面改善
- 概念股的涨幅由资金驱动而非业绩驱动，退潮速度可能很快
- 每次发射都会被市场解读为"利好"，但单次发射不改变产业链格局

### 4.3 正确的投资时机

**不做的事**：在概念炒作高峰期追高PE 80-150x的概念股

**等待的信号**：

| 信号 | 含义 | 对应受益环节 |
|------|------|------------|
| 可回收火箭首次成功回收 | 发射成本下降路径打开 | 全产业链 |
| 千帆/国网发射频次提升到月1次+ | 星座组网加速 | 卫星制造+配套 |
| 某标的航天业务合同负债环比增>30% | 订单实质性流入 | 具体标的 |
| A股商业航天板块整体回调30%+ | 估值风险释放 | 优质标的介入窗口 |

## 五、风险总结（对照risk-register.md）

### 5.1 最高优先级风险

| 风险 | 影响 | 概率 | 对投资的影响 |
|------|------|------|------------|
| 发射工位不足(R3.1) | 颠覆 | 70% | 制约星座组网=制约全产业链收入 |
| 星座组网滞后(R3.4) | 颠覆 | 55% | 下游无收入=上游订单无法加速 |
| 概念股估值泡沫(R4.1) | 重度 | 60% | PE 80-150x回归30-40x，下行50-70% |
| 元器件出口管制(R3.2) | 重度 | 50% | 制约卫星性能和交付 |

### 5.2 最危险的风险组合

**R3.1 + R3.4 = 致命组合**：发射工位不足 → 星座组网滞后 → 下游无收入 → 上游订单萎缩 → 全产业链商业闭环断裂

**R4.1 + R5.1 = 戴维斯双杀**：估值泡沫 + 概念退潮 → PE从80-150x压缩到30-40x + 业绩不及预期 → 下行50-70%

### 5.3 风险定级

**当前风险定级：高风险**

- 2个颠覆级风险已现实发生
- 概念股估值与基本面严重背离
- 最核心的稀缺层（发射工位、可回收火箭）缺乏A股映射
- **建议总仓位 ≤ 15%**，仅选择商业航天收入占比高、有实质订单、估值相对合理的标的

## 六、研究结论

### 核心判断

1. **商业航天是正确的方向，但不是正确的时间**：产业链方向确定，但A股投资时机尚未成熟——核心稀缺环节要么没有标的，要么估值严重透支

2. **中国与SpaceX的差距是系统性的，不是单点的**：发射能力差距26倍（130次/年 vs 5次/年），单星成本差距170-440倍，可回收技术差距8年——这些差距在短期（2-3年）内无法弥合

3. **A股商业航天投资的最大风险不是行业不行，而是标的太贵**：PE 80-150x的概念股，即使行业按预期发展，3-5年增长也已透支；如果行业进度延迟（大概率），则是戴维斯双杀

4. **正确的策略是"跟踪+等待"**：
   - 跟踪：千帆/国网发射频次、可回收火箭验证进度、核心标的合同负债变化
   - 等待：估值回归合理区间（PE <50x）+ 基本面拐点确认（合同负债持续增长）
