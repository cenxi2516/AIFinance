## 二、重点标的详细分析

### 2.1 实质受益标的（商业航天收入占比 >30%）

---

#### 中国卫星（600118）

| 维度 | 信息 |
|------|------|
| 主营 | 小卫星制造（遥感+通信） |
| 商业航天收入占比 | ~60-70%（卫星制造为主） |
| 核心卡住的环节 | 小卫星总体设计+集成 |
| 2024业绩 | 营收利润双降，军品订单波动 [一级：年报] |
| 风险点 | 应收账款高企、军品占比大导致业绩波动、民用商业订单不足 |
| 估值 | PE极高（利润薄），PS约5-6x |
| 判断 | **产业链位置核心但财务质量差，是"重要公司"而非"好投资"** |

**详细分析**：
- 中国卫星是国内小卫星制造绝对龙头，承担千帆/国网部分卫星制造任务 [二级：公开报道]
- 但公司本质是航天科技集团五院下属单位，体制约束导致市场化程度低 [推测]
- 2024年营收利润双降反映军品订单周期性，商业航天订单尚未有效对冲 [一级：年报]
- 应收账款高企说明回款困难，经营现金流不佳 [一级：年报]
- **核心矛盾**：公司是商业航天产业链的核心节点，但不是好投资标的——体制效率低+业绩波动大+估值偏高

---

#### 中国卫通（601698）

| 维度 | 信息 |
|------|------|
| 主营 | GEO卫星通信运营 |
| 商业航天收入占比 | ~90%+ |
| 核心环节 | 卫星带宽出租 |
| 2024业绩 | 收入~30亿，利润~5亿，增长缓慢 [一级：年报] |
| 风险点 | GEO卫星技术路线老化、LEO星座冲击、增长空间有限 |
| 估值 | PE ~50-70x，增速5-10%不支撑估值 |
| 判断 | **卫星通信运营商，但GEO路线是被LEO替代的方向，非增长标的** |

**详细分析**：
- 中国卫通是A股唯一卫星通信运营商，运营中星系列15+颗GEO卫星 [一级：年报]
- 但GEO卫星是"上一代"技术，LEO星座（Starlink/千帆/国网）才是趋势 [推测]
- LEO星座低延迟、高带宽，长期将替代GEO卫星的宽带通信市场 [推测]
- 中国卫通本身也可能参与LEO运营（作为星网集团子公司），但当前财务数据不反映 [推测]
- **核心矛盾**：商业模式清晰但增长天花板明确，PE 50-70x对5-10%增速是高估

---

#### 铖昌科技（001270）

| 维度 | 信息 |
|------|------|
| 主营 | 相控阵T/R芯片 |
| 商业航天收入占比 | ~40-50% |
| 核心卡住的环节 | 星载相控阵TR芯片（稀缺层第5位） |
| 2024业绩 | 收入~3-4亿，利润~1-1.5亿 [一级：年报] |
| 估值 | PE ~80-120x |
| 判断 | **卡在稀缺环节，但估值极度透支** |

**详细分析**：
- 铖昌科技是国内相控阵T/R芯片核心供应商，产品用于星载相控阵天线 [二级：公司公告]
- 相控阵天线是卫星通信载荷的核心，千帆/国网每颗卫星需要数百个TR通道 [推测]
- 但公司收入规模仅3-4亿，当前估值已反映3-5年后的增长预期 [推测]
- 风险在于：TR芯片是否会被卫星总体单位自研替代？ [推测]

| 维度 | 信息 |

## 三、实质受益 vs 概念搭车的区分标准

| 标准 | 实质受益 | 概念搭车 |
|------|---------|---------|
| **商业航天收入占比** | >30% | <10% |
| **订单可见性** | 有明确的千帆/国网/军方订单公告 | 仅提及"涉及"或"在研" |
| **客户集中度** | 前几大客户包含航天总体单位 | 航天客户分散、金额小 |
| **合同负债趋势** | 环比增长（反映新订单流入） | 无明显变化 |
| **研发投入方向** | 主要投向航天相关产品线 | 航天仅是研发方向之一 |
| **估值支撑** | PE <60x 或 有明确增速支撑 | PE >80x 且 无增速支撑 |

4. **注意**：即便排名第1的铖昌科技，PE 80-120x也意味着3-5年增长已透支，当前不是好的介入时机

## 五、核心结论

1. **A股商业航天板块整体高估**：多数概念股PE 80-150x，商业航天收入占比<10%，概念退潮后下行空间50-70% [推测]
2. **真正的稀缺层缺乏A股映射**：发射工位（无标的）、可回收火箭（未上市）、抗辐射芯片（航天微电子未上市）
3. **少量标的具有稀缺层逻辑**：铖昌科技(TR芯片)、航天电子(激光通信)，但估值已透支
4. **投资窗口需等待**：星座组网加速+可回收火箭成功=基本面拐点，预计最早2027-2028年 [推测]
5. **当前策略**：以跟踪为主，等待两个信号：(1)可回收火箭首次成功回收 (2)千帆/国网发射频次明显加速
