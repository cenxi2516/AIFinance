## R1: 宏观风险

### R1.1 出口管制持续升级，代工渠道断裂

| 维度 | 内容 |
|------|------|
| 风险描述 | BIS实体清单持续扩大，复旦微电子等核心标的无法使用TSMC/Samsung先进制程代工，国产FPGA工艺升级受阻 |
| 触发条件 | 国产FPGA代工厂（中芯国际等）被进一步限制，或14nm以下制程设备断供 |
| 前置信号 | 中芯国际产能利用率异常变化、ASML对华售后受限、国内FPGA企业流片延迟 |
| 影响程度 | 重度（直接卡住从28nm向14nm升级的路径） |
| 当前概率 | 40%（已有趋势，但中芯国际28nm产线仍在运转） |
| 依据 | 一级来源：BIS清单 |

| 依据 | 二级来源 |

|------|------|

|------|------|
| 风险描述 | 千帆星座/国网星座组网进度严重滞后→卫星制造需求不及预期→元器件国产替代失去商业闭环 |
