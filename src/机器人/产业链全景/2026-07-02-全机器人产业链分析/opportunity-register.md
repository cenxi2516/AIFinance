# 机遇注册表

> 风险映射后，识别非对称性最高的机遇。每个机遇必须绑定触发条件和前置信号。

## 一、产业链机遇

### O1: 谐波减速器跨品类三重需求共振

- **机遇描述**：谐波减速器同时受益于工业机器人自动化升级、协作机器人普及、人形机器人爆发三重驱动，是跨品类"最大公约数"
- **机遇类别**：产业链 — 多品类需求共振
- **核心逻辑**：任何一类机器人爆发，谐波减速器都受益；三类同时增长 → 需求增速远超单一品类
- **触发条件**：
  - 人形机器人年出货 >5 万台（2026E）
  - 协作机器人年出货 >10 万台（2026E）
  - 工业机器人维持 10%+ 年增速
- **前置信号**：
  - 绿的谐波人形机器人客户订单公告
  - 协作机器人行业出货量季度数据加速
- **影响程度**：重大（对绿的谐波）
- **当前概率**：中高（40-60%）
- **概率依据**：三重需求均处于增长通道，最确定性的共识
- **时间窗口**：2026-2030
- **核心标的**：绿的谐波(688017)、中大力德(002896)
- **上行情景**：2030 年谐波减速器需求 4900 万台（当前 420 万台）→ 市场空间扩大 12 倍
- **下行风险**：竞争对手增多（威灵美的入场可能改变竞争格局）、人形机器人用量不及预期

### O2: 行星滚柱丝杠国产替代从 0 到 1

- **机遇描述**：行星滚柱丝杠是人形机器人最大纯增量零部件，全球仅 4 家巨头垄断，国产化率 <10%，人形领域接近 0%。如果国产验证通过 → 从 0 到 1 的质变
- **机遇类别**：产业链 — 国产替代从 0 到 1
- **核心逻辑**：特斯拉 Optimus 已确认采用行星滚柱丝杠方案（Wikipedia），单台用量 4-6 根。当前全球供需格局极度集中（SKF/Thomson/舍弗勒/博世力士乐），国产替代空间巨大
- **触发条件**：≥1 家国产厂商（鼎智/贝斯特/恒立）获得特斯拉/优必选/智元批量订单
- **前置信号**：
  - 国产厂商公告"通过头部客户验证"
  - 国产厂商丝杠产能扩产计划（资本开支增加）
  - 头部人形机器人厂商供应链日/发布会提及国产丝杠供应商
- **影响程度**：变革性（对验证通过的标的）
- **当前概率**：中（15-40%）
- **概率依据**：2026H2 是验证关键窗口。鼎智科技送样最早、贝斯特产线即将投产、恒立液压资金实力最强
- **时间窗口**：2026Q3-Q4（验证窗口）→ 2027-2028（批量供货）
- **核心标的**：鼎智科技(873594)、贝斯特(300580)、恒立液压(601100)
- **上行情景**：一家国产厂商获得 50%+ 国内人形丝杠份额 → 营收从 0 到数十亿元
- **下行风险**：
  - 良率不达标被退回（概率 15-40%）
  - 特斯拉自研丝杠（概率 10-20%）
  - 技术路线切换（直驱替代丝杠，概率 <10%）

### O3: 伺服电机人形增量被低估

- **机遇描述**：市场对机器人的关注集中在减速器和丝杠，但伺服电机的增量被严重低估——人形机器人单台伺服电机需求是工业机器人的 2-5 倍
- **机遇类别**：产业链 — 量增被低估
- **核心逻辑**：一台人形机器人需要 14-28 个伺服电机（含无框力矩电机），而一台工业机器人仅需 6 个。如果 2030 年人形机器人出货 150 万台 → 伺服电机需求 2100-4200 万台 → 这是当前全球工业机器人伺服需求（~360 万台/年）的 6-12 倍
- **触发条件**：人形机器人年产突破 10 万台（预计 2027-2028）
- **前置信号**：汇川技术/禾川科技公告人形机器人伺服电机订单
- **影响程度**：重大
- **当前概率**：中（15-40%）
- **概率依据**：人形机器人量产趋势明确，伺服作为必要零部件确定性高
- **时间窗口**：2027-2030
- **核心标的**：汇川技术(300124)
- **上行情景**：汇川在人形机器人伺服领域获得类似在工业伺服领域的份额（30%+）
- **下行风险**：人形机器人厂商自研伺服电机（类似特斯拉自研驱动电机）

### O4: 工业机器人核心零部件出海

- **机遇描述**：2025 年中国减速器出口 +36%、机器人整机出口 +54.9%。国产核心零部件正在从"进口替代"走向"全球替代"
- **机遇类别**：市场扩张 — 出海
- **核心逻辑**：国产减速器价格为进口 60%，性能差距缩小至 15% 以内。东南亚/墨西哥等新兴制造业市场对性价比敏感，国产品牌具有强竞争力
- **触发条件**：国产减速器/伺服出口增速 >30% 持续 2 年
- **前置信号**：日本对华减速器出口额继续下降 + 中国减速器出口额继续上升
- **影响程度**：重大
- **当前概率**：中高（40-60%）
- **概率依据**：2025 年已有的出口增速数据支撑，趋势明确
- **时间窗口**：2026-2028
- **核心标的**：双环传动(002472)、绿的谐波(688017)、汇川技术(300124)
- **上行情景**：中国减速器在全球市场份额从 ~20% → 40%+
- **下行风险**：地缘政治导致的贸易壁垒（如印度/东南亚对中国产品加征关税）

## 二、上游/设备机遇

### O5: 丝杠磨削设备——二次替代逻辑

- **机遇描述**：如果国产行星滚柱丝杠放量，必然需要大量精密磨削设备。当前高端螺纹磨床主要依赖日本/德国/瑞士进口。国产磨床的突破，是丝杠国产化的"二次替代"机会
- **机遇类别**：上游 — 设备国产化
- **核心逻辑**：丝杠放量 → 磨床需求激增 → 进口设备交期长+价格高+可能有出口管制 → 国产磨床替代窗口打开
- **触发条件**：国产丝杠厂商（鼎智/贝斯特）资本开支公告中包含日发精机等国产磨床订单
- **前置信号**：国产磨床精度达到 C3 级以上
- **影响程度**：中度
- **当前概率**：低-中（10-25%）
- **概率依据**：日发精机已具备丝杠磨削设备生产能力，但精度和稳定性待验证
- **时间窗口**：2027-2029
- **核心标的**：日发精机（需单独调研）

## 三、资本市场机遇

### O6: 产业资本密集涌入驱动的估值重估

- **机遇描述**：2026 年前 5 个月机器人一级市场融资 434 起/746 亿元，39+企业排队 IPO。宇树科技 IPO 过会是信号。持续的资本涌入和 IPO 将推动 A 股已有标的的估值对标重估
- **机遇类别**：资本市场 — IPO 效应
- **核心逻辑**：当优必选（港股）、宇树科技（科创板即将上市）、智元机器人（可能 IPO）等整机厂获得资本市场定价后，A 股现有零部件标的将获得估值锚点
- **触发条件**：宇树科技科创板正式挂牌 + 首日涨幅 >50%
- **前置信号**：更多机器人企业递交 IPO 申请并获受理
- **影响程度**：中度（短期情绪推动）
- **当前概率**：中高（40-60%）
- **概率依据**：宇树已过会，上市时间预计 2026H2
- **时间窗口**：2026H2-2027
- **核心标的**：绿的谐波(688017)、鼎智科技(873594)
- **上行情景**：宇树上市后市值 500 亿+ → 带动零部件标的估值对标上行
- **下行风险**：宇树上市后破发 → 反向拖累板块估值
