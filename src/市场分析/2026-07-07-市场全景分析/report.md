## 八、下跌原因深度分析（五层逻辑）

### 🥇 第一层：中报业绩验证期 → 核心逻辑切换（最底层原因）

**7月8日中报披露窗口正式开启**，定价逻辑从**"流动性驱动"→"业绩驱动"**。

- 上半年AI/半导体/创新药大幅上涨，已透支乐观预期
- 高增速能否兑现 → 不确定性 → 资金在验证前集中撤离
- **这是本轮调整最根本的驱动力，不是短期情绪波动**

### 🥈 第二层：外部冲击 — 韩国KOSPI200暴跌6.5%熔断

- 三星电子重挫近8%，SK海力士大跌
- 费城半导体指数上周单日跌超6%
- 韩国政府紧急出台稳定措施
- **但A股半导体逆势走强** → 说明国产替代逻辑在持续强化，"脱敏"韩国利空

### 🥉 第三层：主力+北向+两融三方同向流出

| 资金类型 | 当日动向 | 信号 |
|---------|---------|------|
| 主力资金 | 净流出约873亿 | 🔴 强烈空头 |
| 北向资金 | 净流出40亿（连续4日） | 🔴 持续空头 |
| 两融余额 | 单日降仓197亿 | 🔴 去杠杆 |

> 三方同向流出 → **最强空头共振**。上周半导体累计流出555亿、通信设备流出340亿，今日的流出是趋势的延续而非孤立事件。

### 🏅 第四层：高低轮动加速 → 缺乏持续性主线

```
7月6日：煤炭+4.11%、农林牧渔+2.83% 领涨

→ 轮动速度缩短到"隔日级别"，说明没有增量资金，只是存量在反复腾挪
→ 旧主线（通信/算力硬件）持续失血，新主线（半导体硅片/先进封装）能否接力待验证
```

- ✅ **利好**：央行开展1万亿元买断式逆回购+2000亿加量续作
- ✅ **利好**：美国非农低于预期，加息预期降温
- ⚠️ **新规**：沪深北交易所新交易规则7月6日施行（盘后固定价扩围、ST股涨跌幅调至10%）

## 十、核心结论

### 风险定级：⚠️ 中度偏高（但尾盘有抵抗信号）

**今日是一次"结构性普跌"**，5个关键判断：

1. **下跌主因是业绩验证期逻辑切换**，不是系统性风险
   - 中报窗口7月8日开启 → 业绩预期修正 → 高位股获利了结 → 连锁踩踏
   
2. **半导体逆势涨停潮是本日最重要的积极信号**
   - 硅片涨价+国产替代双逻辑驱动，科创50逆势收红+0.28%
   - 但需注意：上周半导体累计流出555亿，今日流入是超跌反弹而非趋势反转
   
3. **缩量调整好于放量杀跌**
   - 成交从3.09万亿缩至2.48万亿（-20%），说明不是恐慌性出逃
   - 尾盘上证从3972回升到3990，关键支撑有效
   
4. **高低轮动加速到"隔日级别"，操作难度极大**
   - 煤炭昨日领涨→今日领跌，半导体重回C位
   - 追涨即套，说明市场缺乏增量资金，存量博弈为主

5. **北向深股通流出>>沪股通，科技股仍是外资减仓重点**
   - 但午后沪股通明显回流（-19→-9亿），蓝筹有资金护盘

### 后续关键观察点

| 观察点 | 阈值 | 含义 |
|--------|------|------|
| 上证 3950 支撑 | 若跌破 → 调整深化至3900 | 关键支撑位（今日3972已测试） |

| 煤炭持续性 | 若继续下跌 → 防御性轮动也失败 | 说明全市场无主线 |
