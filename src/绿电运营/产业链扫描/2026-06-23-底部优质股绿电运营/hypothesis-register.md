## 假设列表

### H1: 水电存量稀缺性将推动长江电力PE中枢从18x上移至20x

- **假设内容**：利率下行周期+水电资源不可再生，市场将逐步把长江电力从"公用事业18x"重新定价为"类债券20x"
- **前提/前置条件**：10年国债收益率维持在2.5%以下 + 来水正常 + 分红率维持60%+
- **验证信号**：长江电力PE持续高于20x超过3个月 + 分红率>60% + 10年国债<2.5%
- **否定信号**：PE回落至16x以下 + 分红率下调至50%以下 + 来水连续2年偏枯>20%
- **验证窗口**：2027-Q2前（1年内）
- **数据来源**：交易所行情数据 + 长江电力年报/半年报
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → P1长江电力优先级进一步上升
  - 证伪 → P1长江电力降级至P2，类债券逻辑需修正

### H2: 核电审批常态化（4-6台/年）将持续至2030年

- **假设内容**：中国每年核准4-6台核电机组的节奏将持续，为核电运营提供5-10年量增确定性
- **前提/前置条件**：核安全记录良好（无INES 3级+事件） + 电力需求增长 + 双碳政策持续
- **验证信号**：2026年核准4+台 + 2027年核准4+台 + 在建机组按期推进
- **否定信号**：任何一年核准<2台 + 核安全事件 + 政策文件暗示放缓
- **验证窗口**：2027-Q4前（1.5年内，看2年核准数据）
- **数据来源**：国家能源局核准公告 + 中国核电年报
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → P2中国核电量增逻辑确认，可考虑加大权重
  - 证伪 → P2中国核电降级，量增逻辑受损

### H3: 国投电力PE将从14.6x修复至16-17x

- **假设内容**：市场将逐步认识到雅砻江水电的稀缺价值，叠加火电扭亏，PE修复至16-17x
- **前提/前置条件**：火电板块不再持续亏损 + 雅砻江上游按期投产 + 水电估值重估趋势持续
- **验证信号**：火电板块季度利润转正 + PE突破16x
- **否定信号**：火电连续2年亏损 + PE跌破13x
- **验证窗口**：2027-Q2前（1年内，看2次年报+4次季报）
- **数据来源**：国投电力季报/年报 + 交易所行情
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → P3国投电力可升至P2
  - 证伪 → P3维持，估值修复逻辑暂缓

### H4: 美的集团海外收入增速维持>10%/年
