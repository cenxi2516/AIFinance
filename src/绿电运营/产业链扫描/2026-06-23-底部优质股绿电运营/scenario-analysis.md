## 二、核心情景推演

### 情景 A：基准情景（概率 ~50%）

**假设**：来水正常+核电审批持续常态化+利率维持低位+贸易摩擦不升级

**各标的参考区间**：

| 标的 | 参考区间(12个月) | 逻辑 |
|------|-----------------|------|
| 长江电力 | 25-31元 | 类债券定价持续，PE中枢从18x向20x靠拢，分红稳定3.5%+ |
| 中国核电 | 8.5-11元 | 量增确定但估值已合理，新机组投产节奏决定上行空间 |
| 国投电力 | 12-17元 | 估值修复+雅砻江增量，PE从14.4x向16-17x修复 |
| 川投能源 | 13-18元 | 跟随雅砻江分红提升，纯水电溢价 |
| 美的集团 | 70-90元 | 全球化缓慢推进，国内需求企稳，PE修复至15-17x |

**触发条件**（判断基准情景成立）：
1. 长江/雅砻江来水量在多年均值±10%以内
2. 年核准核电机组4-6台
3. 10年国债收益率维持在2.0-2.5%
4. 无重大贸易摩擦升级

### 情景 B：乐观情景（概率 ~20%）

**假设**：来水偏丰+核电审批加速+利率进一步下行+贸易环境改善

**触发条件**：
1. 来水偏丰10%+（发电量超预期）
2. 年核准核电机组>6台
3. 10年国债收益率降至2.0%以下
4. 中美贸易关系缓和

**各标的参考区间**：

| 标的 | 参考区间(12个月) | 逻辑 |
|------|-----------------|------|
| 长江电力 | 29-35元 | 来水偏丰+利率下行双重催化，PE中枢可至22-24x |
| 中国核电 | 10-13元 | 审批加速+AI用电需求被重新定价 |
| 国投电力 | 16-20元 | 水电价值重估+火电扭亏 |
| 川投能源 | 16-21元 | 纯水电溢价被市场充分认知 |
| 美的集团 | 80-95元 | 贸易缓和+海外收入加速+TOB突破 |

### 情景 C：悲观情景（概率 ~20%）

**假设**：来水偏枯+电价下行压力+利率小幅上行+贸易摩擦升级

**触发条件**：
1. 来水偏枯15%+（发电量低于预期）
2. 现货电价持续低于标杆电价10%+
3. 10年国债收益率回升至2.8%+
4. 美国对中国家电加征关税超25%

**各标的参考区间**：

| 标的 | 参考区间(12个月) | 逻辑 |
|------|-----------------|------|
| 长江电力 | 23-26元 | 来水偏枯压制发电量+利率上行压制估值 |
| 中国核电 | 7.5-9元 | 电价下行压力+市场风格转向成长 |
| 国投电力 | 11-13元 | 火电亏损扩大+水电发电量下降 |
| 川投能源 | 12-14元 | 雅砻江分红下降 |
| 美的集团 | 60-72元 | 关税打击海外利润+国内房地产持续下行 |

### 情景 D：极端风险情景（概率 ~10%）

**假设**：核安全事故/全球金融风险/台海冲突等极端事件

**触发条件**：
1. 国内核电站发生INES 4级以上事件 → 中国核电无条件退出
2. 全球系统性金融风险 → 所有无差别抛售
3. 台海军事冲突 → 市场停摆

**参考动作**：无条件收缩至现金，等待风险释放后重新评估

**各标的参考区间**：
