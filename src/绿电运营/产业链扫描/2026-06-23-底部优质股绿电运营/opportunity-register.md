## 一、宏观机遇

### O1: 利率下行周期 — 类债券资产重估

- **机遇描述**：中国10年国债收益率从3%+降至~2.5%以下，水电/核电的高分红稳定现金流成为固收替代品，估值从"公用事业"向"类债券"重估
- **机遇类别**：宏观 — 流动性改善
- **触发条件**：10年国债收益率持续低于2.5% + LPR持续下调
- **前置条件**：央行维持宽松货币政策 + 通胀未显著回升
- **当前状态**：前置条件已满足（2026年6月，10年国债~2.3%，LPR持续下调）
- **时间窗口**：已兑现中，预计持续1-3年
- **影响程度**：重大
- **当前概率**：高（>70%）
- **受益标的**：长江电力(P1) > 国投电力(P3) > 川投能源(P4) > 中国核电(P2)
- **风险对冲**：如果利率反转上行(R1b)，类债券逻辑逆转，估值承压
- **验证路径**：跟踪10年国债收益率 + 中证红利指数相对沪深300的超额收益

### O2: AI数据中心用电暴增 — 基荷电源价值提升

- **机遇描述**：AI训练/推理数据中心对电力需求急剧增加，但数据中心需要稳定基荷电源（非间歇性），核电和水电作为唯一零碳基荷电源价值提升
- **机遇类别**：宏观 — 新需求
- **触发条件**：全国数据中心用电增速>15%/年 + 碳排放约束强化
- **前置条件**：AI capex持续扩张 + 绿电消纳权重提升
- **当前状态**：前置条件部分满足（AI capex高位但增速有争议，绿电消纳权重逐步提升）
- **时间窗口**：2026-2030年
- **物理约束**：核电站审批到商运7-10年，水电已无新增大型项目
- **影响程度**：重大
- **当前概率**：中（40-60%）
- **受益标的**：中国核电(P2) > 长江电力(P1)
- **风险对冲**：AI capex见顶则需求增长放缓；储能突破可能改变基荷需求结构
- **验证路径**：跟踪全国数据中心用电量 + 核电/水电长期合同签订情况

## 二、政策与产业机遇

### O3: 核电审批常态化 — 量增确定性

- **机遇描述**：中国核电审批从2016-2018年的零核准恢复到每年4-6台常态化审批，在建+核准机组保障未来5-10年收入增长
- **机遇类别**：政策 — 产业扶持
- **触发条件**：每年核准4-6台核电机组（连续3年确认趋势）
- **前置条件**：核安全记录良好 + 能源安全需求
- **当前状态**：前置条件已满足（2019年起每年核准4-10台，2024-2025年核准5-8台/年）
- **时间窗口**：已兑现中，预计持续5-10年
- **影响程度**：重大
- **当前概率**：高（>80%）
- **受益标的**：中国核电(P2) — 直接受益，在建机组5+台
- **风险对冲**：核安全事故(R2a)可瞬间冻结审批，概率<5%但影响颠覆级
- **验证路径**：跟踪国家能源局核电机组核准公告 + 中国核电在建机组进度

### O4: 电力市场化改革 — 优质电源溢价

- **机遇描述**：电力市场化改革推进，绿电（水电/核电）因零碳属性可获得绿色溢价，长期合同电价可能高于现货市场均值
- **机遇类别**：政策 — 监管放松
- **触发条件**：绿电交易溢价持续存在 + 长期合同电价上浮
- **前置条件**：碳排放权交易体系完善 + 绿色电力证书制度落地
- **当前状态**：前置条件部分满足（绿电交易试点扩大，但溢价幅度有限）
- **时间窗口**：2026-2028年逐步兑现
- **影响程度**：中等
- **当前概率**：中（40-50%）
- **受益标的**：长江电力(P1) > 中国核电(P2) > 国投电力(P3)
- **风险对冲**：电力市场化加速也可能导致电价下行(R2b)，净影响不确定
- **验证路径**：跟踪绿电交易溢价 + 各公司长期合同电价变动

### O5: 双碳政策强化 — 绿电消纳权重提升

- **机遇描述**：碳达峰目标临近（2030年），绿电消纳责任权重持续提升，水电/核电作为最稳定的绿电来源直接受益
- **机遇类别**：政策 — 产业扶持
- **触发条件**：非化石能源占比目标提前完成 + 绿电消纳权重上调
- **前置条件**：政策持续推进 + 煤电退出加速
- **当前状态**：前置条件已满足（双碳目标明确，煤电退出路线图清晰）
- **时间窗口**：2026-2030年
- **影响程度**：中等
- **当前概率**：高（>70%）
- **受益标的**：长江电力(P1) > 中国核电(P2) > 国投电力(P3) > 川投能源(P4)
- **风险对冲**：双碳政策退坡(极低概率) → 绿电溢价消失
- **验证路径**：跟踪非化石能源占比数据 + 绿电消纳权重年度调整

## 三、产业链机遇

### O6: 水电存量资源价值重估 — 不可再生的稀缺性定价

- **机遇描述**：中国优质水电资源（长江、雅砻江、澜沧江、大渡河干流）已基本开发完毕，存量水电站成为"不可复制的稀缺资产"，随着时间推移价值持续提升
- **机遇类别**：产业链 — 稀缺层
- **触发条件**：最后一批大型水电站投产 → 市场意识到"不会再有了"
- **前置条件**：水电开发接近尾声（已满足）
- **当前状态**：前置条件已满足（长江干流6大电站全部投产，雅砻江中下游全部投产）
- **时间窗口**：已兑现中，持续受益
- **物理约束**：水电站8-15年建设周期，已无新的大型坝址可开发
- **影响程度**：变革性（长期）
- **当前概率**：高（>90% — 物理现实不可逆转）
- **受益标的**：长江电力(P1) > 国投电力(P3) > 川投能源(P4)
- **风险对冲**：来水持续枯竭(R1a/R4a)可短期破坏现金流预期，但不改变资源稀缺性
- **验证路径**：跟踪水电开发规划更新 + 水电资产交易估值（如收购对价/装机容量比）

### O7: 核电利用率提升 — 量价齐升空间

- **机遇描述**：中国核电机组利用率（容量因子）约75-80%，低于全球先进水平90%+，随着运营经验积累和调度优化，利用率每提升1pct对应数亿元利润增量
- **机遇类别**：产业链 — 技术突破
- **触发条件**：容量因子从~78%提升至85%+（仍有7pct空间）
- **前置条件**：核安全记录良好 + 电网调度优化 + 检修周期优化
- **当前状态**：前置条件部分满足（利用率逐年缓慢提升中）
- **时间窗口**：3-5年逐步兑现
- **影响程度**：中等
- **当前概率**：中高（50-70%）
- **受益标的**：中国核电(P2)
- **风险对冲**：检修计划调整可能阶段性降低利用率
- **验证路径**：跟踪中国核电季度发电量/利用小时数

## 四、公司层面机遇

### O8: 长江电力六库联调效率提升

- **机遇描述**：六库联调（乌东德+白鹤滩+溪洛渡+向家坝+三峡+葛洲坝）的增发效率从当前~5%仍有提升空间，每提升1pct增发约20亿kWh，对应约6亿元收入
- **机遇类别**：公司 — 产能释放
- **触发条件**：联调算法优化 + 气象预测精度提升
- **前置条件**：梯级电站全部投产 + 数据积累足够
- **当前状态**：前置条件已满足（6库已全部投产，联调效率逐年优化）
- **时间窗口**：持续兑现，每年小幅提升
- **量化目标**：增发效率从5%提升至7-8%（仍有2-3pct空间）
- **影响程度**：中等
- **当前概率**：高（>70%）
- **受益标的**：长江电力(P1)
- **风险对冲**：来水极端偏枯可完全抵消联调增益
- **验证路径**：跟踪长江电力半年报/年报中的"联调增发电量"数据

### O9: 国投电力雅砻江上游开发

- **机遇描述**：雅砻江上游（卡拉、杨房沟等）水电站逐步投产，为雅砻江水电贡献增量收入。上游开发完成后雅砻江将成为全流域梯级开发标杆
- **机遇类别**：公司 — 产能释放
- **触发条件**：卡拉/杨房沟等机组商运
- **前置条件**：环评通过 + 移民安置完成 + 建设完工
- **当前状态**：前置条件部分满足（部分机组已投产，上游仍在建设中）
- **时间窗口**：2026-2029年逐步投产
- **影响程度**：中等
- **当前概率**：中高（50-70%）
- **受益标的**：国投电力(P3) > 川投能源(P4)
- **风险对冲**：环评/移民受阻可延迟投产
- **验证路径**：跟踪国投电力公告中雅砻江上游机组投产时间表

### O10: 美的集团全球化份额提升

- **机遇描述**：美的海外收入占比已超40%，通过并购（东芝白电/库卡）+本地化制造+品牌建设，全球白电份额从~15%向20%+迈进
- **机遇类别**：公司 — 估值修复
- **触发条件**：海外收入增速>10%/年 + 海外毛利率持续提升
- **前置条件**：全球贸易环境不显著恶化 + 品牌认知度持续提升
- **当前状态**：前置条件部分满足（全球化进展良好，但贸易环境不确定）
- **时间窗口**：2026-2030年
- **影响程度**：中等
- **当前概率**：中（40-60%）
- **受益标的**：美的集团(P5)
- **风险对冲**：全球贸易战升级(R1c+R2d)可严重打击海外利润
- **验证路径**：跟踪美的年报中海外分区域收入增速 + 海外毛利率变化

## 七、当前机遇定级

- [x] **高确定性**：宏观/中观/微观三层共振，前置条件基本满足
  - O1(利率下行重估) + O3(核电审批常态化) + O5(双碳强化) + O6(水电稀缺重估) — 四条主线同向共振
  - 核心受益：长江电力 > 中国核电 > 国投电力 > 川投能源
- [ ] **中等确定性**：部分前置条件未满足，等待催化剂
  - O2(AI用电) + O4(绿电溢价) + O7(利用率提升) + O9(雅砻江上游) — 方向对但时间和幅度不确定
- [ ] **低确定性**：方向对但时间点和幅度都不确定
  - O10(美的全球化) — 独立逻辑，贸易环境不确定性大

**核心判断**：绿电运营（水电+核电）是高确定性机遇，4条主线同向共振。美的集团是独立逻辑，确定性中等偏低。
