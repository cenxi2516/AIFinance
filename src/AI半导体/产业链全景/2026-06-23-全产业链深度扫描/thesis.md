# AI 半导体全产业链深度扫描（2026-06-23）

> **分析类型**：全产业链深度扫描 | **市场**：A 股 | **时间窗口**：当前机会（3-12 个月）
> **方法论**：Serenity 产业链瓶颈猎人框架

---

## 一、核心判断（TL;DR）

**先排产业链层级，再排公司。当前最值得优先研究的稀缺层是：HBM/先进存储 → 先进封装设备与材料 → 高端光模块/光引擎 → 半导体设备（刻蚀+薄膜沉积）→ 12 英寸大硅片。**

原因是：AI 需求继续扩张时，最先紧起来的不是纯算力芯片，而是**决定算力芯片能不能造出来、连起来、跑起来**的周边环节。HBM 产能缺口 50-60% 是物理硬约束，CoWoS 虽从 20% 收窄至 10% 但热管理/翘曲新瓶颈正在形成，光模块 1.6T 导入期 EML 激光器已缺货至 2027 年，半导体设备在两存扩产+国产替代双驱动下进入订单爆发期。

**与市场主流叙事的差异**：
- 市场共识：买 GPU/算力芯片 → 实际稀缺在 HBM 和封装
- 市场共识：CoWoS 扩产瓶颈即将解除 → 新瓶颈向 SiC 基板、TGV、玻璃基板迁移
- 市场共识：半导体设备是"稳增" → 两存 IPO 扩产 + 国产化加速 = 设备进入非线性增长期

## 二、系统变化：AI 从"训练主导"切换到"推理主导"

### 2.1 需求驱动力切换

| 维度 | 2024-2025 | 2026-2027 |
|------|-----------|-----------|
| 主导需求 | 训练（Training） | 推理（Inference）占比 >70% |
| 算力形态 | 大集群训练 | 分布式推理 + Token 经济 |
| 核心约束 | GPU 供给 | HBM + 封装 + 互联带宽 |
| 单机价值量 | GPU 占 80%+ | HBM/光模块/液冷占比快速提升 |

### 2.2 物理世界约束（哪些旧设计在被压垮）

| 约束维度 | 旧设计极限 | 新需求 | 谁受益 |
|---------|-----------|--------|--------|
| **内存带宽** | DDR5 带宽不足以匹配 GPU 算力增长 | HBM3E/HBM4 堆叠层数从 8→12→16 | HBM 供应商、TSV 设备、先进封装 |
| **封装密度** | 传统 2.5D CoWoS 光罩尺寸瓶颈 | 5.5x→9.5x 光罩，向 CoPoS 演进 | SiC 基板、TGV、面板级设备 |
| **互联带宽** | 可插拔光模块 800G 极限逼近 | 1.6T + CPO 共封装 | 硅光芯片、光引擎、CPO 基板 |
| **散热** | 风冷极限 ~700W TDP | GPU TDP → 1000W+ | 液冷 CDU/冷板、冷却液 |
| **供电** | 传统 UPS/配电房占地过大 | HVDC/SST 高效配电 | SiC 功率器件、HVDC 电源 |

## 四、各稀缺层详细分析

### 4.1 HBM/先进存储 — 最硬物理约束 ★★★★★

**稀缺来源**：
- 全球仅 3 家供应商（SK 海力士 60% + 三星 + 美光），2026 年产能全部售罄
- 缺口 50-60%，部分客户产能锁定至 2028 年
- HBM3E 消耗晶圆面积是 DDR5 的 3 倍，每片 HBM 晶圆挤占 LPDDR5X/DDR5 产能
- 16 层堆叠良率仅 50-60%，生产周期跨两个季度
- 新建晶圆厂从动工到量产 2-3 年 → 新增产能最快 2028-2029

- 台积电对 CoPoS 供应链祭出"独供协议"，提前锁定下一代封装技术

- **产业链位置**：距稀缺层远近
- **稀缺性**：供给集中度/替代难度

## 六、什么情况说明这个判断错了

### 6.1 对 Tier 1 标的的反方理由

**北方华创**：
- 如果两存 IPO 进度延迟或募资不及预期 → 设备采购节奏放缓
- 如果中美关系缓和、ASML 等对华出口放松 → 国产设备替代紧迫性下降
- 当前估值已包含较高的增长预期，若季度新增订单增速 <30% 可能杀估值

**中际旭创**：
- 如果英伟达转向自研光模块或更换供应商 → 最核心的增长引擎受损
- 如果 1.6T 导入进度慢于预期（目前市场共识是 2026 年大幅放量）
- 估值已处于历史高位，对增速放缓极度敏感

**天孚通信**：
- 对英伟达依赖极高（~65% 份额），如果英伟达分散供应链
- CPO 技术路线若被替代（如 LPO 线性驱动方案）→ 光引擎价值可能被压缩

### 6.2 全局风险情景

| 情景 | 触发条件 | 影响 |
|------|---------|------|
| AI Capex 见顶 | 北美 hyperscaler 下调 capex 指引 | 全产业链杀估值，光模块/设备/材料首当其冲 |
| 存储周期反转 | 2027 年新增产能集中释放 + 需求增速放缓 | HBM 价格暴跌，存储链全线承压 |
| CPO 技术路线替代 | LPO/线性驱动在 1.6T 时代证明更优 | CPO 光引擎公司估值逻辑崩塌 |
| 中美科技脱钩升级 | BIS 新规限制设备零部件对华出口 | 国产设备公司面临零部件断供风险 |
| 两存 IPO 不及预期 | 发行价/募资额低于预期 | 设备采购链预期下调 |
