## 二、核心情景推演

### 情景 A：基准情景（概率 ~45%）

**假设**：AI capex维持20-30%增速增长，国产替代按预期推进，出口管制小幅加码但范围可控，HBM/先进封装持续紧缺

**产业链演变**：
- 台积电CoWoS产能逐步扩张但2026年底仍<8万片/月
- HBM3E价格维持环比小幅上涨
- 国产设备验证按计划推进，部分产品获重复订单
- 电力变压器交期维持36-48月

**各标的参考区间**：

| 标的 | 当前PE | 基准PE区间 | 参考逻辑 |
|------|--------|-----------|---------|
| 安集科技 | 71x | 60-80x | 耗材型稳定增长，估值有支撑 |
| 彤程新材 | 73x | 60-85x | 光刻胶验证推进，估值温和扩张 |
| 通富微电 | 75x | 55-80x | 先进封装占比提升，但毛利率压制估值 |
| 北方华创 | 97x | 70-100x | 平台型龙头溢价，但增速放缓时估值承压 |
| 华海清科 | 106x | 80-120x | CMP稀缺性支撑，但验证节奏决定上限 |
| 澜起科技 | 134x | 100-140x | MRDIMM放量驱动，但高PE需要增速兑现 |
| 中微公司 | 129x | 90-130x | 刻蚀设备稀缺，但验证周期拉长压制估值 |
| 江丰电子 | 148x | 100-150x | 靶材龙头但估值偏高，需要持续高增长 |

**触发条件**（判断基准情景成立）：
1. 季报收入增速20-40%区间
2. 合同负债环比持平或小幅增长
3. 北美CSP capex指引维持增长
4. 无重大出口管制升级

### 情景 B：乐观情景（概率 ~20%）

**假设**：AI capex超预期（北美CSP上调指引+国内晶圆厂新一轮扩产），国产替代加速兑现，HBM紧缺加剧

**触发条件**：
1. ≥2家北美hyperscaler上调capex指引
2. 华海清科减薄设备获量产订单公告
3. 澜起科技MRDIMM收入占比突破30%
4. 台积电CoWoS利用率>95%且交期进一步拉长
5. 国产设备获重复订单数量超预期

**各标的参考区间**：

| 标的 | 乐观PE区间 | 参考逻辑 |
|------|-----------|---------|
| 安集科技 | 80-100x | 耗材需求加速+新配方认证推动估值扩张 |
| 华海清科 | 120-160x | 减薄设备量产+CMP出机加速，稀缺性溢价 |
| 北方华创 | 100-130x | 平台型龙头享受国产替代加速溢价 |
| 澜起科技 | 140-180x | MRDIMM/CXL放量超预期 |
| 彤程新材 | 80-100x | ArF光刻胶量产突破 |

**仓位倾向**：可加大核心标的敞口至70%

### 情景 C：悲观情景（概率 ~25%）

**假设**：AI capex增速放缓至<10%，出口管制升级至零部件层面，部分标的季报低于预期，估值开始压缩

**触发条件**：
1. ≥1家北美hyperscaler下调capex指引
2. BIS扩大出口管制至设备零部件
3. 设备公司合同负债环比下降>10%
4. ≥2只标的季报收入增速<15%
5. HBM/先进封装产能利用率降至<85%

**各标的参考区间**：

| 标的 | 悲观PE区间 | 参考逻辑 |
|------|-----------|---------|
| 安集科技 | 45-60x | 耗材防御性较强，跌幅有限 |
| 彤程新材 | 45-60x | 主板+光刻胶逻辑，相对抗跌 |
| 通富微电 | 40-55x | 封测竞争加剧+客户集中风险 |
| 北方华创 | 55-70x | 平台型但单产品市占率低，估值收缩 |
| 华海清科 | 60-80x | 验证不及预期+估值压缩 |
| 澜起科技 | 80-100x | 高PE+客户自研压力双重打击 |
| 中微公司 | 70-90x | 验证周期长+高估值双杀 |

**仓位倾向**：收缩至30%以下，仅保留安集/彤程

### 情景 D：极端风险情景（概率 ~10%）

**假设**：AI capex见顶+出口管制大幅升级+全球金融风险事件三重叠加

**触发条件**：
1. ≥2家北美hyperscaler同时下调capex指引
2. BIS将北方华创/中微加入实体清单
3. 全球性金融风险事件（如美债危机、台海冲突）
4. A股半导体板块单周跌幅>15%

**参考动作**：无条件收缩至10%以下观察仓位，等待风险释放后重新评估
