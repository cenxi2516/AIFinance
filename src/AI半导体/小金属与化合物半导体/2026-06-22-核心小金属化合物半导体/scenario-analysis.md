## 二、核心情景推演

### 情景 A：基准情景（概率 ~40-50%）

**假设**：中国出口管制持续收紧，锑/钨/镓价格维持高位但不再大幅上涨，光伏+军工需求温和增长，SiC过剩周期持续

**小金属价格演变**：
- 锑价维持14-17万/吨区间，高位震荡不再暴涨
- 钨价APT维持17-18万/吨，温和上行
- 镓/铟/锗价格维持中高位，管制效应常态化

**各标的参考区间**（基于当前估值±1标准差）：

| 标的 | 参考区间(元) | 逻辑 |
|------|-------------|------|
| 湖南黄金 | 24-35 | 锑+金利润支撑PE25-35x |
| 华钰矿业 | 20-30 | 海外锑矿弹性，PE20-30x |
| 厦门钨业 | 75-100 | 钨一体化溢价，PE35-50x需消化 |
| 洛阳钼业 | 16-24 | 钴铜量价齐升，PE15-25x最合理 |
| 中国铝业 | 8-11 | 铝主业驱动，PE10-13x |
| 云南锗业 | 70-120 | ⚠️纯叙事定价，无利润支撑，区间极宽 |
| 北方稀土 | 40-60 | 轻稀土价格温和回升，PE50-75x |
| 中国稀土 | 40-80 | ⚠️整合预期定价，盈利弱 |

**化合物半导体参考区间**：

| 标的 | 参考区间(元) | 逻辑 |
|------|-------------|------|
| 三安光电 | 14-22 | 亏损→微利转折区间，看长沙基地进度 |
| 乾照光电 | 16-25 | InP外延+LED混合，PE偏高 |
| 沃尔德 | 80-130 | 金刚石刀具稳健但PE偏高 |

**触发条件**（判断基准情景成立）：
1. 锑价维持在12-17万/吨区间（不跌破12万、不暴涨超20万）
2. 中国出口管制政策无重大调整
3. Q2/Q3季报利润环比增长>20%（湖南黄金/洛阳钼业）
4. SiC衬底6寸价格维持2000-3000元/片（过剩但不崩盘）

### 情景 B：乐观情景（概率 ~20-25%）

**假设**：中国进一步收紧出口管制（增加铟/钼管制）+光伏/军工需求超预期增长+InP 6寸国产突破+铜钴价格再创新高

**触发条件**：
1. 商务部宣布对铟/钼实施出口管制
2. 光伏玻璃出货量季度增速>30%
3. InP 6寸衬底国产量产宣布（乾照光电/有研半导体）
4. 铜价突破$12000/吨，钴价回升至$25+/kg
5. 洛阳钼业TFM+KFM季度产量超指引

**各标的参考区间**：

| 标的 | 参考区间(元) | 逻辑 |
|------|-------------|------|
| 湖南黄金 | 30-45 | 锑价突破20万/吨，利润爆发 |
| 华钰矿业 | 25-40 | 海外锑矿弹性最大化 |
| 厦门钨业 | 85-120 | 钨战略溢价+深加工利润释放 |
| 洛阳钼业 | 20-28 | 钴铜双升+非洲矿山超产 |
| 云南锗业 | 100-150 | ⚠️锗管制加剧+GaAs突破，但PE仍极端 |
| 乾照光电 | 20-30 | InP突破催化，但利润兑现需时间 |

### 情景 C：悲观情景（概率 ~20-25%）

**假设**：中国部分放松出口管制+小金属价格高位回落+季报利润不及预期+SiC过剩加剧

**触发条件**：
1. 商务部放宽锑/钨出口许可审批（增加配额或简化流程）
2. 锑价回落至12万/吨以下
3. 湖南黄金/洛阳钼业季报利润环比下降>15%
4. SiC衬底6寸价格跌破1500元/片

**各标的参考区间**：

| 标的 | 参考区间(元) | 逻辑 |
|------|-------------|------|
| 湖南黄金 | 18-25 | 锑价回落+金价波动 |
| 华钰矿业 | 15-22 | 海外矿风险+锑价回落 |
| 厦门钨业 | 60-80 | 钨价回调+PE消化 |
| 洛阳钼业 | 14-18 | 钴价回落+刚果金风险 |
| 云南锗业 | 50-80 | 泡沫破裂，回归基本面 |
| 中国稀土 | 30-50 | 整合不及预期+盈利弱 |
| 三安光电 | 10-16 | 亏损扩大+SiC拖累 |

### 情景 D：极端风险情景（概率 ~5-10%）

**假设**：中美关系突然缓和→管制全面放松 或 台海冲突升级→全球供应链中断

**触发条件**：极端地缘事件或全球金融系统性风险

**参考动作**：无条件收缩，等待风险释放后重新评估

## 五、仓位参考框架

> 以下为研究框架建议的仓位思路，非具体仓位指令。

- **总仓位态度**：中风险 → 适度敞口
- **组合内部配比建议**：
  - 核心仓位（确定性最高、估值最合理）：洛阳钼业 → 40%
  - 卫星仓位（高弹性但有基本面支撑）：湖南黄金 → 30%

- **⚠️当前不宜入场**：小金属板块处于涨停潮情绪高峰，需等待1-2周情绪退潮后再评估入场时机
