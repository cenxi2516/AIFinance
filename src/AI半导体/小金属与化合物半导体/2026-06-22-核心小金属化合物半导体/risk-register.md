# 风险注册表 — 核心小金属与化合物半导体

> 每条风险必须绑定具体的触发条件——"当 X 发生时，风险 Y 兑现"。

---

## 一、宏观风险

### R1: 全球经济衰退导致需求断崖

- **风险描述**：如果全球制造业PMI持续低于45，新能源/军工/光伏需求增速将大幅放缓，小金属需求端支撑消失
- **风险类别**：宏观 — 经济周期
- **触发条件**：全球制造业PMI连续3个月<45 + 中国光伏装机增速同比下滑>20%
- **前置信号**：PMI连续2个月<48；光伏组件出口数据连续下滑；铜价周线跌破MA60
- **影响程度**：重度
- **当前概率**：低（<15%）
- **概率依据**：全球PMI当前温和复苏，中国新能源政策支撑明确
- **时间窗口**：2026-2027
- **影响标的**：全板块（需求端共同打击）
- **应对预案**：
  - 信号初现 → 减仓至半仓，只保留估值最合理的洛阳钼业
  - 信号确认 → 退出锑/钨等纯资源标的，仅保留中国铝业(镓利润占比低但铝主业可对冲)
  - 风险兑现 → 全部清仓，等待经济复苏信号

## 二、政策与监管风险

### R2: 中国放松小金属出口管制

- **风险描述**：如果商务部放宽锑/镓/锗/钨出口许可审批（如简化流程、增加配额），海外供应恢复，稀缺溢价瞬间消失
- **风险类别**：政策 — 出口管制放松
- **触发条件**：商务部公告宣布放宽出口许可审批 或 出口配额增加>50%
- **前置信号**：商务部官员表态"考虑优化出口流程"；中国对美贸易谈判中出现小金属议题；出口量环比突然增加>30%
- **影响程度**：颠覆级（thesis完全失效）
- **当前概率**：中（15-25%）
- **概率依据**：管制是中美科技博弈的反制工具，放松取决于中美关系走向；2025年未出现放松迹象但博弈仍在动态演进
- **时间窗口**：随时可能发生（政策突变型风险）
- **影响标的**：全板块——锑/镓/锗/钨/稀土全部受冲击
- **应对预案**：
  - 信号初现 → 立即减仓至1/3仓位
  - 信号确认 → 无条件退出锑/钨/镓/锗/稀土标的
  - 风险兑现 → 清仓，等待价格稳定后重新评估(无稀缺溢价的新均衡)

### R3: 刚果金矿业法规调整（影响洛阳钼业）

- **风险描述**：刚果金政府可能再次调整矿业法规（权益金税率、矿业许可条件），导致TFM/KFM矿山运营成本上升或产量受限
- **风险类别**：政策 — 海外矿业法规
- **触发条件**：刚果金政府宣布新矿业法规 或 TFM/KFM权益金争议重新爆发
- **前置信号**：刚果金矿业部长公开发言调整法规；洛阳钼业公告提及权益金争议；非洲矿业新闻频繁报道政策变化
- **影响程度**：重度（洛阳钼业thesis部分失效）
- **当前概率**：中（15-25%）
- **概率依据**：2023年TFM权益金争议已解决，但刚果金政策环境不稳定是长期现实
- **时间窗口**：随时
- **影响标的**：洛阳钼业(603993)
- **应对预案**：
  - 信号初现 → 洛阳钼业降至观察仓位
  - 信号确认 → 退出洛阳钼业，替换为其他小金属标的
  - 风险兑现 → 清仓洛阳钼业

### R4: 塔吉克斯坦政治风险（影响华钰矿业）

- **风险描述**：华钰矿业康桥奇锑矿位于塔吉克斯坦，政治不稳定可能导致矿山停产或股权争议
- **风险类别**：政策 — 海外政治风险
- **触发条件**：塔吉克斯坦政局动荡 或 康桥奇矿产量突然大幅下降
- **前置信号**：塔吉克矿业新闻异常；华钰矿业公告提及产量下降或运营障碍
- **影响程度**：重度
- **当前概率**：中（20-30%）
- **概率依据**：塔吉克斯坦政治稳定性历来较弱；海外矿山运营风险是已知风险
- **时间窗口**：随时
- **影响标的**：华钰矿业(601020)
- **应对预案**：
  - 信号初现 → 华钰矿业降至观察仓位
  - 信号确认 → 退出华钰矿业
  - 风险兑现 → 清仓华钰矿业

## 三、产业链风险

### R5: SiC衬底过剩周期加剧

- **风险描述**：SiC衬底6寸价格已暴跌50%+，产能利用率<50-60%，如果8寸量产推迟+EV渗透率持续低于预期，过剩将进一步加剧
- **风险类别**：产业链 — 产能过剩
- **触发条件**：6寸SiC衬底价格跌破1500元/片 或 天岳先进毛利率连续2季<15%
- **前置信号**：SiC衬底厂商库存持续增加；Wolfspeed再次发布财务预警；EV SiC渗透率数据低于预期
- **影响程度**：重度（SiC相关标的thesis失效）
- **当前概率**：高（>40%）
- **概率依据**：过剩已经是进行中的事实，不是潜在风险
- **时间窗口**：2026-2027（过剩周期预计持续2年）
- **影响标的**：天岳先进(688034)、三安光电(600703 SiC业务部分)
- **物理约束**：8寸SiC量产需2-3年良率爬坡；EV SiC渗透率提升受车企成本敏感度限制（800V平台普及不及预期）
- **应对预案**：
  - 已回避天岳先进
  - 三安光电仅作为化合物半导体平台观察，不因SiC单独建仓

### R6: GaN替代GaAs射频市场

- **风险描述**：GaN-on-SiC在高功率/高频射频领域正在侵蚀GaAs市场份额，如果替代加速，GaAs衬底需求逻辑减弱
- **风险类别**：产业链 — 技术替代
- **触发条件**：GaN射频器件在5G基站PA市场份额>30%（当前<10%）
- **前置信号**：主要基站厂商宣布切换GaN PA方案；GaAs PA出货量增速放缓
- **影响程度**：中度（GaAs逻辑减弱但不颠覆——移动PA仍是GaAs主导）
- **当前概率**：低（<15%）
- **概率依据**：移动终端PA仍以GaAs为主（功率/成本约束），GaN替代主要在基站侧
- **时间窗口**：2027-2029（替代是渐进的）
- **影响标的**：云南锗业(GaAs衬底)、乾照光电(GaAs外延)
- **应对预案**：持续跟踪GaN/GaAs射频市场份额变化，当前不影响优先级

### R7: 海外小金属替代供应投产

- **风险描述**：加拿大Teck、比利时Umicore、澳大利亚Lynas等海外矿产/回收项目扩产，如果规模投产将缓解供应紧张
- **风险类别**：产业链 — 替代供应
- **触发条件**：海外新项目投产规模>全球需求5% 且 中国以外产量占比提升>10个百分点
- **前置信号**：海外项目宣布量产时间表；再生镓/铟回收率数据改善
- **影响程度**：中度（缓解但不颠覆——中国份额仍是压倒性的）
- **当前概率**：低（<10%）
- **概率依据**：海外项目开发周期3-5年，2026年不可能大规模投产
- **时间窗口**：2028-2030（远期风险）
- **影响标的**：全板块（缓解程度有限）
- **应对预案**：长期跟踪海外项目进展，2028年前不影响短期thesis

## 四、公司层面风险

### R8: 云南锗业估值泡沫破裂

- **风险描述**：PE 3787x意味着当前利润极低，锗+GaAs逻辑虽硬但估值已严重透支未来数年增长
- **风险类别**：公司 — 估值泡沫
- **触发条件**：云南锗业季报利润未大幅增长 或 锗价回调>20%
- **前置信号**：PE维持>500x但利润环比无改善；大股东减持公告；交易所问询函
- **影响程度**：重度（泡沫品种跌幅可能超50%）
- **当前概率**：高（>40%）
- **概率依据**：PE 3787x在A股历史上几乎所有案例最终都大幅回调
- **时间窗口**：2026Q3季报发布前后
- **影响标的**：云南锗业(002428)
- **量化阈值**：PE>500x且季度利润环比增长<30%
- **应对预案**：
  - 当前不建仓（已回避）
  - 如果锗价持续高位+季报利润大幅增长+PE降至<100x → 可重新评估入场

### R9: 中国稀土盈利能力持续偏弱

- **风险描述**：PE 295x+PB 14.22x，盈利能力极弱，中重稀土整合预期虽强但执行进度不确定
- **风险类别**：公司 — 盈利能力弱+估值泡沫
- **触发条件**：连续2季净利润<预期50% 或 PE维持>200x
- **前置信号**：季报利润不及预期；集团整合进度慢于预期
- **影响程度**：重度
- **当前概率**：高（>40%）
- **时间窗口**：持续
- **影响标的**：中国稀土(000831)
- **应对预案**：已回避，不建仓

### R10: 三安光电持续亏损

- **风险描述**：化合物半导体平台逻辑虽完整，但SiC过剩拖累+LED主业下滑+巨额资本开支，亏损状态持续
- **风险类别**：公司 — 亏损+资本开支压力
- **触发条件**：连续2季净利润为负 或 经营现金流持续低于资本开支
- **前置信号**：季报亏损扩大；长沙基地投产进度慢于预期；SiC业务毛利率<20%
- **影响程度**：重度
- **当前概率**：中（30-40%）
- **概率依据**：SiC过剩是确定性风险，LED行业也在周期底部
- **时间窗口**：2026-2027
- **影响标的**：三安光电(600703)
- **应对预案**：仅作为观察标的，等待扭亏信号后再考虑入场

## 五、市场行为风险

### R11: 小金属涨停潮后情绪退潮踩踏

- **风险描述**：锑/钨等品种今日普遍涨停(+9-10%)，情绪过热。涨停潮结束后追涨资金可能踩踏出逃
- **风险类别**：市场行为 — 情绪过热/踩踏
- **触发条件**：板块连续3日无涨停 且 成交量骤降>50% 且 龙虎榜显示游资席位大额净卖出
- **前置信号**：涨停板数量减少；换手率开始下降；融资余额增速放缓
- **影响程度**：重度（短期跌幅可能超30%）
- **当前概率**：中（25-35%）
- **概率依据**：小金属板块今日集体涨停是典型情绪高潮，高潮后必有退潮
- **时间窗口**：1-4周
- **影响标的**：全板块（情绪退潮不分好坏品种）
- **应对预案**：
  - 不追涨！等待回调后再评估入场时机
  - 情绪退潮后只保留基本面最硬的品种（湖南黄金/洛阳钼业）

## 七、风险交互分析

> 最危险的不是单一风险，而是多个风险同时兑现。

| 风险组合 | 概率 | 叠加效应 | 如果同时兑现的后果 |
|---------|------|---------|------------------|
| R2(管制放松) + R11(情绪退潮) | 5-10% | 稀缺溢价消失+资金踩踏 | 全板块跌幅30-50%，龙头跌幅20-30% |
| R3(刚果金) + R4(塔吉克) | <5% | 两大海外矿山同时受阻 | 洛阳钼业+华钰矿业双双暴跌，但反而加剧国内锑紧缺 |
| R5(SiC过剩) + R10(三安亏损) | 30-40% | SiC业务拖累+LED周期底部 | 三安光电亏损扩大，估值进一步下移 |
| R1(衰退) + R2(管制放松) | <5% | 需求消失+供给恢复 | 最极端组合——但经济衰退时管制放松的可能性反而更低 |
