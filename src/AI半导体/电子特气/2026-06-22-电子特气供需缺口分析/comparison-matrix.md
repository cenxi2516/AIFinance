## 排名逻辑说明

排序核心逻辑是"最紧缺品种的产能暴露度"：

1. **南大光电排第一**：WF6是紧缺度最高的品种，南大光电是唯一国产实质产能，"品种稀缺性+产能唯一性"双重加持。MO源业务提供安全垫，即使WF6延迟也不会"归零"。

2. **华特气体排第二**：同时覆盖CH3F+WF6+C4F8三个最紧缺品种，"多品种紧缺"弹性最大。但科创板流动性风险+估值偏高是制约。

3. **派瑞特气排第三**：NF3市占率第一，C4F8/CH3F有增量。但NF3价格下行是最大拖累，需NF3止跌才能升级。

4. **其余标的**：紧缺品种暴露度低或仍在建设期，降级为观察。

宏观约束对排序的影响：环评/安评审批周期18-36月 → 已有产能的标的（南大/华特/派瑞）享受壁垒保护，新进入者难快速追赶 → 强化先发优势排序。

## 什么情况会改变排序

1. **南大光电WF6扩产超预期** → 确认核心地位，拉开与其他标的差距
2. **NF3价格止跌回升** → 派瑞特气从第三升至第二
3. **华特气体CH3F认证失败** → 从第二降至第四以下
4. **金宏/和远硅烷项目提前投产且认证通过** → 可能升至第四
5. **行业安全事故→环评冻结** → 已有产能标的价值重估，排序不变但估值锚点上移
