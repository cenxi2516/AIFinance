# 风险注册表：电子特气供需缺口

> 专业投资者的第一课：**先看风险，再看机遇。**
> 每条风险绑定具体触发条件——"当 X 发生时，风险 Y 兑现"。

---

## 一、宏观风险

### R1: 半导体capex见顶/放缓

- **风险描述**：全球半导体资本开支见顶或显著放缓，导致下游晶圆厂推迟扩产计划，电子特气需求增速大幅下降
- **风险类别**：宏观 — 经济周期
- **触发条件**：(1) ≥2家国内晶圆厂推迟/取消扩产计划 (2) 全球半导体capex同比增速转负 (3) 北美CSP下调数据中心capex指引
- **前置信号**：半导体设备公司订单增速放缓 → 晶圆厂产能利用率下降 → 气体消耗量增速放缓
- **影响程度**：重度
- **当前概率**：中（15-25%）
- **概率依据**：AI需求仍在驱动capex增长，但全球宏观不确定性较高，若海外衰退则需求端承压
- **时间窗口**：2026Q3-2027Q2
- **影响标的**：全部7家候选标的，南大光电/华特气体影响最大（纯度最高）
- **应对预案**：
  - 信号初现 → 降低仓位至半仓，密切跟踪晶圆厂capex数据
  - 信号确认 → 仅保留WF6/CH3F暴露度最高的标的，其余移除
  - 风险兑现 → 全部清仓，等待需求端恢复信号

---

## 二、政策与监管风险

### R2: 环评/安评/能评审批全面收紧

- **风险描述**：环保/安全生产政策全面收紧，新建电子特气产能审批冻结，导致扩产计划无法如期释放
- **风险类别**：政策 — 环保能耗
- **触发条件**：(1) 行业重大安全事故后政策一刀切 (2) 新增产能环评审批周期延长至>36月 (3) 已批复项目被要求补充环评
- **前置信号**：同行业安全事故 → 监管发文收紧 → 审批进度放缓
- **影响程度**：颠覆（对扩产型标的） / 利好（对已有产能的标的，壁垒抬升）
- **当前概率**：低（<15%）
- **概率依据**：电子特气属政策鼓励方向（国产替代），全面冻结可能性低；但局部安全事故可能引发阶段性收紧
- **时间窗口**：随时（事件驱动型）
- **影响标的**：扩产中的标的（南大光电/华特气体/和远气体）风险最大；已有产能（派瑞特气）反而受益
- **应对预案**：
  - 信号初现 → 区分已有产能 vs 在建产能，加仓已有产能标的
  - 信号确认 → 退出扩产依赖型标的，保留产能型标的
  - 风险兑现 → 壁垒逻辑反转，已有产能标的价值重估

### R3: 出口管制扩展至电子特气领域

- **风险描述**：美国BIS将电子特气或其关键原材料/设备纳入出口管制清单
- **风险类别**：政策 — 出口管制
- **触发条件**：BIS实体清单扩展至包含电子特气企业或其上游设备/催化剂供应商
- **前置信号**：BIS对半导体材料领域的管制政策信号 → 中国相关企业被加入实体清单
- **影响程度**：重度（如果管制关键催化剂/纯化设备） / 利好（如果只管制成品气，反而加速国产替代）
- **当前概率**：低（<10%）
- **概率依据**：电子特气本身不在管制清单上，且中国是净进口国，管制成品气对中国影响有限反而刺激国产替代
- **时间窗口**：2026-2027
- **影响标的**：依赖进口设备/催化剂的标的影响最大
- **应对预案**：
  - 信号初现 → 评估受影响标的的上游依赖度
  - 信号确认 → 如果管制催化剂/设备，退出相关标的；如果管制成品气，加仓国产替代标的

## 三、产业链风险

### R4: NF3/CF4产能过剩引发价格战

- **风险描述**：NF3和CF4产能释放过快，供过于求导致价格持续下行，拖累整体板块盈利能力和估值
- **触发条件**：(1) NF3价格跌破4万/吨且持续2季+ (2) 派瑞特气NF3毛利率连续2季下降≥300bp (3) 行业出现恶性价格战（低于成本价销售）
- **前置信号**：NF3产能投放加速 → 价格环比持续下降 → 毛利率收窄
- **影响程度**：重度（对NF3/CF4为主营的标的） / 中度（对多品种布局的标的，市场情绪拖累）
- **当前概率**：中（20-30%）
- **概率依据**：NF3价格2022-2024已累计下降30-40%，产能仍在释放，价格战风险真实存在
- **时间窗口**：2026H2-2027
- **影响标的**：派瑞特气影响最大（NF3市占率第一），昊华科技次之
- **物理约束**：NF3产能建设周期12-18月，产能释放是渐进的，不是一夜之间过剩
- **应对预案**：
  - 信号初现 → 降低派瑞特气权重，加仓紧缺品种暴露度高的标的
  - 信号确认 → 派瑞特气降级为观察，南大光电/华特气体提升权重
  - 风险兑现 → 仅保留WF6/CH3F/C4F8逻辑标的

### R5: 高纯品种国产替代进度不及预期

- **风险描述**：WF6/CH3F/C4F8的5N+纯化技术突破慢于预期，产能爬坡延迟，客户认证不通过
- **触发条件**：(1) 南大光电WF6扩产延期>2季 (2) 华特气体CH3F 5N级认证失败或延期 (3) 国产化率2年内无显著提升
- **前置信号**：在建工程进度慢于公告 → 认证周期拉长 → 产能利用率低
- **影响程度**：中度（延迟但非失败，稀缺性逻辑仍在）
- **当前概率**：中（20-30%）
- **概率依据**：5N+纯化是已知的技术难题，爬坡期延迟在行业里是常态而非例外
- **时间窗口**：2026Q3-2027Q2
- **影响标的**：南大光电（WF6）、华特气体（CH3F）
- **物理约束**：纯化工艺从4N到5N每提升一个量级，难度指数级增长；客户认证周期12-24月
- **应对预案**：
  - 信号初现 → 重新评估技术突破时间线，延迟不等于失败
  - 信号确认 → 调整时间窗口，降低6-12月内的业绩预期
  - 风险兑现 → 如果技术路线被证明不可行（概率极低），关闭相关标的

## 四、公司层面风险

### R6: 核心标的估值偏高

- **风险描述**：科创板电子特气标的（华特气体/派瑞特气/金宏气体/正帆科技）估值偏高，若业绩不及预期则面临戴维斯双杀
- **风险类别**：公司 — 估值
- **触发条件**：(1) PE(TTM)>80x且季报收入增速<20% (2) 机构下调评级≥2家 (3) 股价从高点回落>30%
- **前置信号**：换手率持续下降 → 融资余额高位回落 → 机构持仓减少
- **影响程度**：中度
- **当前概率**：中（20-30%）
- **概率依据**：科创板电子特气标的PE普遍偏高，若NF3价格战+业绩不及预期同时出现，估值压力较大
- **时间窗口**：2026Q3-2027Q1
- **影响标的**：华特气体、派瑞特气估值风险最大
- **量化阈值**：PE>80x + 收入增速<20% = 高危；PE>60x + 收入增速>30% = 可接受
- **应对预案**：
  - 信号初现 → 严格按估值纪律，PE>80x不加仓
  - 信号确认 → 减仓至半仓以下
  - 风险兑现 → 退出高估值标的，转向低估值主板标的（昊华科技/和远气体）

## 五、市场行为风险

### R7: 电子特气主题退潮

- **风险描述**：市场对"国产替代"主题审美疲劳，资金撤出电子特气板块，估值系统性下移
- **风险类别**：市场行为 — 主题退潮
- **触发条件**：(1) 板块连续3月跑输沪深300 (2) 成交额萎缩至高峰期1/3以下 (3) 无新的催化剂
- **前置信号**：题材热度下降 → 北向/融资资金持续流出 → 成交量萎缩
- **影响程度**：中度
- **当前概率**：低-中（15-25%）
- **概率依据**：国产替代是长期逻辑，不易完全退潮；但短期资金可能转向其他热点
- **时间窗口**：2026Q3-Q4
- **影响标的**：全部标的，科创板标的流动性风险更大
- **应对预案**：
  - 信号初现 → 降低卫星仓位，保留核心仓位
  - 信号确认 → 仅保留基本面最强标的
  - 风险兑现 → 等待下一个催化剂，不逆势加仓

## 七、风险交互分析

| 风险组合 | 概率 | 叠加效应 | 如果同时兑现的后果 |
|---------|------|---------|------------------|
| R1 + R4 | 低-中(10-15%) | 需求萎缩+价格战 | 行业"量价齐跌"，板块整体被抛售 |
| R4 + R6 | 中(15-25%) | 价格战+估值杀 | 派瑞特气/华特气体戴维斯双杀风险最高 |
| R1 + R5 | 低(5-10%) | 需求萎缩+供给瓶颈 | 紧缺逻辑失效，但国产替代长期逻辑仍在 |
| R2 + R5 | 极低(<5%) | 审批冻结+技术突破慢 | 新产能完全无法释放，但已有产能标的反而受益 |
| **R3b + R5** | **低(5-10%)** | **纯化设备断供+国产纯化突破延迟** | **国内5N+特气产能断崖式下降，依赖进口的品种（WF6/CH3F）可能面临供应中断** |

**最危险组合**：R1(需求萎缩) + R4(价格战) — 行业从"结构性紧缺"转为"全面过剩"，需无条件收缩。
**结构性风险组合**：R3b(纯化设备断供) + R5(国产纯化突破延迟) — 即使需求不萎缩，国内纯化能力也可能因设备断供而大幅下降。
