# 可验证假设注册表：电子特气供需缺口

> 好的假设必须可证伪——你知道什么证据出现时会承认它错了。

---

## 假设列表

### H1: WF6供需缺口在2027年前不会显著收窄

- **假设内容**：WF6国产化率仍<20%，中国供需缺口维持3000吨/年以上，价格维持高位（>200万/吨）
- **前提/前置条件**：先进制程需求持续增长 + 全球WF6产能无大规模新增
- **验证信号**：(1) 南大光电年报WF6产能仍<1000吨/年 (2) WF6进口量未见显著下降 (3) WF6价格同比涨幅>20%
- **否定信号**：(1) 南大光电WF6产能突破2000吨/年且良率>80% (2) 华特气体WF6量产公告 (3) WF6价格同比下跌>15%
- **验证窗口**：2027-Q2 前
- **数据来源**：南大光电/华特气体年报、海关进出口数据、行业价格数据
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 南大光电维持核心标的地位
  - 证伪 → 南大光电WF6逻辑弱化，需重新评估

### H2: CH3F需求增速>20%/年将持续至2028年

- **假设内容**：先进制程占比提升驱动CH3F替代CHF3，CH3F需求增速维持25%+
- **前提/前置条件**：14nm及以下制程产能持续扩张 + CH3F替代CHF3趋势不变
- **验证信号**：(1) 晶圆厂先进制程产能占比提升 (2) CH3F进口量同比增速>20% (3) CH3F价格维持高位
- **否定信号**：(1) 出现CH3F的替代气体 (2) 先进制程扩产放缓 (3) CH3F价格开始下跌
- **验证窗口**：2027-Q4 前
- **数据来源**：华特气体年报CH3F分部收入、行业价格数据
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 华特气体CH3F逻辑强化
  - 证伪 → CH3F弹性逻辑弱化，但不影响C4F8/WF6逻辑

### H3: NF3价格将在2026-2027年继续下行15-25%

- **假设内容**：NF3产能释放导致供过于求，价格从当前5-7万/吨继续下行至4-5万/吨
- **前提/前置条件**：NF3新增产能按计划释放 + 需求增速<产能增速
- **验证信号**：(1) 派瑞特气NF3毛利率连续2季下降 (2) NF3现货价格环比持续下行 (3) NF3库存水平上升
- **否定信号**：(1) NF3价格止跌回升 (2) 产能投放延期 (3) 需求端出现超预期增长（如面板产能扩张）
- **验证窗口**：2027-Q1 前
- **数据来源**：派瑞特气季报毛利率、NF3价格数据
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 派瑞特气降级，NF3逻辑标的移除
  - 证伪 → 重新评估NF3供需格局

### H4: 南大光电WF6产能2026年可扩至1500吨/年以上

- **假设内容**：南大光电WF6扩产项目如期释放，产能从当前500-800吨/年扩至1500-2000吨/年
- **前提/前置条件**：5N-6N纯化技术突破 + 环评安评审批通过 + 建设如期完成
- **验证信号**：(1) 在建工程金额环比大幅增加 (2) 年报披露WF6产能数据更新 (3) 新增客户认证公告
- **否定信号**：(1) 在建工程金额连续2季无变化（建设停滞） (2) 年报WF6产能未更新 (3) 无新客户认证公告
- **验证窗口**：2027-Q1 前（考虑12-24月建设周期）
- **数据来源**：南大光电季报/年报在建工程、产能披露
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 南大光电核心标的确认，加仓
  - 证伪 → 南大光电降级，WF6逻辑推迟

### H5: 华特气体CH3F 5N级产品2026年可获得≥2家晶圆厂认证

- **假设内容**：华特气体CH3F 5N级产品通过认证，进入量产供应阶段
- **前提/前置条件**：5N纯化良率稳定 + 客户认证周期12-24月 + 产品质量达标
- **验证信号**：(1) 华特气体公告CH3F客户认证通过 (2) CH3F分部收入环比增长>50% (3) 客户名单新增
- **否定信号**：(1) 无认证通过公告且认证已>18月 (2) CH3F分部收入无增长 (3) 客户反馈质量问题
- **验证窗口**：2027-Q1 前
- **数据来源**：华特气体公告、年报CH3F分部收入
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 华特气体核心标的确认
  - 证伪 → 华特气体CH3F逻辑弱化，但C4F8/WF6逻辑仍在

### H6: 电子特气行业环评/安评审批不会系统性冻结

- **假设内容**：电子特气属政策鼓励方向，环评/安评审批维持正常节奏，无全面冻结
- **前提/前置条件**：无重大行业安全事故 + 政策层面继续鼓励国产替代
- **验证信号**：(1) 行业新项目环评审批周期维持在18-24月正常水平 (2) 南大光电/华特气体在建工程持续增长
- **否定信号**：(1) 行业重大安全事故 (2) 多个项目环评被拒或审批周期>36月 (3) 监管发文全面收紧
- **验证窗口**：持续跟踪
- **数据来源**：环评公告、在建工程数据
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 扩产逻辑成立，维持现有排序
  - 证伪 → 已有产能标的价值重估，扩产型标的降级

### H7: 纯化设备/工艺才是电子特气产业链的真正稀缺层

- **假设内容**：电子特气的稀缺瓶颈不在合成产能而在5N+纯化工艺和设备，掌握纯化技术的企业拥有持续竞争优势
- **前提/前置条件**：5N+纯化技术壁垒持续存在 + 无法通过简单砸钱快速突破
- **验证信号**：(1) 拥有纯化技术的企业毛利率显著高于无纯化技术的企业 (2) 新进入者纯化良率远低于先发者 (3) 纯化设备进口依赖度高
- **否定信号**：(1) 新进入者快速达到5N纯化水平 (2) 纯化设备实现国产替代 (3) 纯化良率差异缩小
- **验证窗口**：2027-Q4 前
- **数据来源**：各公司年报毛利率对比、纯化设备进口数据
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 拥有纯化技术的企业（南大/华特）估值应享有溢价
  - 证伪 → 行业竞争格局可能比预期更激烈
