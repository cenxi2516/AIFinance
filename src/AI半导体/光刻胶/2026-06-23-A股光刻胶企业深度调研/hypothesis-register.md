- **验证信号**：公司公告明确表述"量产认证通过"或"进入批量供货阶段"；光刻胶分部收入实现50%+同比增长
- **否定信号**：2027H1前公告中仅出现"验证推进中""持续优化"等模糊表述且无明确量产节点；光刻胶收入增速连续2季低于30%
- **验证窗口**：2027-Q2前
- **数据来源**：彤程新材季度报告/公告；一线Foundry供应商名录
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 彤程新材优先级升至1（维持），确认加仓逻辑
  - 证伪 → 彤程新材优先级降至3以下，ArF国产替代叙事整体降温

### H2: 南大光电ArF光刻胶在2026年内无法获得一线Foundry量产认证

- **假设内容**：由于多线分散和验证进度滞后，南大光电ArF光刻胶在2026年内无法实现一线Foundry量产认证

- **验证信号**：2026年四季报中光刻胶业务收入仍为"小批量试用"口径；无一线Foundry量产认证公告
- **否定信号**：2026年内公告获得一线Foundry量产认证；光刻胶收入占比突破5%
- **验证窗口**：2026-Q4前
- **数据来源**：南大光电季度报告/公告
- **验证结果**：pending
- **验证日期**：

  - 证实 → 南大光电维持当前优先级2，但投资价值进一步被彤程拉开
  - 证伪 → 南大光电重回ArF竞赛第一梯队，优先级可能与彤程并列

### H3: 国际巨头将在中国市场采取"降价10-30%+延长账期"策略延缓国产替代

- **假设内容**：JSR、信越化学、东京应化等日本光刻胶巨头将在国产光刻胶突破关键节点时降价10-30%，并提供更长账期，削弱国产替代的成本竞争力
- **前提/前置条件**：国产光刻胶即将通过认证或已初步放量；日本企业不愿放弃中国市场份额
- **验证信号**：晶圆厂采购数据显示进口光刻胶单价同比明显下降；行业媒体报道"日企降价"；国产光刻胶企业毛利率承压
- **否定信号**：日本进一步收紧出口导致供应减少，价格反而上涨（R2兑现）
- **验证窗口**：2026-Q4至2027-Q4（与ArF认证窗口同步）
- **数据来源**：行业媒体（二级）；晶圆厂年报采购数据（一级）；上市公司毛利率变化
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → 全板块利润空间被压缩，估值中枢下移，增长预期需下调
  - 证伪 → 国产替代商业逻辑更通畅，优先級维持或上升

### H4: 徐州博康PHS树脂3年内无法实现半导体级批量供货

- **假设内容**：由于分子量分布控制和批次一致性等技术挑战，徐州博康的PHS树脂在2029年前无法实现半导体级批量供货
- **前提/前置条件**：PHS树脂合成技术壁垒极高（全球仅3-4家掌握）；博康虽有进展但数据不透明
- **验证信号**：2029年前无公开信息表明博康PHS树脂通过下游光刻胶厂商验证；华懋科技年报中博康投资收益无显著增长
- **否定信号**：博康公告PHS树脂批量供货；彤程新材或其他光刻胶企业公告使用国产PHS树脂
- **验证窗口**：2029-Q4前
- **数据来源**：华懋科技年报；博康公开信息；行业媒体
- **验证结果**：pending
- **验证日期**：
- **对优先级的影响**：
  - 证实 → ArF光刻胶上游安全仍是盲区，整体板块风险溢价维持高位
  - 证伪 → 产业链最稀缺环节被突破，华懋科技（博康）逻辑逆转，优先级大幅上升
