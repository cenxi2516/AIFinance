# 光刻胶行业情景推演

> 分析主题：中国A股光刻胶企业
> 创建日期：2026-06-23

## 核心变量

1. **ArF光刻胶认证进展**：彤程新材/南大光电/鼎龙股份是否获得一线Foundry量产认证
2. **日本出口政策**：是否升级对华光刻胶树脂/PAG出口管制
3. **国内晶圆厂扩产节奏**：中芯/华虹/长存 capex 变化
4. **国际巨头定价策略**：降价围堵力度
5. **上游树脂/PAG国产化**：威迈芯材/八亿时空/徐州博康的放量进度
6. **AI加速材料研发**：AI+自动化合成能否缩短树脂开发周期

## 情景一：基准情景（概率 45-50%）

### 前提
- ArF光刻胶验证推进但2026年内未获大规模量产认证（已有小批量销售）
- 日本出口政策维持现状（收紧趋势但未全面禁止）
- 国内晶圆厂温和扩产，capex增速10-15%
- 国际巨头局部降价，但幅度有限
- 上游树脂/PAG国产化稳步推进（八亿/威迈持续放量）

### 标的影响

| 标的 | 估值变化 | 光刻胶业务 | 股价判断 |
|------|---------|-----------|---------|
| 彤程新材 | PE 73x → 65-80x | KrF+ArF持续放量，树脂自供占比提升 | 温和上涨，估值中枢上移 |
| 鼎龙股份 | 2026E PE 43x → 40-55x | 300吨产线利用率爬坡至40-50%，光刻胶收入2-4亿 | 稳健上涨，CMP安全垫+光刻胶弹性逐步兑现 |
| 南大光电 | PE 140x → 110-150x | ArF小批量持续，无重大突破 | 高位震荡，估值略承压 |
| 雅克科技 | PE 适中 → 稳定 | 面板+半导体光刻胶收入突破20亿 | 稳健，增速匹配估值 |
| 晶瑞电材 | 略有压力 | i线稳定，KrF缓慢推进 | 横盘偏弱 |
| 上海新阳 | PE 70x → 60-80x | 电镀液驱动增长 | 稳健 |
| 八亿时空 | PE 高 → 震荡 | KrF树脂收入从1000万→5000万 | 高波动，放量验证期 |

## 情景二：乐观情景（概率 20-25%）

### 前提
- 彤程新材/鼎龙股份 ArF光刻胶 2026H2-2027H1 获得一线Foundry量产认证（28nm及以上节点）
- 日本维持现状或经济利益考量下不会全面禁止
- 国内晶圆厂加速扩产 + 国产替代政策加码（"十五五"明确考核国产化率）
- 国际巨头降价幅度有限（<15%）
- 八亿时空树脂进入彤程/鼎龙供应链，威迈芯材PAG覆盖国内主要光刻胶厂商

### 标的影响

| 标的 | 估值变化 | 股价判断 |
|------|---------|---------|
| 彤程新材 | PE → 80-100x | 标志性突破，估值大幅扩张，涨幅50%+ |
| 鼎龙股份 | 2026E PE → 55-70x | CMP+光刻胶双轮驱动逻辑确立，涨幅40%+ |
| 南大光电 | PE → 150-180x | 跟涨，但认证进度差距可能拉大 |
| 八亿时空 | PE → 大幅扩张 | 树脂独立供应商稀缺性获定价 |
| 雅克科技 | PE → 温和扩张 | 受板块情绪带动 |

### 关键催化剂叠加
- ArF量产认证公告 → 市场定价"国产替代从故事到现实"
- 日本经产省无新管制措施 → 短期解除最大不确定性
- 大基金三期光刻胶项目落地 → 政策资金双重背书

## 情景三：悲观情景（概率 20-25%）

### 前提
- ArF认证受阻或大幅延期（批次一致性/良率问题导致验证周期延长至36月+）
- 日本升级出口管制，限制ArF级PHS树脂/PAG对华供应
- 全球半导体周期下行，晶圆厂削减capex 15-20%
- 国际巨头大幅降价20-30%围堵国产

### 标的影响

| 标的 | 估值变化 | 股价判断 |
|------|---------|---------|
| 彤程新材 | PE → 45-55x | 双重打击（认证受阻+树脂断供风险），杀估值30-40% |
| 南大光电 | PE → 70-90x | 多线拖累+树脂完全依赖进口，杀估值更严重 |
| 鼎龙股份 | PE → 30-38x | 相对抗跌（CMP基本盘支撑），但光刻胶期权价值归零 |
| 晶瑞电材 | PE → 估值收缩 | i线竞争加剧，利润承压 |
| 上海新阳 | 相对抗跌 | 电镀液基本盘较稳，光刻胶投入可控 |
| 八亿时空 | PE → 大幅杀跌 | KrF树脂国产化逻辑未变但市场情绪恶化 |

### 关键恶化信号
- 日本经产省将ArF树脂列入出口管制清单
- 彤程新材公告"验证仍在推进"但超24月无实质进展
- 全球半导体BB值连续3月<1
- JSR/TOK在中国市场降价公告

## 情景四：极端情景（概率 5-10%）

### 前提
- 日本全面禁止对华ArF树脂/PAG出口
- 中美科技对抗急剧升级（台海/南海地缘事件触发）
- 国产ArF光刻胶逻辑基础坍塌
- 国际巨头全面断供而非降价

### 标的影响
- 全线暴跌，光刻胶主题标的跌幅40-60%+
- 唯一幸存逻辑：徐州博康（全链条自主）+ 威迈芯材（PAG自主）+ 八亿时空（树脂自主）
- 但短期内产能远不足以填补缺口，更多是"战略性存活"而非"商业性获益"

### 底线判断
即使在此极端情景下，国内晶圆厂仍有6-12个月的光刻胶库存（保质期限制），不会立即停产。但12个月后如果没有替代方案，28nm以上产线将面临真实停产风险。

---

## 情景五：AI加速情景（概率 10-15%，中长期）

### 前提
- 2026年5月上海AI实验室联合厦门大学、苏州国家实验室，通过AI+自动化合成攻克高端KrF光刻胶树脂稳定制备难题（批次稳定性±10%，PDI<1.3）
- 如果AI方法可迁移至ArF树脂研发，开发周期可能从10年压缩至2-3年
- 商业模式：AI驱动的材料研发平台为国内光刻胶厂商提供树脂定制服务

### 标的影响

| 标的 | 影响 | 逻辑 |
|------|------|------|
| 彤程新材 | 最直接受益 | 如果AI加速ArF树脂自研，树脂自供时间表大幅提前 |
| 八亿时空 | 双重影响 | 短期：AI可能降低树脂合成壁垒，更多竞争者进入；长期：AI可帮助优化现有产品 |
| 南大光电 | 间接受益 | 如果国内树脂供应突破，可降低对外依赖 |
| 徐州博康 | 相对受益减少 | 全链条自主的稀缺性可能因AI加速而下降 |

### 时间线估计
- 2026-2027：KrF树脂AI优化成果工业化验证
- 2027-2029：ArF树脂AI研发方法迁移
- 2029-2031：如果成功，国产ArF树脂规模化供应成为可能

> ⚠️ 此情景的不确定性极高。AI在材料科学中的应用仍处于早期，"实验室成功→工业化放大"的鸿沟巨大。
- 但此情景下，拥有树脂自给能力的徐州博康（华懋参股）反而可能是唯一幸存逻辑
- 催生"树脂自给"新主线
