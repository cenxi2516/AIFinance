# 光刻胶上游核心原材料深度分析：树脂 & PAG

> 分析日期：2026-06-23
> 核心判断：上游树脂和 PAG 是光刻胶产业链中**最被低估的稀缺层**，当前国产化率几乎为零，但 2025-2026 年出现了多个"从 0 到 1"的突破信号。

## 一、为什么上游比光刻胶成品更关键

### 1.1 成本结构与技术壁垒

光刻胶的成本结构中，**树脂占约 50%，PAG（光致产酸剂）占约 15%**：

```
光刻胶成本拆解：
├── 树脂（Resin）：~50% ← 决定成膜性能 + 化学稳定性
├── 单体（Monomer）：~15% ← 合成树脂的基础原料
├── 光致产酸剂（PAG）：~15% ← 决定感光灵敏度和分辨率
├── 溶剂：~15% ← 调节粘度（技术壁垒相对较低）
└── 添加剂：~5% ← 配方核心机密
```

### 1.2 "树脂是光刻胶的芯片"

光刻胶配方的核心是**把树脂、PAG、溶剂、添加剂按精确比例调配**。配方可以通过逆向工程（元素分析+质谱）逐步逼近，但**树脂合成需要的是工艺参数数据库**——分子量分布（PDI<1.1）、末端基团结构精确控制、金属离子<1ppb——这不是花钱买设备就能解决的。

| 技术壁垒 | 树脂合成 | 光刻胶配方 |
|---------|---------|----------|
| 所需时间 | 10 年以上工艺积累 | 3-5 年配方迭代 |
| 核心障碍 | 阴离子聚合技术 + 纯化 | 配比优化 + 客户验证 |
| 可被 AI 加速程度 | 有限（需要物理实验数据） | 较大（配方空间搜索） |
| 全球供应商数量 | 3-4 家（信越、东曹、住友） | 6-8 家（JSR、TOK、信越、杜邦等） |
| 国产化率 | **<1%**（ArF/KrF 级） | KrF ~5-8%，ArF <2% |

> 结论：即使国产光刻胶配方突破，如果树脂供应被日本掐断，整个国产 ArF/KrF 光刻胶产业会"一夜归零"。

`★ Insight ─────────────────────────────────────`
**为什么日本能垄断光刻胶上游 40 年？**

1. **先发优势 + 捆绑生态**：日本企业在 1980 年代开始配合东京电子（TEL）、尼康的光刻机做光刻胶树脂研发。树脂-光刻胶-光刻机三者是深度耦合的——信越化学的树脂参数是为 JSR/TOK 的光刻胶定制的，而 JSR/TOK 的光刻胶又是为 TEL 的涂胶显影机优化的。这是一个封闭的日本生态。
2. **阴离子聚合的"暗知识"**：树脂合成中的关键步骤——阴离子活性聚合——极其依赖操作者的经验和工艺参数。温度波动 0.5℃、引发剂加料速度快 2 秒，都可能导致分子量分布失控。这些"暗知识"不在论文里，在产线操作工的脑子里。
3. **纯化的物理极限**：金属离子从 ppb（十亿分之一）控制到 ppt（万亿分之一），不是靠"过滤"能解决的。需要从原料、反应釜内衬、管道、包装容器全链条做超纯处理——每一环节都需要 10 年以上的供应商磨合。

## 二、树脂环节：核心企业分析

### 2.1 全球格局

| 企业 | 国家 | 核心产品 | 全球地位 |
|------|------|---------|---------|
| **信越化学** | 日本 | ArF PHS 树脂、KrF PHS 树脂 | **全球最大供应商**，几乎垄断 ArF 树脂 |
| **东曹** | 日本 | 特种聚合物树脂 | 信越之外的第二选择 |
| **住友化学** | 日本 | KrF/ArF 树脂 | 自用为主，少量外供 |
| **杜邦/陶氏** | 美国 | KrF 树脂（部分） | 份额较小，主要供应杜邦自家光刻胶 |

> **关键事实**：ArF 浸没式光刻胶所需的 PHS 树脂（聚羟基苯乙烯），全球仅信越化学等极少数企业能批量供应。这就是"瓶颈中的瓶颈"。

### 2.2 国产树脂突破进展

#### 彤程新材（北京科华）—— ArF 光刻胶厂商中树脂自供最领先

| 产品 | 状态 | 详情 |
|------|------|------|
| **PHS 树脂**（KrF 用） | ✅ **已量产自供** | 开发 PTBS-PHS 树脂并实现放大；多款量产 KrF 光刻胶**已搭载自产 PHS 树脂**；成本比外购低 15-20%，毛利率提升 20-30 个百分点 |
| 甲酚甲醛树脂（i 线用） | ✅ 中试完成 | 6 款切割甲酚甲醛树脂完成中试，金杂控制在 ppb 级别 |
| 丙烯酸树脂（ArF 用） | 🔄 开发中 | 已建立关键原材料供应、合成工艺及放大装置 |
| EBR 溶剂 | ✅ G4/G5 级已量产 | 年产 2 万吨 |

**核心判断**：彤程新材是 A 股光刻胶标的中，**唯一实现 KrF 树脂自供且有明确数据验证（毛利率提升 20-30pp）的企业**。ArF 树脂仍在开发中。

#### 徐州博康——国内唯一全产业链自主

| 维度 | 详情 |
|------|------|
| **产业链覆盖** | 单体 → 树脂 → PAG → 光刻胶成品，**100% 全链条自主** |
| **KrF 树脂** | 已自供，支撑 KrF 光刻胶量产 |
| **ArF 树脂** | 已有合成能力，支撑 ArFi 浸没式光刻胶获批量订单 |
| **护城河** | HTI560 系列 ArF 浸没式光刻胶实现原材料 **100% 国产化** |
| **产能** | 东阳 8000 吨光刻材料项目 2026 年投产 |
| **局限** | 未上市，通过华懋科技间接参股，数据不透明 |

**核心判断**：徐州博康的树脂自给能力是**中国光刻胶产业链中最稀缺的资产**。如果其 ArF 树脂能稳定量产并外供，将从根本上改变国产光刻胶的原料安全困境。但信息不透明是最大障碍。

#### 八亿时空（688181）—— 独立第三方树脂供应商

| 维度 | 详情 |
|------|------|
| **核心产品** | KrF 光刻胶用 PHS 树脂及衍生物，覆盖窄分布阴离子 + 宽分布自由基全系列 |
| **技术来源** | 液晶材料领域化学合成 + 纯化经验延伸 |
| **产能** | 上虞基地**百吨级**柔性/量产双产线已建成；二期 400 吨在建，达产后总产能 **500 吨/年** |
| **量产里程碑** | 2025 年 Q4 实现多款树脂**吨级出货**；2026 年加速放量 |
| **客户与合作** | 已与多家国内头部光刻胶厂家建立深度合作；子公司引入**厦门恒坤**（国内 12 英寸晶圆厂材料供应商）战略投资 11.11%，形成"树脂→光刻胶→晶圆厂"产业链联动 |
| **2025 年半导体材料收入** | 1086.83 万元（占比 1.28%），仍在早期 |
| **2026 年收入展望** | 5000 万-1 亿元 |
| **估值** | 2025 年营收 8.68 亿（液晶为主），净利润 8106 万；当前 PE 较高（光刻胶树脂预期溢价） |

**核心判断**：八亿时空是国内**唯一独立第三方 KrF 树脂量产供应商**。其战略价值在于：如果它能成为彤程/鼎龙/南大等光刻胶厂商的树脂供应商，将解决"树脂受制于日本"的系统性风险。但当前收入体量极小（<2%），且尚未盈亏平衡，需要持续跟踪放量节奏。

#### 万华化学 —— 化工巨头降维切入

| 维度 | 详情 |
|------|------|
| **产品** | 高性能光刻胶树脂（高疏水性、低浸出率） |
| **策略** | 以化工巨头的规模和纯化能力切入 |
| **进展** | 已实现量产（具体规模未公开），但主要用于面板光刻胶方向 |
| **优势** | 化工纯化能力 + 成本控制 + 产能规模 |
| **局限** | 半导体级 ArF 树脂尚未进入（对万华而言市场太小，优先级待定） |

### 2.3 树脂环节投资优先级

| 优先级 | 标的 | 逻辑 |

## 三、PAG（光致产酸剂）环节：更隐秘的稀缺层

### 3.1 全球格局

PAG 决定光刻胶的感光灵敏度和分辨率——可以说**PAG 是光刻胶的"芯片"**。全球 ArF/KrF 级 PAG 市场几乎完全由日本企业主导：

| 企业 | 国家 | 地位 |
|------|------|------|
| 富士胶片 | 日本 | 全球最大 PAG 供应商 |
| 东洋化学 | 日本 | ArF PAG 核心供应商 |
| 保土谷化学 | 日本 | KrF PAG 重要供应商 |
| 贺利氏 | 德国 | 特种 PAG 供应商 |

### 3.2 国产 PAG 突破进展

#### 威迈芯材 —— PAG 国产化的"隐形冠军"

**国内进展最快、最确定的 PAG 供应商。**

| 维度 | 详情 |
|------|------|
| **技术突破** | 实现 **7/14nm 制程（ArFi/ArF）** 光刻胶主材量产突破；PAG 纯度 ≥99.5%，单一金属杂质 <10ppb，总金杂 <50ppb，**突破国家攻关指标** |
| **核心产品** | 光致产酸剂（PAG）、BARC 树脂、PHS 树脂、光引发剂（PI），覆盖 ArFi/ArF/KrF 全系列 DUV 体系 |
| **量产基地** | 合肥新站高新区工厂 2025 年初投产，总投资 3 亿元，占地 50 亩，**规划年产能 100 吨**，定位为**国内最大的 DUV 级光刻胶核心主材量产基地** |
| **海外布局** | 韩国设有 2 座量产工厂，具备 20 年量产经验 |
| **客户覆盖** | 已覆盖国内各大主流光刻胶企业，累计交付 **50 余款 PAG 产品**，ArF/KrF PAG 实现**百公斤级稳定批量交付** |
| **资本背书** | 2026 年 4 月**中国建投**旗下基金领投新一轮融资，国家战略资本精准布局 |
| **背景** | 亚威股份子公司，通过跨境并购引入韩国成熟团队 + 技术 |

> **中国建投领投的深层含义**：中国建投是中央汇金全资子公司，代表国家战略资本意志。投资威迈芯材意味着国家层面已将 PAG 国产化列为关键攻坚方向。

#### 万润股份 —— 中试阶段，进度落后

| 维度 | 详情 |
|------|------|
| **产品** | 光致酸产生剂（PAG），已实现中试产品供应 |
| **优势** | 液晶材料/OLED 材料化学合成经验可延伸 |
| **局限** | 仍处于**中试验证阶段**，尚未达到规模化量产水平 |
| **与威迈对比** | 进度晚约 2-3 年，威迈已进入百公斤级交付，万润仍在中试 |

#### 东材科技 —— 合资布局，后发追赶

| 维度 | 详情 |
|------|------|
| **布局** | 2025 年 12 月与韩国 Chemax、种亿化学合资设立**成都东凯芯** |
| **产品** | 高端光刻胶所需单体、光酸（PAG）、树脂的合成和纯化 |
| **阶段** | **试生产和推广应用阶段**，尚未进入大规模量产 |
| **策略** | 通过合资引进韩国技术，降低自主研发风险 |
| **时间线** | 预计晚于威迈约 1-2 年 |

#### 强力新材（300429）—— 老牌 PAG 供应商，但聚焦 PCB 级

| 维度 | 详情 |
|------|------|
| **产业链位置** | 光刻胶专用化学品（PAG + 树脂） |
| **核心市场** | **PCB 光刻胶**上游，非半导体级 |
| **局限** | 半导体级 PAG 能力有限，天花板明确 |

## 四、上游国产化整体判断

### 4.1 突破时间线估算

```
PCB 级树脂/PAG：     ████████████████ 已国产化（容大感光等）
面板级树脂/PAG：     ████████░░░░░░░░ 国产化率 ~50%，2027 年或达 70%+
KrF 树脂/PAG：      ████░░░░░░░░░░░░ 2025-2026 年突破（八亿/威迈/彤程）
ArF 树脂：          ██░░░░░░░░░░░░░░ 2027-2030 年（徐州博康有苗头，其余几乎空白）
ArF PAG：           ███░░░░░░░░░░░░░ 2025-2027 年（威迈芯材领跑）
EUV 树脂/PAG：      ░░░░░░░░░░░░░░░░ 暂无路线图
```

### 4.2 核心判断

1. **KrF 树脂/PAG 的国产化拐点已至**：八亿时空（树脂）+ 威迈芯材（PAG）在 2025 年均实现了"吨级/百公斤级"交付突破，2026 年是放量验证年。
2. **ArF 树脂仍是最大瓶颈**：除徐州博康外，国内无第二家企业具备 ArF 树脂合成能力，且博康产能有限（东阳项目 2026 年才投产）。
3. **PAG 比树脂更容易突破**：PAG 是精细化学品，合成难度低于聚合物树脂。威迈芯材通过韩国团队+中国资本的组合，已经跑通了量产路径。
4. **上游的估值溢价正在形成**：中国建投领投威迈芯材、八亿时空引入厦门恒坤，表明产业链上下游正在形成资本+业务的深度绑定，这是从"单打独斗"到"生态作战"的关键信号。

## 五、上游投资的风险与边界

### 5.1 主要风险

| 风险 | 描述 | 影响 |
|------|------|------|
| **日本倾销压制** | 如果国产树脂/PAG 即将量产，日本企业大幅降价 | 国产厂商尚未盈亏平衡，价格战可能导致亏损扩大 |
| **客户导入周期** | 光刻胶厂商更换树脂供应商需要重新做验证（6-12 月） | 即使突破，上量节奏慢于预期 |
| **规模不经济** | 半导体光刻胶树脂市场有限（全球约 100-200 亿人民币），与万华化学等巨头的体量要求不匹配 | 大企业缺乏动力，小企业缺乏资金 |
| **技术路线变化** | EUV 光刻胶使用金属氧化物/分子玻璃新体系，不需要 PHS 树脂 | 长期（2030+）技术替代风险 |

### 5.2 研究边界

上游树脂/PAG 的投资机会集中于**一级市场**（徐州博康、威迈芯材）和**少数二级标的**（八亿时空、亚威股份、华懋科技）。其中：
- 八亿时空是唯一纯二级市场可投的独立树脂标的
- 亚威股份通过子公司威迈芯材间接受益
- 华懋科技通过参股徐州博康间接受益

**反方理由**：上游国产化从"突破"到"盈利"再到"有意义的收入贡献"，至少需要 3-5 年。如果只是跟踪观察而不急于布局，时间是朋友。
