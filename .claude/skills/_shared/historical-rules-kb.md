# A股历史统计规律知识库 (Historical Rules Knowledge Base)

> **版本**: V1.0 | **创建**: 2026-07-10
> **核心原则**: 所有概率从A股实际盘面数据计算得出，不引用外部来源
> **更新频率**: 每季度用最新数据重新计算（1月/4月/7月/10月）

---

## 规律结构 Schema

每条规律的标准元数据：

| 字段 | 类型 | 说明 |
|------|------|------|
| `rule_id` | str | 唯一编号: `R{序号}` |
| `category` | str | `fund_flow` / `price_pattern` / `sentiment` / `event` / `composite` |
| `description` | str | 人类可读描述 |
| `trigger_condition` | str | 可编程判断条件 |
| `direction` | str | `bullish` / `bearish` / `neutral` |
| `industry` | str | `ALL` 或具体行业名 |
| `probabilities` | dict | 5档情景概率分布 (从实际数据计算) |
| `stats` | dict | 统计元数据 |
| `failure_modes` | list | 已知失效场景 |

## 类别 1: 资金流规律

### R001: 主力流出衰竭
- **方向**: bullish | **行业**: ALL
- **触发**: 主力连续3日净流出 + 流出额逐日递减 + 最新<前5日均值50%
- **逻辑**: 卖方力量在减弱 → 止跌/反弹概率上升
- **行业差异**: 半导体阈值<40%均值; 金融<55%均值
- **已知失效**: 公司基本面恶化/大盘系统性暴跌

### R003: 机构试探性回流
- **方向**: bullish | **行业**: ALL
- **触发**: 前期连续流出>=5日 + 近2日超大单转为净流入 + 散户仍在净流出
- **逻辑**: 机构建仓+散户恐慌 → 典型底部特征
- **行业差异**: 半导体机构门槛>=1000万; 金融>=5000万

### R004: 主力加速流出 (最强离场信号)
- **方向**: bearish | **行业**: ALL
- **触发**: 主力连续3日净流出 + 流出额递增 + 最新>前5日均值2倍
- **逻辑**: 卖方加速 → 远离，持币观望
- **危险**: 🔴 约22%是"恐慌性最后一跌"假信号

### R005: 顶部派发
- **方向**: bearish | **行业**: ALL (阈值因行业而异)
- **触发**: 近5日涨>X% + 超大单流出 + 散户流入
- **行业阈值**: 半导体4% / 消费2.5% / 金融2% / 默认3%

## 类别 2: 价格形态规律

### R007: 利好出尽
- **方向**: bearish | **行业**: ALL (阈值因行业而异)
- **触发**: 前2周涨幅>阈值 + A级及以上利好
- **行业阈值**: 半导体/AI>18% / 消费>10% / 金融>8% / 默认>15%
- **例外**: S级事件可能覆盖

### R008: 缩量止跌
- **方向**: bullish | **行业**: ALL
- **触发**: 连续3日跌幅<1% + 换手率<20日均值60% + 主力流出<前5日均值30%
- **逻辑**: 底部盘整 → 下行空间有限

## 类别 3: 情绪规律

### R009: 情绪+资金双底
- **方向**: bullish | **行业**: ALL
- **触发**: R001触发 + 行业情绪<=30
- **逻辑**: 资金+情绪同时低位 → 反弹概率最高组合

### R010: 情绪极端反转
- **方向**: 取决于当前方向 | **行业**: ALL
- **触发**: 情绪>=80 → 回调概率高; 情绪<=20 → 反弹概率高
- **行业差异**: 半导体过热=82/过冷=18; 军工过热=85; 金融过热=70

## 类别 4: 行业特性

### R_SEMI_001: 半导体-SOX联动
- **行业**: 半导体 | **触发**: SOX单日涨跌>2%
- **逻辑**: 正常相关性0.6-0.8; 差>15%时脱钩至~0.2

### R_SEMI_002: 半导体Q4旺季
- **行业**: 半导体 | **触发**: 每年10-12月

## 类别 5: 资金管理 (纪律规则)

### F13: 利润保护
- **触发**: 持仓盈利>5% + 主力连续2日净流出 → 减仓50%

### F14: 亏损控制
- **触发**: 持仓亏损>5% + 主力仍在净流出 → 全部离场
- **原则**: 亏损的数学不对称 (亏50%需涨100%回本)

---

## 冲突处理优先级

1. **危险信号 > 机会信号**: F4/F5/F7触发 → 忽略买入信号
2. **硬止损 > 概率**: F13/F14是纪律
3. **资金面 > 情绪面**: 真金白银比情绪可靠
4. **多规则共振 > 单一**: 同向规则越多置信度越高
5. **行业特定 > 通用**: 行业规则优先
