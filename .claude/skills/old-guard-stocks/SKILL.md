# Old Guard Stocks — 老登股筛选

## 核心投资逻辑

```
老登股 = 持续盈利（好公司）∩ 有护城河（难替代）∩ 估值错杀（坏价格）
                           ↓
              不是"捡便宜货"，而是"好资产遇到了暂时的坏定价"
```

**为什么不是简单"低估值筛选"？**

| 类型 | 盈利 | 护城河 | 估值 | 本质 |
|------|------|--------|------|------|
| **老登股** ✅ | 持续为正 | 有 | 被错杀/低位 | 好公司 + 坏价格 = 机会 |
| 价值陷阱 ❌ | 看似为正 | 无 | 低 | 差公司 + 低估值 = 应该的 |
| 成长泡沫 ❌ | 可能亏损 | 未验证 | 高 | 故事 + 高估值 = 赌博 |
| 平庸公司 ❌ | 微利 | 无 | 合理 | 无 Alpha = 不值得研究 |

**老登股的三个必要充分条件**：
1. **持续盈利**：至少 8 个季度不亏损，证明它是个"活得久"的公司
2. **护城河**：在产业链中有不可替代性（品牌/技术/规模/牌照/客户粘性），保证盈利可持续
3. **估值错杀**：当前估值明显低于其基本面质量应有的水平（PE 压缩 + 盈利未恶化 = 错杀信号）

## 概述

专门筛选"好公司遇到了坏价格"的标的。先验证公司真的好（持续盈利 + 护城河 + 财报可信），再判断价格是否被错杀。

**核心原则**：
- **质量第一，价格第二**：先确认公司真的好，再看是不是被错杀。垃圾公司估值再低也不碰
- **错杀 ≠ 便宜**：关键是"盈利没恶化但估值大幅压缩"——这是错杀信号；"盈利恶化 + 估值下降"不是错杀，是合理定价
- **护城河是关键**：没有护城河的盈利是不可持续的，不能算老登股
- **证据驱动**：每个判断必须绑定可验证的公开数据，不做无来源推测

## 何时使用

**适用场景**：
- 用户想"看看各行业有哪些老登股"（跨行业筛选）
- 用户问"XX 行业有哪些持续赚钱、有护城河、但估值被错杀的龙头"
- 用户想做"质量+护城河+错杀"三维度的标的筛选
- 用户问"帮我找一些财报靠谱、有壁垒、最近跌多了的行业龙头"
- 作为 serenity-skill 产业链分析后的估值错杀落地环节
- 市场大幅回调后，筛选"被一起错杀的好公司"

**不适用场景**：
- 纯技术面/资金面择时（应调用 stock-pick）
- 深度产业链瓶颈分析（应调用 serenity-skill）
- 单公司深度壁垒拆解（应调用 moat-hunter，本 skill 做快速护城河判断）
- 政策/事件催化分析（应调用 policy-event-tracker）
- 小盘成长股/题材炒作标的筛选

## 维度一：持续盈利能力（硬门槛，不通过直接排除）

**核心理念**：一个持续赚钱的公司才值得研究。不赚钱的公司没有"老登"资格。

| 指标 | 门槛 | 检查方法 |
|------|------|---------|
| 净利润连续性 | 最近 8 个季度（2 年）净利润**全部为正** | `sina_financial_report("lrb")` → 净利润 |
| ROE 水平 | 最近年度 ROE > 8%（金融行业 > 10%） | mootdx `client.finance()` → roe |
| 营收稳定性 | 最近 8 季营收无连续 3 季同比下降（允许 1-2 季波动） | 利润表 → 营业收入_同比 |
| 经营现金流 | 最近 4 季累计经营现金流 > 0 | `sina_financial_report("llb")` |

**硬门槛判定**：四项**必须全部满足**，任一项不满足 → 排除。

**数据拉取**：

```python
for period in lrb:

    revenue = float(period.get("营业收入", 0))
    rev_yoy = float(period.get("营业收入_同比", 0))
    # 检查净利润是否全部 > 0
    # 统计连续同比下降次数

# 现金流量表（最近 4 期）
llb = sina_financial_report(code, "llb", num=4)
total_oper_cf = sum(float(p.get("经营活动产生的现金流量净额", 0)) for p in llb)

# ROE（mootdx 快照）
client = tdx_client()

```

## 维度二：护城河判断（硬门槛，不通过直接排除）

**核心理念**：没有护城河的盈利不可持续。今天赚钱不代表 3 年后还能赚钱。老登股必须是"有壁垒的盈利者"。

### 快速护城河判定（5 类 × 3 档）

本 skill 做**快速护城河判断**（深度拆解留给 moat-hunter）。对每类护城河给出"强/中/弱"判断：

| 护城河类型 | 强（明确有） | 中（可能有） | 弱/无 |
|-----------|------------|------------|-------|
| **品牌壁垒** | 消费者愿付溢价，行业心智占有率第一 | 有知名度但非首选 | 无品牌溢价，同质化竞争 |
| **技术壁垒** | 核心专利不可绕开，良率/性能行业第一 | 有技术优势但可追赶 | 通用技术，无专利保护 |
| **规模壁垒** | 行业产能/份额第一，扩产周期 > 2 年 | 大型企业但非第一 | 小产能，无规模优势 |
| **牌照壁垒** | 独家/寡头牌照（金融/军工/稀土） | 有准入门槛但非独家 | 无政策限制 |
| **客户粘性** | 深度绑定（联合研发/认证 ≥ 12 月/独家供应） | 有合作关系但可切换 | 标准化产品，客户随时可换 |

**硬门槛通过条件**（必须满足）：
- **至少 1 类护城河为"强"**，或 **至少 2 类护城河为"中"**
- 全部为"弱/无" → 没有护城河 → 排除

**快速判断方法**（非深度，用于批量筛选）：
```python
# 品牌壁垒：毛利率是否持续高于行业平均？（定价权的量化体现）
# → 毛利率 > 行业平均 + 5pp → 品牌壁垒可能为"强"

# 规模壁垒：市值是否行业 Top 3？
quotes = tencent_quote(codes)  # 批量拉市值，同行排名

# 技术壁垒 + 牌照壁垒：WebSearch 快速搜索
# WebSearch: "{公司} 行业地位 市场份额 2026"
# WebSearch: "{公司} 核心专利 技术优势"

# 客户粘性：前 5 大客户集中度（财报附注）+ 合作年限
# WebSearch: "{公司} 客户 供应协议 战略合作"
```

> **注意**：本 skill 的护城河判断是**快速筛查级别**，目的是排除明显没有壁垒的公司。对于通过筛选的核心标的，建议后续调用 moat-hunter 做深度不可替代性分析。

## 辅助排查：财报可信度（6 项红旗）

"老登"必须是"真老登"，不能是"假老登"（财务造假）。本维度不是独立硬门槛，而是**辅助排查**——有红旗不代表一定造假，但必须标注风险。

| # | 红旗信号 | 阈值 | 风险说明 | 数据来源 |
|---|---------|------|---------|---------|
| 1 | **应收/营收比过高** | 应收账款/营业收入 > 60% | 可能虚增收入、回款困难 | 资产负债表 + 利润表 |
| 2 | **经营现金流背离** | 连续 4 季净利润 > 0 但经营现金流 < 0 | 利润"纸面富贵"，无现金流入 | 现金流量表 + 利润表 |
| 3 | **存货异常膨胀** | 存货增速 > 营收增速 × 2（连续 2 季） | 产品滞销、跌价风险 | 资产负债表 + 利润表 |
| 4 | **商誉减值风险** | 商誉/净资产 > 50% | 并购溢价过高，减值雷 | 资产负债表 |
| 5 | **大股东高质押** | 大股东质押比例 > 60% | 爆仓风险、资金链问题 | WebSearch |
| 6 | **审计意见异常** | 最近年报"非标"意见 | 财报可信度存疑 | WebSearch |

**红旗处理规则**：
- 🟢 **0 面红旗**：财报高可信度，正常评分
- 🟡 **1 面红旗**：标注该红旗，降一档（如核心→优质）
- 🔴 **≥2 面红旗**：**直接排除**，不进入后续评分

## 辅助验证：毛利率水平

毛利率是护城河的量化体现——高且稳定的毛利率 → 有定价权 → 护城河真实存在。

| 评分 | 条件 | 含义 |
|------|------|------|
| ✅ 优质 | 连续 8 季毛利率 > 行业平均 + 5pp，且波动 < 3pp | 强定价权，护城河可信 |
| ⚠️ 合格 | 毛利率 ≥ 行业平均，波动 < 5pp | 有一定定价权 |
| ❌ 不合格 | 毛利率 < 行业平均，或连续下降 | 无定价权，护城河存疑 |

毛利率不合格 → 不直接排除，但必须在报告中标注风险，且"护城河"判断需重新审视。

```python
lrb = sina_financial_report(code, "lrb", num=8)
margins = []
for period in lrb:
    rev = float(period.get("营业收入", 0))
    cost = float(period.get("营业成本", 0))
    if rev > 0:
        margins.append((period["报告期"], round((rev - cost) / rev * 100, 1)))

avg_margin = sum(m[1] for m in margins) / len(margins)
trend = "上升" if margins[-1][1] > margins[0][1] else ("下降" if margins[-1][1] < margins[0][1] else "稳定")
print(f"毛利率趋势: {[m[1] for m in margins]} → {trend}，均值 {avg_margin:.1f}%")
```

## ★★★★★ 核心判断：估值错杀识别 ★★★★★

这是老登股筛选的**核心创新**——不是简单看 PE 低不低，而是判断**盈利质量 vs 估值压缩是否错配**。

### 什么是"估值错杀"？

```
正常下跌：盈利恶化 → 估值下降 → 股价跌 ✅ 合理定价
估值错杀：盈利稳定 → 估值压缩 → 股价跌 ❌ 市场错配
```

**错杀的三个典型场景**：

| 场景 | 描述 | 识别方法 |
|------|------|---------|
| **场景 A：泥沙俱下** | 大市/行业恐慌，好公司被一起杀 | 个股跌幅≈行业跌幅，但盈利趋势明显好于行业 |
| **场景 B：短期利空** | 一次性/暂时的负面事件，不影响长期盈利 | 事件影响可量化、有明确结束时间，长期护城河未受损 |
| **场景 C：周期底部** | 周期行业低谷，但龙头现金流能扛过去 | 在手现金/有息负债 > 1，经营现金流仍为正 |

### 错杀程度打分（权重 50%）

从三个子维度评估：

#### 子维度 4a：估值压缩程度（权重 50%）

比较当前估值与历史估值、行业估值的差距：

| 信号 | 强错杀（5分） | 中度错杀（3分） | 非错杀（1分） |
|------|-------------|---------------|-------------|
| **PE 历史分位** | < 历史 20% 分位 | 历史 20-50% 分位 | > 历史 50% 分位 |
| **PE 行业分位** | < 行业 30% 分位 | 行业 30-60% 分位 | > 行业 60% 分位 |
| **股价回撤** | 距 1 年高点回撤 > 30% | 回撤 15-30% | 回撤 < 15% |
| **北向资金** | 股价跌但北向逆势加仓（背离信号） | 北向同步减持 | 北向大幅流出 |

```python
# 估值数据
quotes = tencent_quote([code])
pe = quotes[code]["pe_ttm"]
pb = quotes[code]["pb"]

# 历史 PE 区间（WebSearch + mootdx K 线倒推）
# WebSearch: "{公司} 历史PE 估值分位 2024 2025 2026"
# 或用 mootdx 拉 3 年日 K 线，结合利润表估算历史 PE 区间

# 股价回撤
klines = client.bars(symbol=code, category=4, offset=250)  # 1年日线
high_1y = max(k['high'] for k in klines)
current = klines[-1]['close']
drawdown = (high_1y - current) / high_1y * 100

# 北向资金背离检查
fund_flow = stock_fund_flow_120d(code)
recent_flow = sum(d["main_net"] for d in fund_flow[-20:])
# 股价在跌但北向在买 → 背离信号 → 可能的错杀
```

#### 子维度 4b：盈利-估值背离度 ⭐ 最核心指标（权重 50%）

这是识别错杀的关键量化指标——**盈利没变差，但估值变得更便宜了**：

```
背离度 = (当前 PE 分位 - 盈利趋势分位)

盈利趋势分位 = 基于近 8 季净利润增速/稳定性给出的 0-100 分位（越高越好）
当前 PE 分位 = PE 在历史/行业中的分位（越低越便宜）

背离度越大 → 错杀越明显
```

| 背离度 | 分数 | 信号解读 |
|--------|------|---------|
| **> 40** | ⭐⭐⭐⭐⭐ (5分) | 极度错杀——盈利稳定甚至改善，但估值跌到地板 |
| **20-40** | ⭐⭐⭐⭐ (4分) | 明显错杀——盈利没变差，估值显著压缩 |
| **10-20** | ⭐⭐⭐ (3分) | 可能错杀——有一定背离，需进一步验证 |
| **0-10** | ⭐⭐ (2分) | 基本同步——估值下跌可能反映了某些风险 |
| **< 0 (负值)** | ⭐ (1分) | 不是错杀——盈利恶化比估值下降更严重 |

**关键验证——排除"假错杀"**：
在判定"错杀"之前，必须回答三个问题：
1. 卖方一致预期 EPS 是否被大幅下调？（如下调 > 15%，不是错杀，是基本面恶化）
2. 是否有未被财报体现的隐性风险？（如政策转向、技术替代、大客户丢失）
3. 同行业其他公司是否也出现了类似的"估值压缩"？（全行业杀估值 vs 个股错杀）

```python
# 盈利稳定性评估（8 季净利润）
lrb = sina_financial_report(code, "lrb", num=8)
net_profits = [float(p.get("净利润", 0)) for p in lrb]

# 盈利趋势分位估算规则：
# - 8 季净利润全部 > 0 且逐季增长/稳定 → 80-100 分位
# - 8 季净利润全部 > 0 但有个别季波动 → 60-80 分位
# - 8 季净利润全部 > 0 但趋势向下 → 40-60 分位
# 已在维度一筛除了亏损公司，此处均为正

# 结合 PE 分位计算背离度

# 卖方预期 EPS（辅助验证）
# 通过东财研报 API 或同花顺一致预期获取
# ths_eps_forecast(code) → 最近 3 个月预期 EPS 是否被下调
```

### 综合得分公式

```
综合得分 = 估值压缩程度得分 × 25% + 盈利-估值背离度得分 × 25% + 护城河强度 × 20%
           + 毛利率水平得分 × 15% + 财报可信度(红旗反向) × 15%
```

**护城河强度折算**：
- 1 类"强" = 4 分，2 类及以上"强" = 5 分
- 2 类"中" = 3 分，3 类及以上"中" = 4 分

**财报可信度折算**（红旗越少越高）：
- 0 面红旗 = 5 分
- 1 面红旗 = 2 分

### 最终定级

| 综合得分 | 定级 | 含义 |
|---------|------|------|
| ≥ 4.0 | ⭐⭐⭐ **核心老登** | 优质公司确认被错杀，深度研究优先级最高 |
| 3.0-3.9 | ⭐⭐ **优质老登** | 好公司但错杀程度不够极端，或护城河有轻微瑕疵 |
| 2.0-2.9 | ⭐ **观察老登** | 有一定质量但估值/护城河有一端明显不足 |
| < 2.0 | 不入池 | 不满足老登股核心定义 |

## 附加加减分项

| 项目 | 条件 | 分值 |
|------|------|------|
| 股息率高 | 股息率 > 3% 且分红连续 > 5 年 | +0.5 |
| 现金流质量 | 经营现金流/净利润 > 1.2（连续 4 季） | +0.5 |

## 与 moat-hunter 的深度联动（⭐ 关键协作链路）

### 为什么需要联动？

老登股筛选中的"护城河快速判断"和 moat-hunter 的"深度不可替代性分析"是**两个不同颗粒度**的工作：

| 维度 | old-guard-stocks 护城河判断 | moat-hunter 深度分析 |
|------|--------------------------|---------------------|
| 目的 | **筛选**——排除无壁垒的公司 | **验证**——确认壁垒有多深 |
| 深度 | 快速判断（5-10 分钟/只） | 深度拆解（30-60 分钟/只） |
| 数据 | 毛利率 + 市值排名 + WebSearch | 专利检索 + 客户验证 + 供需 4 类证据 + 切换成本量化 |
| 输出 | "强/中/弱"三档 | S/A/B/C 四级 + 供需报告 |
| 精度 | 可能有误判（假阳/假阴） | 高置信度 |

### 联动触发条件

以下情况**必须**将标的从老登股筛选**流转到 moat-hunter** 做深度验证：

| 触发条件 | 优先级 | 原因 |
|---------|--------|------|
| 🏆 核心老登（综合 ≥ 4.0） | **必须** | 最高优先级标的，护城河必须确认"真强"，不能仅靠快速判断 |
| ⚠️ 护城河判断不确定 | **强烈建议** | 快速判断中"2类中"勉强通过的标的，需要深度验证是否真有壁垒 |
| 🔍 毛利率与护城河矛盾 | **强烈建议** | 毛利率高但说不清为什么高（是品牌？技术？还是短期供需？） |
| 📊 行业技术变革期 | **建议** | 技术路线可能变化的行业（如光伏/锂电/半导体），护城河需要实时重估 |

## 质量控制规则

### 必须遵守

1. **硬门槛不可通融**：持续盈利和护城河两项必须逐项验证，不能凭印象通过
2. **错杀必须量化**：不能凭感觉说"跌多了就是错杀"，必须有背离度计算
3. **必须排除假错杀**：每个"错杀"判断必须经过三个验证问题（卖方下调？隐性风险？行业通杀？）
4. **护城河判断必须有依据**：每类护城河判断附具体理由（毛利率→品牌，市值排名→规模，等等）
5. **区分事实与推测**：API 返回 = 事实，行业排名 = 计算，护城河判断 = 分析推测
6. **财报数据必须真实拉取**：不能凭记忆或常识给数字

### 禁止行为

- ❌ 没有拉取真实财务数据就给"老登股"认定
- ❌ 把"跌了很多"等同于"被错杀"（不分析基本面就判断错杀）
- ❌ 把"PE 低"等同于"被错杀"（垃圾公司 PE 低是应该的）
- ❌ 跳过护城河判断（没有护城河的盈利不可持续）
- ❌ 跳过假错杀排除步骤
- ❌ 给出买卖建议（违反研究边界）
- ❌ 编造 PE/PB/毛利率/背离度数据

|---------|---------|------|
| "白酒行业有哪些老登股" | 单行业全流程 | 三维度 + 错杀识别 |
| "市场跌了这么多，哪些好公司被错杀了" | 全市场扫描 + 错杀筛选 | 错杀识别为主（背离度排序） |
| "帮我看看各行业的老登股" | 多行业扫描 | 快速护城河 + 跨行业比较 |
| "贵州茅台是老登股吗" | 单只诊断 | 三维度诊断 + 错杀深度分析 |
| "XX 最近跌了 30%，是老登股吗（是错杀吗）" | 单只错杀诊断 | 重点：背离度 + 假错杀排除 |
| "最近财报季，重新扫一遍老登股" | 更新扫描 | 重点更新盈利趋势 + 错杀程度变化 |

## 风险边界

- **研究支持，不做交易执行**：老登股筛选是对"好公司+坏价格"的分析参考，不构成买卖建议
- **错杀判断是概率判断**：基于公开数据的背离度分析，不能保证市场会纠正错杀
- **护城河快速判断 ≠ 深度验证**：本 skill 的护城河判断是批量筛选级别，可能有误判（建议核心标的走 moat-hunter 深度验证）
- **假错杀排除依赖公开信息**：可能存在未公开的隐性风险未被三个验证问题覆盖
- **错杀不等于马上涨**：估值修复可能需要催化剂和时间，错杀标的可能继续被错杀
- **周期股特殊处理**：周期股 PE 低时可能是盈利顶点（不是错杀），需结合 PB + 库存周期位置判断
