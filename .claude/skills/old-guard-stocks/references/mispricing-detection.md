# 估值错杀识别方法论

## 核心概念

**估值错杀 ≠ 估值低**

```
估值低但没有错杀：盈利恶化 + 估值下降 = 市场正确定价（价值陷阱）
估值高但是错杀：盈利稳定 + 估值大幅压缩 = 市场错误定价（老登机会）
```

## 错杀的三个必要条件

只有同时满足三个条件，才能判断为"错杀"：

1. **盈利未恶化**：近 8 季净利润稳定或上升，ROE 无明显下滑
2. **估值大幅压缩**：PE 处于历史低位区间（< 30% 分位），或股价大幅回撤（> 25%）
3. **非基本面原因**：排除盈利预测下调、政策转向、技术替代、竞争恶化等原因

缺少任一条件 → 不是错杀，是合理定价。

## 背离度计算（核心量化指标）

### 公式

```
背离度 = 盈利趋势得分 - PE 分位得分

盈利趋势得分 = 基于近 8 季净利润表现（0-100，越高越好）
PE 分位得分 = PE 在历史中的分位（0-100，越低越便宜）

背离度范围：[-100, 100]
- 正值越大 → 错杀越明显（盈利好但估值低）
- 负值 → 不是错杀（盈利差但估值不低，或盈利恶化比估值下降更快）
```

### 盈利趋势得分计算规则

| 盈利表现 | 得分 | 说明 |
|---------|------|------|
| 8 季净利润全部 > 0，且最近 4 季同比增长 | 90-100 | 盈利强劲增长 |
| 8 季净利润全部 > 0，最近 4 季基本持平（±10%） | 75-90 | 盈利稳定高位 |
| 8 季净利润全部 > 0，最近 4 季较前 4 季略降（-10~0%） | 60-75 | 盈利小幅下滑 |
| 8 季净利润全部 > 0，但趋势明显向下（-10~-30%） | 40-60 | 盈利在恶化 |
| 有 1-2 季亏损 | 20-40 | 盈利不稳定 |

```python
def calc_profit_trend_score(net_profits_8q: list[float]) -> float:
    """计算盈利趋势得分（0-100）"""
    if any(np <= 0 for np in net_profits_8q):
        # 有亏损季度
        loss_count = sum(1 for np in net_profits_8q if np <= 0)
        return max(20, 40 - loss_count * 15)
    
    first_4q_avg = sum(net_profits_8q[:4]) / 4
    last_4q_avg = sum(net_profits_8q[4:]) / 4
    growth_rate = (last_4q_avg - first_4q_avg) / first_4q_avg * 100
    
    if growth_rate > 20:
        return 95
    elif growth_rate > 10:
        return 85
    elif growth_rate > -5:
        return 75
    elif growth_rate > -15:
        return 60
    elif growth_rate > -30:
        return 45
    else:
        return 30
```

### PE 分位得分估计

由于精确的历史 PE 分位需要数据库支持，在 skill 执行中采用**近似估计**：

```python
def estimate_pe_percentile(pe_current: float, industry_pe_range: tuple, 
                           history_pe_high: float = None, history_pe_low: float = None) -> float:
    """
    估计 PE 在当前行业和历史中的分位。
    
    返回值 0-100：
    - 0 = PE 接近历史最低（最便宜）
    - 100 = PE 接近历史最高（最贵）
    """
    industry_low, industry_mid, industry_high = industry_pe_range
    
    if pe_current <= industry_low:
        return 10   # 行业地板价
    elif pe_current <= industry_mid:
        return 30   # 行业偏低
    elif pe_current <= industry_high:
        return 60   # 行业偏高
    else:
        return 85   # 行业顶部
```

### 背离度解读

| 背离度 | 错杀强度 | 含义 | 典型场景 |
|--------|---------|------|---------|
| > 50 | 极度错杀 | 盈利强劲但估值在地板上 | 市场恐慌 + 公司基本面完好 |
| 30-50 | 明显错杀 | 盈利稳定但估值显著低估 | 行业利空 + 龙头被错杀 |
| 15-30 | 中度错杀 | 有一定背离 | 需进一步验证 |
| 0-15 | 轻微错杀 | 估值可能合理偏低 | 关注催化剂 |
| < 0 | 非错杀 | 估值反映了基本面 | 不纳入老登股 |

## 错杀三场景识别

### 场景 A：泥沙俱下（最经典的老登股机会）

**特征**：
- 大市或行业出现恐慌性下跌
- 好公司股票被无差别抛售（ETF 赎回、止损盘、流动性危机）
- 公司基本面没有变化，护城河没有损伤

**识别方法**：
```
1. 个股跌幅 ≈ 行业跌幅（被一起杀）
2. 但：个股盈利趋势 >> 行业平均（基本面明显更好）
3. 北向/机构可能逆势加仓（聪明钱在捡）
```

**案例模式**：2024 年初全市场流动性危机中，茅台从 1800 跌到 1300（-28%），但盈利增长 15%，PE 从 35x 压缩到 22x → 典型的泥沙俱下错杀

### 场景 B：短期利空（一次性事件）

**特征**：
- 公司遭遇一次性/暂时的负面事件
- 事件影响可量化、有明确结束时间
- 长期护城河和盈利能力不受影响

**识别方法**：
```
1. 事件影响可量化（如罚款 X 亿、某季度停产损失 Y 亿）
2. 事件有明确结束时间（如诉讼判决后、产线检修完成后）
3. 长期逻辑未破坏（护城河 5 类判断不变）
```

**常见短期利空类型**：
- 一次性罚款/诉讼赔偿
- 季度性停产检修
- 核心高管离职（但团队体系成熟）
- 季度业绩不及预期（但全年指引未下调）
- 被剔除某指数（被动基金减持）

**案例模式**：某医药龙头因集采降价单季利润 -20%，股价 -35%，但集采换量后 2 季度利润创新高 → 短期利空错杀

### 场景 C：周期底部

**特征**：
- 周期行业处于低谷
- 但龙头公司现金流充沛，能扛过寒冬
- 行业产能出清后龙头份额将提升

**识别方法**：
```
1. 行业处于周期底部（产能过剩 → 出清中 → 价格企稳）
2. 公司：在手现金/有息负债 > 1，经营现金流仍为正
3. 公司：毛利率好于行业平均（低成本的行业龙头）
4. 竞争对手开始亏损/退出（格局改善信号）
```

**注意**：周期股 PE 低时可能是利润顶点（不是错杀！），必须结合 PB + 库存周期 + 产能周期判断。

## 假错杀排除（三步验证）

在判定"错杀"之前，**必须**完成以下三步排除：

### 验证 1：卖方是否下调了盈利预测？

```python
# 方法 1：同花顺一致预期
ths_eps_forecast(code)
# 比较 3 个月前 vs 当前的一致预期 EPS
# 如下调 > 15% → 不是错杀，是基本面在恶化

# 方法 2：东财研报预测
reports = eastmoney_reports(code, max_pages=3)
# 看最近 3 个月研报的 predictThisYearEps 趋势
```

### 验证 2：是否有隐性风险未被财报体现？

```
WebSearch: "{公司} 风险 利空 2026"
WebSearch: "{行业} 政策 转向 监管 2026"
WebSearch: "{公司} 技术替代 竞争格局 变化"

重点排查：
- 政策风向是否改变？（如教育双减、游戏版号、新能源补贴退坡）
- 技术路线是否被替代？（如光伏 PERC → TOPCon，LCD → OLED）
- 核心客户是否在流失？（大客户订单变化）
- 管理层是否在减持？（内幕人比市场更了解公司）
```

### 验证 3：是行业通杀还是个股错杀？

```python
# 拉同行业其他公司
peers = get_industry_peers(code)
peer_quotes = tencent_quote(peers)

# 比较 PE 分位
for peer_code, peer_q in peer_quotes.items():
    peer_pe = peer_q["pe_ttm"]
    # 如果同行 PE 分位都在 20% 以下 → 行业通杀（可能行业有利空未消化）
    # 如果只有这只 PE 在 20% 以下 → 个股错杀（更有可能是机会）
```

**判定规则**：
- 行业 PE 分位 + 个股 PE 分位 都在 20% 以下 → 行业系统性低估（可能是宏观/政策原因）
- 行业 PE 分位正常 + 个股 PE 分位异常低 → **个股错杀**（更值得研究）

## 错杀评估综合打分表

| 子维度 | 5分 | 4分 | 3分 | 2分 | 1分 |
|--------|-----|-----|-----|-----|-----|
| PE 历史分位 | < 15% | 15-25% | 25-40% | 40-60% | > 60% |
| PE 行业分位 | < 20% | 20-35% | 35-55% | 55-75% | > 75% |
| 股价回撤 | > 40% | 30-40% | 20-30% | 10-20% | < 10% |
| 盈利-估值背离度 | > 50 | 30-50 | 15-30 | 5-15 | < 5 |
| 北向背离 | 股价跌+北向大幅买入 | 股价跌+北向小幅买入 | 同步 | 股价跌+北向小幅卖出 | 股价跌+北向大幅卖出 |

**错杀综合评分** = 以上 5 项的平均分（等权）

## 错杀发现后的跟踪清单

判定为"错杀"后，不是买入信号，而是**深度研究的起点**：

1. [ ] 盈利稳定性验证：未来 2 季盈利能否维持？（跟踪月度经营数据/季度报告）
2. [ ] 护城河验证：错杀期间护城河是否受损？（调用 moat-hunter 深度分析）
3. [ ] 催化剂识别：什么事件能让市场纠正错杀？（财报超预期/政策利好/行业拐点/回购）
4. [ ] 资金面确认：聪明钱是否在买？（北向/机构/大股东增持）
5. [ ] 技术面确认：股价是否在筑底？（底部放量/缩量止跌/均线走平）
6. [ ] 设定纠错条件：什么情况下说明"错杀判断错了"？（如连续 2 季盈利恶化/护城河被突破）

> ⚠️ **重要提醒**：错杀不等于马上涨。市场可能继续错杀 3 个月、6 个月甚至更久。错杀分析回答的是"定价是否合理"，不是"什么时候会涨"。择时请结合 stock-pick 的技术面分析。
