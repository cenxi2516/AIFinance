# 红旗信号详细检查清单与案例

## 概述

6 项红旗信号用于排查财报造假/粉饰风险。每项红旗不是"定罪"而是"存疑"——触发红旗意味着需要更多调查。

**重要原则**：
- 红旗是概率指标，不是造假证据
- 不同行业正常值不同（如建筑行业应收/营收比天然较高）
- 1 项红旗可能是行业特性或偶发因素，≥2 项红旗才是真正危险信号
- 所有阈值是经验参考值，不是绝对红线

---

## 红旗 1：应收/营收比过高

### 检查方法

```python
fzb = sina_financial_report(code, "fzb", num=4)
lrb = sina_financial_report(code, "lrb", num=4)

for i in range(min(len(fzb), len(lrb))):
    yszk = float(fzb[i].get("应收账款", 0))
    revenue = float(lrb[i].get("营业收入", 0))
    ratio = (yszk / revenue * 100) if revenue > 0 else 0
    print(f"{fzb[i]['报告期']}: 应收/营收 = {ratio:.1f}%")
```

### 判断标准

| 应收/营收比 | 信号 | 说明 |
|------------|------|------|
| < 20% | 🟢 健康 | 回款良好 |
| 20-40% | 🟡 关注 | 需看趋势，如持续上升需警惕 |
| 40-60% | 🟠 警惕 | 回款周期长，可能有坏账风险 |
| > 60% | 🔴 红旗 | 需重点排查 |

### 行业调整

| 行业 | 正常区间 | 红旗阈值 | 原因 |
|------|---------|---------|------|
| 建筑/工程 | 30-60% | > 80% | 工程结算周期长，天然高 |
| 消费品 | 5-20% | > 40% | 渠道回款快 |
| 科技/软件 | 15-35% | > 50% | 项目制收款 |
| 制造业 | 10-30% | > 50% | 正常信用期 |

### 红旗案例

**真红旗**：某公司应收/营收从 25% 飙升至 65%，同期经营现金流恶化 → 虚增收入嫌疑
**假红旗**：某建筑公司应收/营收 55%，但 90% 为政府项目应收（回款确定性高）→ 行业特性

## 红旗 2：经营现金流 vs 净利润背离

### 检查方法

```python
llb = sina_financial_report(code, "llb", num=8)
lrb = sina_financial_report(code, "lrb", num=8)

for i in range(min(len(llb), len(lrb))):
    oper_cf = float(llb[i].get("经营活动产生的现金流量净额", 0))
    net_profit = float(lrb[i].get("净利润", 0))
    ratio = (oper_cf / net_profit) if net_profit != 0 else 0
    print(f"{llb[i]['报告期']}: 经营现金流={oper_cf/1e8:.1f}亿 净利润={net_profit/1e8:.1f}亿 比值={ratio:.2f}")
```

### 判断标准

| 经营现金流/净利润 | 信号 | 说明 |
|-----------------|------|------|
| > 1.0 | 🟢 优秀 | 利润现金含量高 |
| 0.5-1.0 | 🟡 正常 | 大部分行业正常水平 |
| 0-0.5 | 🟠 关注 | 利润质量偏低 |
| < 0（连续4季） | 🔴 红旗 | 纸面富贵，利润无现金支撑 |

### 红旗案例

**真红旗**：某公司连续 6 季净利润为正（合计 15 亿），但经营现金流连续 6 季为负（合计 -8 亿） → 利润质量极差，可能虚增收入
**假红旗**：某地产公司某季经营现金流为负（拿地支出大），但属于行业正常经营周期

## 红旗 3：存货异常膨胀

### 检查方法

```python
fzb = sina_financial_report(code, "fzb", num=8)
lrb = sina_financial_report(code, "lrb", num=8)

for i in range(1, min(len(fzb), len(lrb))):
    ch_current = float(fzb[i].get("存货", 0))
    ch_prev = float(fzb[i-1].get("存货", 0))
    rev_current = float(lrb[i].get("营业收入", 0))
    rev_prev = float(lrb[i-1].get("营业收入", 0))
    
    ch_growth = ((ch_current - ch_prev) / ch_prev * 100) if ch_prev > 0 else 0
    rev_growth = ((rev_current - rev_prev) / rev_prev * 100) if rev_prev > 0 else 0
    
    flag = "🔴" if ch_growth > rev_growth * 2 else "🟢"
    print(f"{fzb[i]['报告期']}: 存货增速={ch_growth:.1f}% 营收增速={rev_growth:.1f}% {flag}")
```

### 判断标准

| 存货 vs 营收 | 信号 | 说明 |
|-------------|------|------|
| 存货增速 < 营收增速 | 🟢 健康 | 销售消化良好 |
| 存货增速 = 营收增速 ±10% | 🟡 正常 | 同步增长 |
| 存货增速 > 营收增速 × 1.5 | 🟠 警惕 | 可能出现滞销 |
| 存货增速 > 营收增速 × 2（连续2季） | 🔴 红旗 | 滞销/虚增存货 |

### 红旗案例

**真红旗**：某消费电子公司连续 3 季存货增速 > 40%，营收增速仅 5% → 产品滞销，后续计提大额存货跌价
**假红旗**：某白酒公司存货增速 > 营收增速 → 基酒库存增值（白酒行业存货越放越值钱）

## 红旗 4：商誉减值风险

### 检查方法

```python
fzb = sina_financial_report(code, "fzb", num=4)

for period in fzb:
    goodwill = float(period.get("商誉", 0))
    equity = float(period.get("净资产", 0))  # 归属母公司股东权益
    ratio = (goodwill / equity * 100) if equity > 0 else 0
    flag = "🔴" if ratio > 50 else ("🟠" if ratio > 30 else "🟢")
    print(f"{period['报告期']}: 商誉={goodwill/1e8:.1f}亿 净资产={equity/1e8:.1f}亿 比例={ratio:.1f}% {flag}")
```

### 判断标准

| 商誉/净资产 | 信号 | 说明 |
|------------|------|------|
| < 10% | 🟢 安全 | 商誉影响不大 |
| 10-30% | 🟡 关注 | 需要了解商誉来源 |
| 30-50% | 🟠 警惕 | 减值可能重创利润 |
| > 50% | 🔴 红旗 | 一颗"商誉地雷" |

### 红旗案例

**真红旗**：某传媒公司商誉/净资产 = 80%，多为 2015-2016 年高溢价并购形成，后续连续计提减值，利润从盈转亏
**假红旗**：某医药公司商誉/净资产 = 40%，但被并购标的盈利持续超预期，商誉无减值风险

## 红旗 6：审计意见异常

### 检查方法

```python
# WebSearch: "{公司名称} {年份} 年报 审计意见"
# 关注审计报告类型：标准无保留 / 带强调事项段无保留 / 保留意见 / 无法表示意见 / 否定意见
```

### 判断标准

| 审计意见 | 信号 | 说明 |
|---------|------|------|
| 标准无保留意见 | 🟢 正常 | 审计师认可财报 |
| 带强调事项段无保留 | 🟡 关注 | 有需要关注的事项（持续经营疑问等） |
| 保留意见 | 🔴 红旗 | 部分科目有问题 |
| 无法表示意见 | 🔴 红旗 | 审计师不敢/不能下结论 |
| 否定意见 | 🔴 红旗 | 财报严重失实 |

### 红旗案例

**真红旗**：某公司连续 2 年被出具"无法表示意见"，次年暴雷退市
**假红旗**：某公司被出具"带强调事项段无保留"，原因为重大未决诉讼，但诉讼结果已基本明朗

## 红旗综合判定规则

| 红旗数量 | 判定 | 处理 |
|---------|------|------|
| 0 | 🟢 高度可信 | 正常进入评分 |
| 1 | 🟡 有疑虑 | 标注该红旗，降一档评分 |
| 2-3 | 🔴 中高风险 | **直接排除** |
| ≥4 | 🔴 极高风险 | **坚决排除**，典型的财务造假/粉饰特征 |

### 红旗联动分析

某些红旗组合特别危险：

- **红旗 1 + 红旗 2**：应收高 + 经营现金流为负 = 虚增收入的经典模式
- **红旗 3 + 红旗 2**：存货膨胀 + 经营现金流为负 = 产品滞销 + 利润虚假
- **红旗 4 + 红旗 5**：商誉高 + 大股东高质押 = 并购后遗症 + 资金链紧张
- **红旗 1 + 红旗 3 + 红旗 5**：三种同时出现 → 极高概率存在系统性财务问题
