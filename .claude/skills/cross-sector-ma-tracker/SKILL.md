# 跨界并购追踪器（Cross-Sector M&A Tracker）

## Overview

**核心定位**：综合性跨界并购追踪——覆盖投资机会发现、风险监控、产业趋势分析三个维度。

**核心原则**：
- **信号分级**：按证据强度分 S/A/B/C 四级，弱信号不可驱动强结论
- **风险前置**：先看商誉/整合/监管风险，再看转型机遇
- **多源交叉验证**：公告（一级）+ 新闻/研报（二级交叉验证）+ Web（补充）

## When to Activate

### 触发关键词
"跨界并购""传统企业转型科技""收购科技公司""重组转型""跨界投资"
"传统行业+科技标的""产业转型升级""并购重组扫描""跨界科技""第二曲线"
"传统企业科技化""跨界布局"

### 典型用户问法
- "最近有哪些传统企业在收购科技公司？"
- "帮我扫描一下跨界并购的机会"
- "传统行业转型科技的最新案例"
- "A股跨界并购全景扫描"
- "哪些钢铁/煤炭/地产公司在投资科技？"

### 不适用场景
- 科技企业之间的并购（不涉及跨界）
- 纯粹的同行业重组整合
- 金融投资（非产业并购）
- 海外并购（不在 A 股范围）

## 行业分类规则

详见 `references/industry-mapping.md`。核心规则：

| 分类 | 覆盖行业 | 识别方法 |
|------|---------|---------|
| **传统行业** | 钢铁/煤炭/石化/化工/纺织/农林/建筑/建材/地产/交通/商贸/食品/家电/公用事业/银行/非银/轻工/社会服务 | 申万一级行业归属 + 关键词匹配 |
| **科技行业** | 电子(半导体)/计算机(AI/软件/云计算)/通信(5G/光模块)/传媒(互联网)/军工(航天)/医药(生物科技) | 同上 |
| **新能源**（独立） | 电力设备(光伏/储能/锂电)、汽车(新能源部分) | 新能源独立分类，不视为传统→科技跨界 |

### 边界模糊处理规则
1. **主营收入占比原则**：>50% 为主业归属
2. **市场共识原则**：若无法获取分业务收入，以市场共识标签为准
3. **标注原则**：边界模糊案例必须标注"模糊"并在报告中说明判断依据

## 工作流程（5 阶段 Checklist）

### Phase 1: 信号采集（并行拉取）⚡

```
并行执行以下数据拉取，不可顺序化：

□ 巨潮公告关键词检索 — cninfo_announcements()
  使用 references/keyword-library.md 中的预设关键词逐个检索
  覆盖时间窗口：默认近 3 个月，用户可自定义

□ 东财个股新闻扫描 — eastmoney_stock_news()
  针对传统行业市值 Top50 逐一拉取新闻（分批并行）
  过滤标题/摘要含并购关键词的条目

□ 东财全球资讯过滤 — eastmoney_global_news()
  拉取近 3 个月快讯，过滤并购/重组/跨界相关内容

□ WebSearch 补充搜索 — WebSearch()
  搜索："A股 跨界并购 科技" "传统企业 收购 科技公司" "重组转型 科技"
  "上市公司 跨界投资 半导体/AI/机器人" 等组合词

□ （可选）研报关键词搜索 — eastmoney_industry_reports()
  搜索研报标题含"跨界""转型""并购重组""第二曲线"的研报
```

**⚠️ 关键约束**：
- 巨潮公告检索必须逐个关键词轮询，不可只搜一个关键词
- 每条信号必须记录来源（公告编号 / 新闻标题+日期 / 研报名称+作者+日期）
- 若 a-stock-data 端点不可用，用 WebFetch 替代获取公告/新闻

### Phase 2: 行业分类过滤 🔍

```
对每条信号：
□ 识别买方（出资方）的申万一级行业归属
□ 识别标的（被收购方/投资对象）的行业归属
□ 对照 references/industry-mapping.md 判定买方分类
□ 判定标的分类
□ 过滤：只保留"传统→科技"或"传统→新能源"方向的跨界
□ 排除：同一集团内部资产划转（关键词："同一控制下""内部重组"）
□ 排除：收购金额 < 1000 万元（非战略性布局）
□ 去重：同一笔交易在多个信号源中重复出现的合并为一条
```

### Phase 3: 信号交叉验证 & 分级 🎯

| 等级 | 定义 | 来源要求 | 案例特征 |
|------|------|---------|---------|
| **S 级** | 公告已确认 + 标的在科技核心领域 | 巨潮公告原文（一级来源） | 重大资产重组公告/发行股份购买资产/现金收购完成公告，标的为半导体/AI/机器人/航天等核心科技 |
| **A 级** | 公告已确认 + 标的在科技相关领域 | 巨潮公告原文（一级来源） | 公告确认的收购/投资，标的为软件/通信/新能源/生物科技等相关领域 |
| **B 级** | 新闻/研报覆盖 + 有明确标的 | 2 个以上独立来源交叉验证 | 公司公告了投资意向/框架协议/MoU；或主流财经媒体+券商研报同时覆盖 |
| **C 级** | 传闻/意向阶段 + 方向符合 | 单一来源，标记"待验证" | 市场传闻/互动平台回复/公司"正在研究"等模糊表态 |

**降级规则**：
- 同一交易多次公告无实质进展 → 降一级
- 交易金额 < 5000 万 → 最高不超过 A 级
- 标的与买方主业无协同逻辑 → 降一级（可能是财务投资）

**排除规则**：
- 公告后超过 6 个月无任何进展 → 标记为"停滞"，移出活跃清单
- 交易已宣告终止/失败 → 标记为"终止"，纳入失败案例库

### Phase 4: 重点案例深度分析 🔬

```
□ S 级案例：全部深度分析
  - 交易结构（现金收购/发股收购/合资/少数股权投资/资产注入）
  - 交易金额与估值（PE/PB/PS 倍数，与可比交易对比）
  - 产业链定位（标的在产业链中的环节，买方跨界合理性）
  - 调用 moat-hunter 评估标的不可替代性（REQUIRED for S级）
  - 风险分析（商誉/整合/监管/资金压力/管理层能力圈）
  - 机遇判断（估值重塑/第二曲线/产业链协同/技术获取）

□ A 级案例：选取 3-5 个代表性案例深度分析
  - 同 S 级分析框架，moat-hunter 调用可选

□ B/C 级案例：仅列表记录，不深度分析
```

### Phase 5: 报告生成 & 输出 📝

```
□ 创建输出目录 src/选股/YYYY-MM-DD-跨界并购扫描/
□ 创建子目录 case-detail/ 和 data/
□ 写入主报告 report.md（按下方输出规范）
□ 写入 S 级案例详情到 case-detail/（每个案例一个 .md）
□ 写入原始信号数据到 data/raw-signals.json
□ 控制台打印核心结论（调用 scripts/print_conclusion.py）
□ 更新 src/选股/_index.md（添加本次扫描条目）
```

## 质量控制规则

### Must-Do（必须执行）

- [ ] 每条 S/A 级信号标注来源（公告编号/新闻链接/研报名称+日期）
- [ ] 行业归属判断对照 `references/industry-mapping.md`，不凭直觉
- [ ] 边界模糊公司标注"模糊"并在报告中说明判断依据
- [ ] 报告包含风险分析章节（5 类风险至少覆盖 3 类）
- [ ] 区分"事实"与"推测"，未确认数据标注"待验证"
- [ ] 与上次扫描结果做 diff，标注新增/推进/停滞/终止
- [ ] S 级案例必须调用 moat-hunter 做标的不可替代性分析
- [ ] 最终结论调用 `scripts/print_conclusion.py` 打印到控制台

### Must-Not（严禁行为）

- ❌ 禁止将 B/C 级信号当作确定事实呈现
- ❌ 禁止编造交易金额、交易对方、交易进度
- ❌ 禁止给出任何形式的买卖建议
- ❌ 禁止仅凭单一来源（尤其 Web 来源）下结论
- ❌ 禁止忽略已终止/失败的交易案例
- ❌ 禁止使用社交媒体/论坛/KOL 作为信息来源
- ❌ 禁止将内部资产划转当作跨界并购

## 常见误判场景

| 场景 | 易犯错误 | 正确处理 |
|------|---------|---------|
| 传统车企投资新能源 | 误判为跨界 | 汽车行业边界模糊，按新能源收入占比判断。若新能源占比>50%，不视为"传统→新能源"跨界 |
| 同一集团内部资产划转 | 误判为跨界并购 | 用排除关键词过滤"同一控制下合并""内部重组""关联交易" |
| 收购金额 < 1000 万 | 误判为战略转型 | 金额过小通常只是参股试水或财务投资，标注金额并降级处理 |
| 跨界收购目的是"保壳" | 按正常转型逻辑分析 | 识别保壳动机（连续亏损+小市值+收购轻资产科技公司），风险等级+1 |
| 公告后 > 6 月无进展 | 仍列为活跃交易 | 标注"停滞"，移出活跃清单，必要时列入"失败案例" |
| 单一新闻来源（门户网站） | 当作确定事实 | B/C 级信号的单一来源必须标注"待验证"，不可提升为确定结论 |
| 标的名称含"科技"但实际非科技 | 误判为科技标的 | 穿透标的的实际业务（查工商信息/官网/行业分类），不只看名称 |
| 收购方本身已是科技公司 | 误判为跨界 | 检查收购方行业归属，若主营已是科技行业，不属于本 Skill 覆盖范围 |

## 边界情况

### 渐进式转型公司
某些传统企业通过多年多笔小型投资逐步转型（如传统化工→材料科技→电子材料）。
**处理方式**：单笔投资金额虽小，但若累计同一科技方向投资 > 3 笔，合并分析并提升一个等级。

### 借壳上市
科技公司通过传统行业壳公司上市，名义上是传统公司"收购"科技公司。
**处理方式**：识别借壳特征（控制权变更+主营业务变更+标的规模远大于买方），单独标注"借壳上市"而非产业并购。

### 海外并购
A 股公司收购海外科技公司或设立海外科技子公司。
**处理方式**：纳入扫描范围，但标注"海外"，额外关注地缘政治风险和审批风险。

### 多元化集团
某些公司横跨传统和科技（如部分国企集团同时有传统和科技业务）。
**处理方式**：按合并报表主营业务收入占比判定，若科技业务已超过 30%，标注"半转型"，不作为标准的跨界案例。
