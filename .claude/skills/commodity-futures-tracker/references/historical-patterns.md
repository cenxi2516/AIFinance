## C001: 铜金比与全球PMI

| 属性 | 内容 |
|------|------|
| **规律** | 铜金比（铜价/金价）与全球制造业 PMI 高度正相关 |
| **逻辑** | 铜是工业需求晴雨表，金是避险需求晴雨表。PMI上升→工业需求强→铜强于金→比值上升 |

| **方向** | 铜金比↑ = 经济复苏/通胀预期↑ = 工业金属看涨 |

## C002: 美元与黄金的反向关系

| 属性 | 内容 |
|------|------|
| **规律** | 美元指数(DXY)与黄金价格大部分时间呈反向关系 |
| **逻辑** | 黄金以美元计价，美元贬值 → 黄金对其他货币持有者变便宜 → 需求增加 |
| **触发条件** | DXY 单日波动 > 0.5% 或连续 5 日同向变动 |
| **方向** | 美元↓ = 黄金↑ |
| **例外** | 极端避险时（如 2020年3月、2022年3月），黄金和美元可以同涨（避险需求压倒定价机制） |
| **历史胜率** | 待验证（约 70-80% 时间成立） |
| **样本数** | 待积累 |

## C003: 金银比 — 市场恐慌/贪婪指标

| 属性 | 内容 |
|------|------|
| **规律** | 金银比（金价/银价）上升 = 市场避险情绪上升 = 经济不确定性增加 |
| **逻辑** | 白银有工业属性（50%+ 工业需求），黄金主要是避险/投资需求。经济担忧→工业需求预期降→白银弱于黄金 |
| **触发条件** | 金银比突破历史中枢 ±1 标准差 |
| **参考区间** | 历史上金银比在 45-95 之间波动，均值约 65。>80 = 极度恐慌，<50 = 极度风险偏好 |
| **历史胜率** | 待验证 |
| **样本数** | 待积累 |
| **首次记录** | 2026-07-23 |

## C004: LME 库存 + 注销仓单 — 短期价格先行指标

| 属性 | 内容 |
|------|------|
| **规律** | LME 注销仓单占比（Cancelled Warrants/Total）快速上升 → 库存即将下降 → 短期价格偏强 |
| **逻辑** | 注销仓单 = 被提货人标记为即将提取的仓单 ≠ 注册仓单(可交割)。注销占比上升意味着现货需求增加 |
| **触发条件** | 注销仓单占比单周上升 > 10 个百分点 |
| **方向** | 注销占比↑ = 短期看涨（1-4 周） |
| **注意** | 注销仓单可能是"融资交易"（非真实需求驱动的仓单注销），需交叉验证现货升贴水 |
| **历史胜率** | 待验证 |
| **样本数** | 待积累 |
| **首次记录** | 2026-07-23 |

## C005: 铜 TC/RC 加工费 — 矿端松紧指标

| 属性 | 内容 |
|------|------|
| **规律** | 铜精矿加工费 TC/RC 走低 = 矿端偏紧 = 中期铜价看涨（3-6个月） |
| **逻辑** | TC 是冶炼厂向矿商收取的加工费。矿紧张 → 冶炼厂抢矿 → 加工费降低 → 矿端供给不足 → 未来精铜产量受限 |
| **触发条件** | TC 跌破冶炼厂盈亏平衡线（约 40$/吨） |
| **参考区间** | 历史 TC 范围：20-130 $/吨。2024年以来 TC 跌至个位数（极端矿紧） |
| **历史胜率** | 待验证 |
| **样本数** | 待积累 |
| **首次记录** | 2026-07-23 |

## C006: 碳酸锂 — 成本曲线是最强支撑/压力

| 属性 | 内容 |
|------|------|
| **规律** | 碳酸锂价格跌破边际矿山成本 → 矿山减产 → 供需再平衡 → 价格止跌回升 |
| **逻辑** | 锂矿成本曲线陡峭：盐湖提锂 3-5万/吨 → 澳洲精矿 5-8万/吨 → 非洲/中国锂云母 8-12万/吨。价格跌破某个成本层级 → 该层级产能退出 → 供给减少 |
| **触发条件** | 碳酸锂期货价格跌破 8万元/吨（澳洲矿成本线） |
| **方向** | 价格 < 成本 → 中期看涨（减产→去库→涨价，但滞后 3-6 个月） |
| **2026年现状** | 碳酸锂约 14.5万元/吨，远高于澳洲矿成本线，但部分高成本产能（中国锂云母约 10-12万）有压力 |
| **历史胜率** | 待验证 |
| **首次记录** | 2026-07-23 |

## C007: 稀土 — 配额公布前后的价格脉冲

| 属性 | 内容 |
|------|------|
| **规律** | 工信部稀土开采总量控制指标公布前后（每年 2月/8月），稀土价格容易出现脉冲行情 |
| **逻辑** | 配额增速是市场对供需的核心预期锚。配额增速低于需求增速 → 供给缺口扩大 → 价格上涨 |
| **触发条件** | 配额公布日前后 2 周 |
| **方向** | 配额增速 < 10% = 看涨；配额增速 > 20% = 看跌 |
| **注意** | 配额不等于真实产量（可能有超采），但配额增速是政策态度信号 |
| **历史胜率** | 待验证 |
| **首次记录** | 2026-07-23 |

## C008: 内外价差 — 进口盈亏与国内政策信号

| 属性 | 内容 |
|------|------|
| **规律** | 国内期货价格 > 国际价格 + 进口成本（即进口亏损）→ 国内有独立利多（收储预期/限产/需求旺） |
| **逻辑** | 在正常关税和运费下，国内价格 = 国际价格 + 进口成本。溢价 = 国内独立因素在起作用 |
| **触发条件** | 国内-国际价格偏离度 > 3%，且持续 > 3 天 |
| **方向** | 国内溢价↑ = 国内独立利多 → 关注进口窗口打开后的套利压力 |
| **例** | 沪铜 vs LME铜的进口盈亏是铜市最常用的套利指标 |
| **历史胜率** | 待验证 |
| **首次记录** | 2026-07-23 |

## C009: 原油 — 地缘风险溢价的时间衰减

| 属性 | 内容 |
|------|------|
| **规律** | 地缘冲突推动的油价上涨，若无实际的供应中断，风险溢价会在 2-4 周内衰减 50-70% |
| **逻辑** | 市场对地缘风险的定价：第 1 周恐慌定价 → 第 2 周评估实际影响 → 第 3-4 周风险溢价消退（若无实质断供） |
| **触发条件** | 地缘事件爆发当日（中东冲突/俄乌升级/霍尔木兹海峡威胁） |
| **方向** | 初期冲高 → 若无断供则回落 |
| **关键验证** | 是否有实质性的供应中断（油轮停运/管道关闭/产量减少）vs 仅仅是"担忧" |
| **历史胜率** | 待验证 |
| **首次记录** | 2026-07-23 |

## C010: 黄金 — 央行购金是中长期趋势的最强支撑

| 属性 | 内容 |
|------|------|
| **规律** | 全球央行持续购金（季度 > 200吨）→ 黄金中长期走势偏强，短期回调是买入机会而非趋势反转 |
| **逻辑** | 央行购金是长期战略行为（去美元化/储备多元化），不因金价波动而改变。每年 800-1000 吨的央行购金量约占全球黄金需求的 20-25%，是最大的单一需求来源 |
| **触发条件** | WGC 季度报告显示央行购金 > 200吨 |
| **方向** | 央行持续购金 → 中长期看涨（6-24个月） |
| **2022-2026背景** | 2022年以来全球央行购金量创历史新高（年均 1000+ 吨），中国央行连续 18 个月增持后于 2024 年暂停，2025 年恢复 |
| **历史胜率** | 待验证 |
| **首次记录** | 2026-07-23 |

## 使用说明

1. **每次分析大宗商品时**：对照本库中的相关规律，检查是否触发
2. **发现新规律时**：按模板格式添加新条目，编号递增
3. **规律被证伪时**：不要删除，而是在更新记录中标注"证伪"和原因（避免重复踩坑）
4. **胜率积累**：每次分析后回填验证结果
5. **非 A 股规律**：这里是商品期货自身的价格规律，不与 quant-dashboard 中的 A 股市场规律重叠
