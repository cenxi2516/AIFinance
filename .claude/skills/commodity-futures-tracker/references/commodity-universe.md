## 四、新浪期货 API 字段说明

### 4.1 国际期货 (hf_ 前缀)

以 COMEX 黄金 `hf_GC` 为例（15 个字段）：
```
[0]  = 最新价
[1]  = 保留(通常空)
[2]  = 昨收/前参考价
[3]  = 今开
[4]  = 日最高
[5]  = 日最低
[6]  = 更新时间(HH:MM:SS)
[7]  = 日内最高
[8]  = 日内最低
[9]  = 成交量相关
[10] = 成交量相关
[11] = 成交量相关
[12] = 日期(YYYY-MM-DD)
[13] = 品种中文名
[14] = 保留
```

> 不同国际品种的字段顺序略有差异（如 XAU/XAG 与 GC/SI 不同），代码已做自适应解析。

### 4.2 国内期货 (nf_ 前缀)

以沪金 `nf_AU0` 为例（44 个字段）：
```
[0]  = 合约名称(如"黄金连续")
[1]  = 时间(HHMMSS格式)
[2]  = 最新价
[3]  = 今开盘
[4]  = 最高价
[5]  = 最低价
[6]  = 昨结算
[7]  = 买一价
[8]  = 卖一价
...  ...
[15] = 市场(沪/深/...)
[16] = 品种(黄金/铜/...)
[17] = 日期(YYYY-MM-DD)
...  ...
[27] = 均价
```

## 五、维护规则

1. **新增品种**：发现新的可追踪期货品种时，验证新浪代码 → 补充到本文对应分类 → 更新 SKILL.md 的品种字典
2. **代码变更**：新浪 API 无官方文档，品种代码可能变化。若某代码持续返回空，需重新搜索替代代码
3. **A股映射更新**：公司并购/更名/退市后需更新标的列表
4. **BK代码**：东方财富板块代码较稳定，但板块新增/合并时需同步更新
