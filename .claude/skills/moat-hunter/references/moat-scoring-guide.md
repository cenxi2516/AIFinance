# 5 类壁垒评分细则

本文档为 moat-hunter 的稀缺性评估提供详细的评分标准和真实案例参考。

## 评分总则

- **1 分（弱）**：该壁垒几乎不存在，或很容易被突破
- **2 分（较弱）**：存在一定壁垒但不够坚固
- **3 分（中等）**：有明显壁垒，需要时间和资源才能突破
- **4 分（强）**：壁垒坚固，短期（3 年内）难以被突破
- **5 分（极强）**：壁垒几乎是永久性的，或在可预见未来（5 年以上）无法突破

> **关键原则**：打分时必须引用具体依据，不能凭印象。无公开数据默认给 2 分（保守假设）。

## 一、技术壁垒（权重 30%）

### 定义

企业通过专利、know-how（默会知识）、工艺配方、技术秘密形成的竞争壁垒。

### 评分标准

| 分数 | 标准 | 典型特征 | 验证方法 |
|------|------|---------|---------|
| 1 | 通用技术，无专利保护，技术门槛低 | 产品可被逆向工程、无核心专利、技术人才流动大 | 专利检索无核心专利 |
| 2 | 有少量专利但可绕开，技术差距 1-2 年 | 工艺有优化空间但基本原理通用 | 竞争对手产品指标接近 |
| 3 | 有核心专利组合，know-how 需 3-5 年积累 | 良率/性能明显优于同行、有专利诉讼胜诉记录 | 良率对比、专利引用分析 |
| 4 | 核心专利不可绕开，know-how 需 5-10 年 | 行业标准必要专利、工艺配方为核心机密 | 标准必要专利（SEP）检索 |
| 5 | 技术路线唯一，know-how ≥10 年积累且无法复制 | 全球独有技术、没有替代技术路线 | 技术路线图显示无替代方案 |

### 关键信号

- **正向信号**：良率显著高于同行（≥10pct）、拥有标准必要专利、技术路线被行业标准锁定、研发投入持续高且产出效率高
- **反向信号**：同行良率快速追赶、新技术路线出现、核心技术人员离职创业、专利即将到期

### 验证数据源

```
专利检索: WebSearch → "{公司} 专利 {技术关键词}"
良率对比: WebSearch → "{公司} 良率 vs {竞争对手} 良率"
技术路线: WebSearch → "{行业} 技术路线图 2026"
```

## 二、认证壁垒（权重 20%）

### 定义

客户对供应商的认证/验证周期形成的进入壁垒。常见于汽车电子、半导体设备、航空航天、医疗器械等领域。

### 评分标准

| 分数 | 标准 | 典型特征 | 典型行业 |
|------|------|---------|---------|
| 1 | 无认证要求或 1-3 月可完成 | 标准化产品，客户直接采购 | 通用零部件 |
| 2 | 客户有认证流程但不长（3-6 月） | 需要样品测试但周期可控 | 消费电子组件 |
| 3 | 认证周期 6-18 月，行业有准入要求 | 需要产线审核、多轮验证 | 汽车 Tier2、一般工业 |
| 4 | 认证周期 18-24 月，每代产品需重新认证 | 进入客户 AVL（合格供应商清单）极难 | 汽车 Tier1、医疗器械 |
| 5 | 认证周期 ≥2 年 + 独家认证 + 客户不愿轻易更换 | 已成为客户唯一认证来源，退出代价极高 | 半导体设备、航空发动机 |

### 关键信号

- **正向信号**：已进入核心客户 AVL、认证通过公告、客户主动要求扩产配合、供应商份额持续提升
- **反向信号**：客户引入第二供应商、认证周期缩短（行业标准化）、客户自建认证能力

### 验证数据源

```
认证状态: 公司公告/年报 → "通过XX客户认证""进入XX供应链"
认证周期: WebSearch → "{行业} 供应商认证 周期 流程"
客户AVL: 客户年报/供应商名单 → 核实是否仍在供应
```

## 三、规模壁垒（权重 25%）

### 定义

通过资本开支规模、产能建设周期、规模经济效应形成的进入壁垒。

### 评分标准

| 分数 | 标准 | 典型特征 | 验证指标 |
|------|------|---------|---------|
| 1 | 轻资产，扩产 < 6 月，capex < 1 亿 | 设备通用、厂房租赁、可快速扩产 | 固定资产/总资产 < 15% |
| 2 | 扩产需 6-12 月，capex 1-5 亿 | 需要专用设备但供给充足 | 固定资产/总资产 15-30% |
| 3 | 扩产需 1-2 年，capex 5-10 亿 | 设备交期长、厂房需自建 | 固定资产/总资产 > 30%、在建工程/固定资产 > 10% |
| 4 | 扩产需 2-3 年，capex 10-50 亿 | 核心设备寡头垄断、需要配套基础设施 | 在建工程持续增长、环评/能评周期长 |
| 5 | 扩产 ≥3 年 + capex > 50 亿 + 选址受限 | 晶圆厂级别，需要政府审批、人才储备 | 百亿级投资公告、多地政府招商竞争 |

### 关键信号

- **正向信号**：在建工程持续增长、新产能被客户预订（"产能未投产已被订完"）、扩产公告中提及"客户要求扩产"、交期延长
- **反向信号**：行业集体扩产（警惕产能过剩）、竞争对手拿到大额融资、新进入者获得政府补贴

### 验证数据源

```
固定资产规模: a-stock-data 财报 → 资产负债表 → 固定资产 + 在建工程
扩产计划: 公司公告 → "扩产""新建产能""项目投资"
行业扩产统计: WebSearch → "{行业} 扩产 统计 2025 2026"
```

## 四、客户粘性（权重 15%）

### 定义

客户更换供应商的代价（切换成本），包括直接成本、间接成本和时间成本。

### 评分标准

| 分数 | 标准 | 典型特征 |
|------|------|---------|
| 1 | 标准化产品，客户可随时切换，切换成本接近零 | 大宗商品、通用物料 |
| 2 | 产品有差异化但替代品充足 | 品牌有认知但客户无忠诚度 |
| 3 | 联合开发关系，切换需 6-12 月重新认证 | 定制化产品、需要协同设计 |
| 4 | 深度绑定：联合研发 + 独家供应 + 长期合同 | 客户主动参股、5 年以上框架协议 |
| 5 | 客户无法脱离：产品嵌入客户核心工艺 + 共同投资 | 客户如更换供应商，产线需要重建 |

### 关键信号

- **正向信号**：客户合作年限长（≥5 年）、大客户参股、长期框架协议金额大、供应份额 > 50%、客户年报中提及为主要供应商
- **反向信号**：客户引入第二供应商、大客户自研进展、框架协议到期未续约、供应份额下降

### 验证数据源

```
客户关系: 公司公告 → "战略合作""框架协议""长期供货"
供应份额: 客户年报/供应商名单 + 公司年报 → 前 5 大客户明细
客户参股: 公司公告 → "引入战略投资者""定向增发"
```

## 五、政策壁垒（权重 10%）

### 定义

由政策、法规、牌照、出口管制等形成的行政性进入壁垒。

### 评分标准

| 分数 | 标准 | 典型特征 |
|------|------|---------|
| 1 | 无政策限制，完全自由竞争 | 一般制造业 |
| 2 | 有行业监管但备案即可，无实质限制 | 一般工商业 |
| 3 | 有行业准入要求，需申请许可 | 部分特种设备 |
| 4 | 牌照数量受限，新进入者受限 | 稀土开采、危险废物处理 |
| 5 | 牌照极其稀缺 + 出口管制限制竞争对手进入 | 军工三证、核工业、芯片出口管制清单 |

### 关键信号

- **正向信号**：公司拥有稀缺牌照、政策明确限制新进入者、出口管制把竞争对手挡在门外
- **反向信号**：行业放开准入、牌照扩容、政策方向转向市场化竞争

### 验证数据源

```
政策文件: WebSearch → "{行业} 准入 政策 牌照 2025 2026"
牌照清单: WebSearch → "{行业} 持牌企业 名单"
出口管制: WebSearch → "出口管制 清单 {行业/技术}"
```

## 综合评分计算

```
稀缺性综合评分 = 技术×30% + 认证×20% + 规模×25% + 客户粘性×15% + 政策×10%
```

### 评分等级

| 综合评分 | 等级 | 含义 |
|---------|------|------|
| 4.0 - 5.0 | 极强壁垒 | 在可预见未来几乎不可替代 |
| 3.0 - 3.9 | 强壁垒 | 壁垒坚固，替代需要重大投入和长时间 |
| 2.0 - 2.9 | 中等壁垒 | 有壁垒但存在被突破的可能性 |
| 1.0 - 1.9 | 弱壁垒 | 壁垒薄弱，竞争压力大 |

## 常见误区

1. **把"行业好"当成"壁垒深"**：行业高增长 ≠ 公司有壁垒。如果行业好但新进入者蜂拥而至，壁垒实际上很弱。
2. **把"规模大"当成"规模壁垒"**：大而不强的公司（固定资产高但回报率低）不等于有壁垒。关键是扩产的边际难度。
3. **把"客户大"当成"客户粘性"**：给大客户供货不等于被绑定。如果份额低（< 20%），大客户随时可以换。
4. **忽略时间维度**：壁垒是会衰减的。一个 5 年前的强壁垒如果没被持续加固，现在可能已经弱化。
5. **只看存量不看过量**：只看了现有供应商数量，没看正在进入的新玩家。
