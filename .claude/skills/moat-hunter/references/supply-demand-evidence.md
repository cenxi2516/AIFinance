# 供需关系验证数据源清单

本文档为 moat-hunter 的供需关系验证提供详细的数据拉取指南。

## 核心原则

- **至少 2 类证据**才能通过供需验证
- **真实数据优先**：财报数字 > 公司公告 > 券商测算 > 行业推断
- **趋势比绝对值重要**：连续 3-4 季的趋势比单一季度的绝对值更有说服力
- **数据滞后标注**：超过 2 季的数据必须标注"数据滞后，待季报更新"

---

## 一、订单/合同负债验证

### 为什么重要

A 股最重要的领先指标之一。合同负债领先收入 1-2 季，在手订单反映了未来 6-12 月的收入可见度。

### 数据拉取

**合同负债**（a-stock-data 财报）：
```
目标：资产负债表 → 合同负债科目
分析：最近 8 季趋势（环比增速、同比增速）
正向信号：连续 3 季环比增长 + 合同负债/单季收入 > 1.5x
反向信号：合同负债环比下降 + 合同负债/收入比下降
```

**在手订单**（公司公告 + WebSearch）：
```
a-stock-data: 公司公告 → 搜索"重大合同""中标""在手订单"
WebSearch: "{公司} 在手订单 2025 2026"
正向信号：在手订单/年收入 > 1.5x，或公司公告明确"订单饱满"
反向信号：在手订单下降、重大项目延期或取消
```

**重大合同公告**（巨潮公告）：
```
a-stock-data: 巨潮公告 → 搜索"经营合同""重大合同"
注意：关注合同金额、客户名称、执行期限
```

### 评分标准

| 状态 | 标准 |
|------|------|
| 🟢 强 | 合同负债连续 3+ 季增长 + 在手订单/收入 > 1.5x + 有明确重大合同公告 |
| 🟡 中 | 合同负债增长但幅度不大 + 在手订单/收入 1-1.5x |
| 🟠 弱 | 合同负债波动无明显趋势 + 在手订单数据不清晰 |
| 🔴 未验证 | 无公开数据或合同负债下降 |

## 二、产能利用率验证

### 为什么重要

产能利用率 > 85% 通常意味着供不应求，是企业扩产的触发条件。如果产能利用率高 + 扩产计划明确 = 供不应求被管理层面确认。

### 数据拉取

**产能利用率**（公司公告/调研纪要）：
```
a-stock-data: 公司公告 → 搜索"产能利用率""产线""达产率"
WebSearch: "{公司} 产能利用率 2025 2026"
WebSearch: "{公司} 调研纪要 产能 site:cninfo.com.cn"
正向信号：产能利用率 > 85% + 管理层提到"产能瓶颈""供不应求"
反向信号：产能利用率下降 + 新增产能投产但利用率低
```

**扩产计划**（公司公告）：
```
a-stock-data: 公司公告 → 搜索"扩产""新建项目""产能规划"
正向信号：扩产公告 + "客户要求扩产""产能已被预订"等表述
反向信号：扩产计划推迟或取消 + 行业集体大规模扩产
```

**交期数据**（WebSearch）：
```
WebSearch: "{行业/产品} 交货周期 2026"
正向信号：交期延长、客户排队等待
反向信号：交期缩短、现货充足
```

### 评分标准

| 状态 | 标准 |
|------|------|
| 🟢 强 | 产能利用率 > 90% + 扩产计划明确 + 管理层确认"供不应求" |
| 🟡 中 | 产能利用率 80-90% + 有扩产计划但规模不大 |
| 🟠 弱 | 产能利用率 < 80% 或数据模糊 + 无扩产计划 |
| 🔴 未验证 | 无产能利用率公开数据 |

## 三、价格/毛利率验证

### 为什么重要

在供不应求的环境中，企业通常拥有定价权，表现为产品价格上升和/或毛利率改善。毛利率是最直接的"供需关系温度计"。

### 数据拉取

**毛利率趋势**（a-stock-data 财报）：
```
目标：利润表 → 营业收入、营业成本
计算：毛利率 = (营业收入 - 营业成本) / 营业收入 × 100%
分析：最近 8 季毛利率趋势（环比变化）
正向信号：毛利率连续 2+ 季改善或维持高位（> 行业平均 5pct+）
反向信号：毛利率连续下降 + 原材料成本上升无法转嫁
```

**产品价格**（WebSearch）：
```
WebSearch: "{产品名称} 价格 趋势 2025 2026"
WebSearch: "{行业} 价格指数 2026"
正向信号：产品价格上涨或稳定，ASP 提升
反向信号：产品价格下跌、价格战
```

**净利率/ROE 辅助验证**：
```
净利率趋势：毛利率高但净利率低 → 可能有费用问题，议价权没有想象中强
ROE 趋势：ROE 持续 > 15% + 趋势向上 → 壁垒真正转化为回报
```

### 评分标准

| 状态 | 标准 |
|------|------|
| 🟢 强 | 毛利率连续 2+ 季改善 + 高于行业均值 5pct+ + 产品价格稳定/上升 |
| 🟡 中 | 毛利率稳定 + 与行业均值持平 |
| 🟠 弱 | 毛利率波动大 + 低于行业均值 |
| 🔴 未验证 | 毛利率持续下降 + 定价权丧失 |

## 四、客户行为验证

### 为什么重要

客户愿意"用钱投票"是最强的供不应求信号——预付款、锁定长期合同、参股供应商都是供不应求的极致体现。

### 数据拉取

**预付款/长期合同**（公司公告）：
```
a-stock-data: 巨潮公告 → 搜索"预付款""长期供货协议""战略合作协议"
正向信号：客户预付款（反映在合同负债中）、5 年以上框架协议、独家供应条款
反向信号：框架协议到期未续、合同条款松动
```

**客户参股**（公司公告）：
```
a-stock-data: 公司公告 → 搜索"定向增发""引入战略投资者"
正向信号：大客户参与定增、合资建厂、客户入股
反向信号：客户减持/退出
```

**客户集中度变化**（年报）：
```
年报 → "前五名客户"
正向信号：大客户集中度适度且供应份额提升
反向信号：大客户集中度过高（> 70%）且单一客户风险大
```

### 评分标准

| 状态 | 标准 |
|------|------|
| 🟢 强 | 客户预付款/锁定长期合同 + 或客户参股 + 或独家供应 |
| 🟡 中 | 有长期合同但无独家条款 + 客户关系稳定 |
| 🟠 弱 | 客户关系以短期订单为主 + 无可查长期协议 |
| 🔴 未验证 | 无公开客户合同信息 |

## 综合验证矩阵

| 综合状态 | 条件 | 置信度 |
|---------|------|--------|
| 🟢 **强验证** | ≥3 类证据正向且无矛盾 | 高：供需紧张已被多方数据证实 |
| 🟡 **中验证** | ≥2 类证据正向，数据一致 | 中：供需偏紧，但需更多数据确认 |
| 🟠 **弱验证** | 仅 1 类证据或数据矛盾 | 低：供需判断不确定性大 |
| 🔴 **未验证** | 无公开数据或全部反向 | 极低：无法判断或供过于求 |

---

## 常见陷阱

1. **合同负债增加 ≠ 供不应求**：可能是客户预付款政策变化、会计政策调整，需要结合产能利用率综合判断
2. **毛利率高 ≠ 有定价权**：可能是行业周期高点、一次性因素，需要看 8 季趋势而非单季
3. **产能利用率高但无扩产计划**：可能是管理层不看好需求持续性，反而是反向信号
4. **在手订单大但交付周期长**：如果交付周期被动延长（产能跟不上），是正向信号；如果客户主动推迟交付，是反向信号
5. **忽视应收账款质量**：合同负债增加但应收账款同时飙升 → 可能是放松信用政策换来的"假需求"
