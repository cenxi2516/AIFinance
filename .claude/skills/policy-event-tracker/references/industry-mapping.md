### 经济数据发布

| 数据 | 影响行业 | 传导逻辑 |
|------|---------|---------|
| CPI/PPI | 全市场 → 消费/周期 | 通胀↑利好上游周期，通胀↓利好下游消费 |
| PMI | 全市场 → 制造业 | 50 以上扩张，利好制造/设备 |
| 社融/信贷 | 全市场 → 金融/地产 | 超预期利好银行/券商/地产 |
| GDP | 全市场 | 超预期→风险偏好↑ |
| 进出口数据 | 外贸相关 | 出口超预期→利好光伏/锂电/电子 |
| 工业利润 | 制造业 | 利润改善→利好设备投资链 |

## 产业链敏感环节索引

### 按"弹性最大"原则

当政策/事件利好某行业时，按以下顺序找最敏感的环节：

1. **瓶颈/稀缺层**（供给受限，需求增加→涨价弹性最大）→ 参考 serenity-skill 分析
2. **高经营杠杆**（固定成本高，收入增加→利润弹性最大）→ 制造业/设备类
3. **直接受益**（政策直接补贴/采购对象）→ 最直接但弹性未必最大
4. **间接受益**（下游需求溢出）→ 弹性最弱，最晚反应

### 按"受损最重"原则

当政策/事件利空某行业时，按以下顺序：

1. **直接打击对象**（政策直接限制/制裁）
2. **高财务杠杆**（债务重，流动性收紧→最脆弱）
3. **高对外依存度**（出口占比高，贸易摩擦→冲击大）
4. **高估值**（杀估值时跌幅最大）
