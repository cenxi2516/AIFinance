# 大宗商品期货追踪器 (commodity-futures-tracker) — 设计计划

## 1. 定位

**14 技能架构的第 15 个 skill** — 专门追踪全球大宗商品期货价格，分析涨跌趋势，基于供需关系/政策/事件/产业趋势判断价格方向，并映射到 A 股相关板块。

**与现有 skill 的关系**：
- `a-stock-data`：为其提供 A 股行情数据（用于映射验证）
- `policy-event-tracker`：消费其政策事件输出，叠加商品维度
- `quant-dashboard`：为其提供商品价格信号作为宏观输入
- `industry-sentiment-tracker`：消费其行业情绪数据，验证商品→股票的传导

**四句话定位**：
1. **涨了还是跌了？** → 实时价格仪表盘，多品种多周期涨跌幅
2. **为什么涨跌？** → 供需关系 + 政策事件 + 产业趋势归因
3. **还会继续吗？** → 趋势研判 + 关键拐点信号检测
4. **A股怎么映射？** → 商品价格 → A 股板块/标的传导链

## 3. 分析框架

### 四层分析引擎

```
Layer 1: 价格仪表盘 (Price Dashboard)
├── 实时价格+涨跌幅（当日/5日/20日/60日）
├── 多品种横向对比（谁最强/谁最弱）
├── 内外价差（国内vs国际价格偏离度）
└── 关键技术位（均线/布林带位置）

Layer 2: 供需基本面 (Supply-Demand)
├── 全球供需平衡表（短缺/过剩 万吨）
├── 库存趋势（LME/SHFE/COMEX注册仓单变化）
├── 矿山产能（开工率/停产/新投产）
└── 下游需求（新能源/电网/地产/汽车 用金属需求增速）

Layer 3: 政策事件驱动 (Policy & Events)
├── 出口管制/关税/制裁（对供给的影响）
├── 矿山停产/罢工/自然灾害（供应冲击）
├── 收储/抛储（国储局操作）
└── 行业政策（产能置换/环保限产/碳关税）

Layer 4: A股传导映射 (A-Share Mapping)
├── 商品价格→A股板块涨跌幅相关性
├── 领先/滞后关系（期货领先股票多久）
├── 标的弹性（哪些股票对商品价格最敏感）
└── 背离信号（商品涨但股票跌 = 市场不买账）
```

### 价格分析信号（借鉴 fund-flow-predictor 的规则引擎模式）

| 信号 | 类型 | 触发条件 | 含义 |
|------|------|---------|------|
| S1 突破新高 | 看涨 | 价格突破 60 日最高且放量 | 趋势加速 |
| S2 连续下跌 | 看跌 | 5 日连续下跌且累计跌幅>5% | 短空趋势 |
| S3 内外价差扩大 | 关注 | 国内价格-国际价格偏离>3% | 套利/政策信号 |
| S4 库存低位+价格坚挺 | 看涨 | LME库存<5年低点 + 价格>60日均线 | 供给紧缺 |
| S5 期货领先股票 | 背离 | 期货涨但A股板块跌 | 股票有补涨机会 |
| S6 美元走弱+商品走强 | 宏观 | 美元指数跌+商品涨 | 宏观顺风 |

- 某个品种深度分析（供需+政策+趋势）
- 大宗商品→A股传导分析

- 个股买卖建议
- 短线交易策略
