# 新建 Skill: `tech-event-analyzer`（科技事件影响分析器）

## 一、设计定位

```
policy-event-tracker          tech-event-analyzer          hard-tech-dashboard
（全行业广撒网）      →       （科技赛道深挖+评分）    →      （六维合成研判）
  广度优先 → 罗列              深度优先 → 量化              合成层 → 综合
```

**核心差异化**：
- vs policy-event-tracker：只做科技 7 大赛道，但挖深挖透（全球事件 + 五维量化评分 + 共振检测）
- vs hard-tech-dashboard：本 skill 是**事件驱动主动拉取型**，不是合成消费型

## 二、核心能力

| 能力 | 说明 |
|------|------|
| 🌍 全球科技事件搜索 | 中/美/韩/日/欧，7 大科技子赛道 |

| 📊 五维影响评分 | 每事件 0-10 分，偏短期交易冲击导向 |

| 🔄 共振/对冲检测 | 多事件同向=高置信度，矛盾=风险信号 |
| 📈 **事件生命周期追踪** | 跨次运行，追踪衰减曲线，检测新事件加强/削弱原有方向 |

## 四、五维影响评分体系（短期交易冲击导向）

| 维度 | 权重 | 1 分 | 3 分 | 5 分 |
|------|------|------|------|------|
| **市场情绪冲击** | 30% | 个股级，不会引起板块波动 | 子板块级，可能带动同概念 3-10 只 | 全板块涨停潮级（如今日半导体） |
| **产业链影响** | 25% | 单只个股 | 细分环节（如存储/设备） | 全产业链/多子板块联动 |
| **时效紧迫性** | 20% | 1 月以上才兑现 | 1-2 周内 | 已发生待消化/本日/明日 |
| **确定性** | 15% | 传闻/媒体猜测 | 大概率/多方佐证 | 官方公告/CEO 确认/财报 |
| **新颖度** | 10% | 预期内/已被反复讨论 | 已知方向新进展 | 全新信息/超预期/首飞首發 |

**额外加减分**：
- 🚨 **强共振**（≥3 条独立事件同向）：**+1 分**
- ⚠️ **反预期**（与主流共识相反）：**+1 分**（反身性价值）
- 📉 **利好出尽风险**（对应子板块前期涨幅 >15%）：**强制降 2 分**
- 💰 **资金已提前反应**（近 2 日主力已大幅流入/流出）：**降 1 分**（已定价）

**最终影响分 = 加权分 + 加减分 → 映射到 0-10**

## 五、事件生命周期追踪（跨次运行）

### 衰减曲线模型

```
影响力
  ↑
10├─●  Day 0: 事件爆发，峰值影响分（如 8.5/10）
  │  ╲
 8├── ╲  Day 1-2: 快速衰减期（每日 ×0.8）
  │    ╲
 6├──── ╲  Day 3-5: 平稳衰减期（每日 ×0.9）
  │      ╲
 4├────── ╲  Day 6-10: 慢速衰减期（每日 ×0.95）
  │        ╲
 2├───────── ╲  Day 10+: 残余影响（每日 ×0.98）
  │           ╲________
 0├──────────────────────→ 时间
```

### 追踪机制

- 每次运行保存 `{事件ID, 初始分, 爆发日期, 衰减参数, 当前残余分}`
- 下次运行时：
  1. 计算旧事件衰减后的当前影响分
  2. 搜索新事件
  3. 检测新事件是**加强**还是**削弱**原有方向
  4. 合并输出：当前有效影响 + 新冲击
- 当影响分衰减至 <1.0 时标记为"已消化"，不再追踪

## 七、执行流程

```
Step 1:  读取前次运行的事件追踪状态（衰减计算）
Step 2:  全球科技事件搜索（WebSearch × 7 赛道 + 全球宏观科技）
Step 3:  去重 + 初筛（过滤噪音/非科技/已被充分定价）
Step 4:  五维评分（每条事件独立打分）
Step 5:  传导链分析（事件→子板块→核心标的）
Step 6:  共振/对冲检测 + 利好出尽风险检查
Step 7:  输出报告 + 保存事件追踪状态
```

## 十一、关键设计决策

1. **评分偏向短期冲击**：权重最高的维度是"市场情绪冲击"(30%)+"时效紧迫性"(20%)=50%，因为目标是判断 1-5 天交易冲击
2. **利好出尽是强制约束**：从 policy-event-tracker v1.3 继承，前期涨幅>15% 强制降 2 分（7/10 半导体血的教训）
3. **生命周期追踪用 JSON 文件**：轻量持久化，不需要数据库，文件放在 references/ 下
4. **搜索次数**：7 赛道 + 全球科技资金 = 8-10 次 WebSearch，比 policy-event-tracker 少但更聚焦
